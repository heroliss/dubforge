# DubForge

⚒️ **视频翻译配音工作台** —— 在 VideoLingo 领域经验之上全新设计的一站式流水线：
下载 → 预处理(人声/背景/说话人分离) → 转录 → 分句 → 翻译 → 字幕与配音 → 成片。

获取完成后，网络视频的平台标题、作者/频道、上传日期、时长、播放量、页面链接和作者描述会随下载一起采集；系统会调用 LLM 生成适合展示的中文标题和内容概要，并在获取视频页集中展示，标题、概要、来源和描述均可复制。LLM 不可用时不阻断下载；本地视频在转录前只提供可靠的基础信息。

「字幕与配音」页统一校对双语文字、修改逐句起止时间、合成试听和导出字幕。字幕导出与配音可分别选用；只做原文字幕时，语义整理完成后即可进入本页，不需要翻译或启动配音服务。校对稿单独保存，保留原始模型输出；字幕、试听和成片读取同一份修改结果。改时间保留音频完整长度，改译文仅使对应旧配音过期；上游重跑与手工修改冲突时会提示核对。

先挑代表句调整项目参数，再补齐配音时会复用有效音频，保留明确选择的原声和空位；逐句全部合成完也直接算配音完成，无需额外确认。单句、合成所选和补齐配音都作为后台步骤任务执行，刷新或切换页面不影响队列；顶部显示本次任务进度，可暂停或停止，列表显示当前合成句与失败原因。关闭后端会中断任务，已完成的版本保留。满意标记仅用于自行记录。任务表由校对后的时间轴和逐句译文自动准备，不再单独运行「配音计划」。项目配音参数不改变全局默认。

句子列表可直接试听、查看状态、切换原声/配音，并勾选部分或全部句子合成。点击句子文本只定位，不改变播放状态；单句试听与连续预览共用视频时间轴，背景音同步跟随暂停、拖动和变速。每句选用的原声、配音版本和音量直接用于最终成片，无需额外传递；新句默认原声。下拉框始终保留“新配音（空位）”，选中空位时人声静音，合成会新增版本；选中已有版本时合成覆盖它。满意只标记具体版本，覆盖后需重新确认。Shift 支持区间勾选，复选框仅用于批量操作。IndexTTS 支持「本句设置 → 项目步骤设置 → 系列模板 → 全局默认」逐项覆盖，列表外侧的本句参数入口可调整本句音色、情感与合成表现；服务地址、语言和超时仍由步骤统一管理。人工校对保留本句设置；上游重新分句后不套用旧句设置。

配音参数上方可快捷启动本机已安装的 IndexTTS / GPT-SoVITS，并自动检测启动是否就绪；已有服务直接复用。安装目录留空时自动查找，找不到或存在多个版本时可在配音参数中指定。启动日志位于工作目录的 `logs/`，失败时页面会显示具体路径。服务在后台独立运行，离开配音页不会关闭它；远程服务需在所在机器启动。

「转录」和「语义整理」是有意分开的：转录保留每个词的时间戳，只在强句末、明显停顿或约 2 秒识别后短语上限处形成时间锚点；2 秒只整理识别结果，不会切短 Whisper 的识别上下文。语义整理可按 `asr.segmentation_mode` 选择发送短语级时间轴（默认，请求较短）或全部词级时间轴，两者都会附带长静音提示，全文一次交给 LLM。超过安全预算时提示调整容量。模型按语义和真实时间重新分句；程序用可靠词锚点校正时间，长静音留空，长度和时长兜底沿用软上限，避免再次机械切碎完整表达。质量检查失败最多定向全文重试一次，仍失败则保留旧产物。关闭 LLM 后可单独使用规则整理。

翻译也尽量全文一次输入，只在实际请求预算不足时连续分窗，并保留边界参考与术语交接。整理完成的原文作为定稿，译文按同编号保留内容和时间，半句不跨编号补全。整理和翻译可独立选择「低思考强度（low）」或跟随模型配置，只影响本步骤请求；不增加正常调用次数，也不保证更低总 token 用量。

## 设计原则

1. **步骤常驻可见、可单独重跑** —— 管线是显式步骤状态机，不再有"下一步之后按钮消失"
2. **中断恢复一等公民** —— 产物原子写入、步骤输入指纹、重启自动判中断、全部幂等
3. **领域库与界面解耦** —— `dubforge` 纯 Python 核心库；FastAPI 是壳；Vue 是另一层壳；TTS/ASR/翻译全插件化
4. **中文一等支持** —— UI 全中文、错误码→中文消息+修复建议、注释中文

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Python 3.13 (uv) + FastAPI + SQLModel/SQLite |
| 前端 | Vue 3 + Vite + Naive UI + Pinia（构建产物由 FastAPI 托管） |
| 外部服务 | IndexTTS2.5 (:7860) / GPT-SoVITS (:9880) / OpenAI 兼容 LLM (智谱 GLM 等) |

IndexTTS 的「超长重试因子」默认 `0.7, 0.5`，留空关闭。新合成音频超过可用时间时，按顺序尝试比当前有效因子更小的值，时长合适即停止；仍偏长则保留本轮最短的完整音频并提示。句间空隙可利用，末句按自身结束时间判断；最终采用的较小因子自动保存到本句设置，后续合成沿用，详情显示音频实际使用的因子。

配音合成期间可继续播放视频和逐句试听；每句完成后约 1.5 秒内自动更新预览音频，保留视频位置和播放状态。覆盖配音及缩时重试期间可继续试听旧版本，本句完成后切换到新结果。

句子列表的「自动定位」可选关闭、跟随合成或跟随预览，两种跟随模式互斥。跟随合成在切换合成句时选中并滚动列表，同时定位视频；「定位到本句」也执行相同操作，均保持播放或暂停状态。跟随预览只随播放换句选中并滚动列表，不改写视频位置；句间停顿保留当前句。自动定位的选中不改变批量勾选。

同步预览中的「字幕」可切换原文、译文、双语或关闭。默认双语，无译文时显示原文；直接读取已保存的校对文字和起止时间，无需先导出或合成配音。双语顺序沿用导出设置。字幕文件旁的「预览」用于核对实际导出结果（含最短显示时长）；文件过期后自动切回当前文字。切换字幕不改变视频位置和播放状态。

视频上方的「烧录效果」可调整字体、字号、文字色、描边和底部距离，并渲染指定时间的单帧画面。预览和最终成片共用 FFmpeg 字幕样式，包含导出时的最短显示时长；预览无需先导出或配音。保存设置并在成片版本中开启烧录后即可合成；字幕导出用于单独取得字幕文件。字体使用系统已安装字体，找不到或缺字时自动回退；SRT 不保存样式。普通视频字幕用于检查文字与时间，样式以烧录效果预览为准。 合成成片页可输入起止时间，或点 ⏱ 使用当前播放时间，并生成 preview_*.mp4 试合成片段；试片使用当前成片参数和区域内的配音/字幕，不替代 final_*.mp4 正式成片。合成成片页的「成片版本」支持原声/配音、字幕、评论三个独立维度及版本差异设置；输出以版本身份命名，同版本重跑替换自身。原声、不烧录字幕且不叠加评论的版本直接引用原片，不重复合成。实际产物路径可直接点击，在文件浏览器中定位。

语义整理按真实语音时间分配文字，避免长句挤进极短片段；翻译请求及局部修复均附上每句时长，引导短句简洁、自然语速能说完，并保留关键信息。时长参与翻译缓存指纹。该引导不等同于精确控制 TTS 时长，实际超长仍由配音提示和可选缩时重试处理。

## 快速开始

### 一次确认，从视频到B站

先在侧栏「系列模板」设置全局默认及系列模板，再在项目总览绑定模板；多个项目可在项目空间勾选后批量绑定。设置只有「全局默认 → 系列模板 → 项目覆盖」一条继承链，各步骤显示生效值与来源。未覆盖字段跟随上级，恢复继承会删除本层覆盖，明确关闭、0、空值或与上级相同的值仍可保留为独立设置。

项目空间的「批量导入」支持逐行视频链接/本地路径，以及带逐项目模板和参数覆盖的 JSON 清单；可以粘贴、读取或拖入文件。先预览再创建，默认跳过重复来源，断线可安全重试；只创建、不自动运行。格式、双分P样板和给其他 LLM 的用法见 [批量创建项目](docs/batch-project-import.md)，入口内还能下载含当前模板及全部可用参数的 LLM 说明。

- 在「合成成片」保存版本清单，例如中文配音版与原声双语版。每个版本独立选择配音、烧录字幕、叠加评论，可覆盖字幕与评论样式。清单整体继承；本项目编辑清单后不再跟随上级清单。
- 在「发布到B站 → 项目发布设置」指定账号、合集、文案和封面规则，以及版本对应的分P顺序、发布名称。分P引用已有版本，不再维护另一套成片参数。模板也使用同一套发布字段。
- 在获取视频页的评论区选择沿用已确认内容，或自动采集、评分、翻译及上屏。自动模式目前支持 YouTube；采集上限、上屏数量、提示词及样式均可继承。无可用评论时停止，不偷偷改成无评论版。
- 项目总览「自动运行 → 检查并运行」读取已保存设置，只核对终点、依赖与执行范围，不另存全流程方案。项目空间可对所选项目逐一预检并批量执行，存在阻塞的项目不会启动。
- 终点分为仅制作成片、准备发布草稿和自动投稿。默认只准备草稿；自动投稿仍需对本批视频确认权利。AI 只补齐未手动指定的文案，保存设置本身不会触发制作或投稿。
- 同版本再次生成会原子替换自身，未变化版本复用。总览“运行勾选步骤”仅制作，不自动投稿。失败保留已完成结果；重启后需重新预检才能继续。投稿结果不明时不自动重发，加入合集失败不重复上传。
- 运行期间锁定执行勾选与设置：项目只检查本项目，系列检查绑定项目，全局检查所有项目。停止、取消、浏览与实时显示偏好仍可用；仅等待 B站审核不锁定下一次使用的设置。正在执行的步骤继续使用冻结快照，重启或外部改动后仍需核对再继续。需要先配置 LLM、识别环境及配音服务；自动流程不擅自安装或启动这些外部组件。
- 修改已有项目继承的制作参数会使相关结果显示需更新，旧文件仍保留，保存设置不会自动重做。轮换 LLM 密钥、调整等待超时或编辑未使用的模型组不会影响制作结果；希望项目固定参数时，可使用项目覆盖。
- 项目列表、流程总览和步骤页的「需更新」等状态标签可直接点击，悬停显示简要变化，点击查看完整参数对比、设置来源、上游文件状态及可能受影响的步骤。成功制作会保存脱敏输入快照；升级前只存指纹的记录会明确提示无法还原旧值，仍显示能核实的依赖变化与文件缺失。查看原因不会启动任务。

升级时只迁移一次旧设置值，删除旧配置表和独立账号默认层，不保留双轨读写。旧账号默认如有值，会转为普通系列模板。迁移前在数据库旁保存 `*.before-unified-configuration.sqlite3` 备份，并更新项目恢复清单；不删除视频、字幕、配音或发布回执。配置设计见 [ADR-0058](docs/decisions/0058-unified-series-configuration.md)。

**日常启动：双击根目录 `StartDev.bat`** —— 立即显示启动提示，按阶段检查配置、启动服务并报告等待时间。默认只保留一个控制台；输入 `help` 查看全部命令，`quit` / `exit` / `stop` 退出并关闭本次前后端，保留复用的后端与独立配音服务。直接回车只显示帮助。
后端和前端日志写入 `data/dev-logs/<后端端口>-<前端端口>/`，重开时旧日志移至其中的 `archive/`（均不入库）。后端端口读取 `config.yaml` 的
`server.port`，前端开发端口默认是 `5273`。需要分别观察服务窗口时，运行
`powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1 -ShowServiceWindows`。
停止开发服务只会结束本次启动的后端/前端进程，不会删除项目文件或已完成产物；如果页面中仍有管线任务，建议先在页面点击「停止」并等待它进入结束状态，再停止开发服务。开发服务被中断时，下一次启动会按恢复规则把未完成步骤标为「已中断」。

调试模式下看到的三个控制台分别是：启动控制台（控制面板）、后端 FastAPI/Uvicorn
（`config.yaml` 中的 `server.port`，带自动重载）和前端 Vite（5273，热更新）。它们是两个服务加一个控制器，并不是重复启动；
日常模式隐藏服务窗口，标准输出与错误仍写入日志。`logs backend` / `logs frontend` 查看最近输出；`watch backend` / `watch frontend` 连续跟随，按 Esc 或 Q 返回控制台。可用 `services` 查看 IndexTTS、GPT-SoVITS 及项目独立地址，用 `start indextts25`、`stop indextts25`、`logs indextts25`、`watch indextts25` 管理指定服务；GPT-SoVITS 使用标识 `gptsovits`。启动配置和配音占用保护与网页共用，控制台不会切换项目选用的后端。

开发时只访问启动脚本最后打开的 `http://127.0.0.1:5273`。它是 Vite 前端，`/api` 会自动代理到同一轮启动的后端端口。
后端端口（例如 `8601`）也能直接打开页面，这是生产形态：FastAPI 同时提供 API 和 `frontend/dist` 静态页面。
两种访问方式不是两套功能；修改代码后应使用开发地址，生产页面需要重新构建 `dist`。
如果启动脚本发现后端端口已被占用，选择“复用现有实例”只会启动前端，后端仍运行旧代码；
修改后端代码或要验证最新修复时，应在当前任务安全结束后选择“结束现有实例并重新启动”，再刷新 `5273` 页面。

首次使用需初始化依赖：

完整安装、可选环境和共享预设说明见 [安装指南](docs/installation.md)。Windows 可在根目录运行 `./scripts/install.ps1` 安装基础程序，按需增加 `-Asr`（识别）和 `-Separation`（人声分离）；已安装用户可使用 `-SkipFrontend` 只补装后端组件。配音服务使用独立环境。

```powershell
# 后端 (自动下载 Python 3.13 并装依赖)
cd backend
uv sync --inexact    # 基础依赖；本地识别加 --extra asr，分离加 --extra separation

# 前端
cd frontend
npm install
```

手动方式（等价于 StartDev.bat）：

```powershell
cd backend
uv run uvicorn app.main:app --port 8600 --reload

# 前端 (另一终端)
cd frontend
npm run dev          # http://127.0.0.1:5273, /api 默认代理到 8600；启动脚本会自动传入实际后端端口

# 生产形态
.\scripts\build.ps1          # 构建 dist
cd backend; uv run uvicorn app.main:app --port 8600   # 单进程托管 API + 页面
```

首次使用：复制 `config.example.yaml` → `config.yaml`，填入 LLM API key（该文件已 gitignore）。

## 新手配置顺序

第一次使用不需要理解全部参数，按这个顺序即可：

1. 在「设置 → 模型与服务」填写 `base_url`、`api_key` 和 `model`，点「测试」确认服务可用，再点「保存模型设置」。
2. 新建项目时粘贴视频链接，或填写本地视频路径；不确定时保留默认参数。
3. 在项目总览勾选需要的步骤，点击「运行所选」；若依赖缺失或过期，可点击「准备依赖并运行」「补齐依赖并运行」或「更新依赖并运行」，先查看执行计划再执行。可以只下载、提取音轨，或在语义整理后导出原文而不翻译；识别原稿可在语音转文字步骤直接下载。在「字幕与配音」页校对后，字幕和配音共用修改结果，导出与合成分别可选；上游更新后可用「字幕与配音」的「同步更新」刷新导出文件并重新合成失效句子，需要精调声音时再逐句试听。
4. 在「设置 → 制作与发布」统一编辑全局默认和系列模板的共用参数，项目绑定模板后只修改例外。步骤页显示最终值与来源，修改后点击保存；点击恢复继承可继续跟随模板或全局。

设置页仅保留三个分类：「制作与发布」管理继承规则；「模型与服务」管理连接、密钥与本机环境；「运行与存储」管理并行度、目录、显示偏好与耗时记录。切换分类保留草稿，切换模板或离开时提示未保存修改。全局、模板与项目复用参数编辑器，配音预设与 IndexTTS 推荐参数先填入草稿，保存后生效。

参数旁的说明解释了“调大/调小”的代价：通常更清晰、更准确会更慢并占更多显存；遇到显存不足或服务限流，优先降低模型规格、位移次数或并发数。

## B站发布中心（首版）

侧栏「发布中心」或合成页「选择成片，发布到B站」可进入。同一项目选择多个成片作为分P，共用标题、封面和发布设置，并可加入现有合集。发布规则沿用全局、系列模板和项目的统一继承；具体稿件保存文案与文件清单，确认上传后冻结快照。单纯修改发布规则不影响成片的新旧状态。

先安装可选组件：`./scripts/install.ps1 -Publishing -SkipFrontend`（或在 `workers/bilibili` 执行 `npm ci --ignore-scripts`）。然后在发布中心扫码连接账号、读取可用设置、新建草稿并选择成片。页面按「准备视频 → 投稿资料 → 确认发布 → 进度与回执」排列。保存资料仅修改本地草稿；「上传并投稿」在确认一次后自动完成全部分P上传、正式投稿及配置的合集归属，关闭页面不停止后台任务。「仅上传文件」完成后停在待投稿，文字资料仍可修改，不需要重传视频。

审核退回后，先生成符合当前审查设置的新成片。在原发布记录点击「使用审查修订版新建草稿」，核对逐P替换清单后创建本地草稿；系统按登记的原产物关联修订版，保留原分P顺序、名称、账号、封面与已确认文案。缺失、失效或有歧义的修订文件会阻断创建，不会自动使用旧文件。核对资料后点击「上传并投稿」即可后台自动重发。该路径创建另一条投稿、取得新的BV号，原稿与原回执保留。

如果要保留原BV号，请打开B站创作中心修改原稿、替换视频。本地「B站稿件」支持文案、分P排序、追加分P和合集管理；追加会保留全部旧视频，不能代替审核退回后的原分P替换。

项目列表、项目总览与稿件页展示独立的B站发布状态。视频上传按实际已传字节显示进度、当前分P及已完成分P数量；字节达到100%后仍显示合并分片、正式投稿和加入合集等阶段，直至平台确认完成。

配音、成片和发布页提供「发布前内容审查」。默认开启本地文本筛查与命中时段的完整混音静音；同时检查整理原文、译文、原始识别稿和评论。命中行从原文、译文、双语字幕及烧录字幕中整句隐藏，原稿保留。自定义屏蔽词每行一个，人工屏蔽时段按原视频时间填写 `开始秒-结束秒:原因`，例如 `60.5-72:平台指出的片段`。评论命中后整条不入选；自动选评同时按平台内容类别筛选。配置沿用全局、模板、项目继承，保存后需重新生成相关字幕与成片。

审查面板只执行本地规则，不自动调用模型。内置规则针对已经遇到的明确语境，普通旅游地名不单独屏蔽；规则可能遗漏改写、画面文字及未转写语音，未命中不能解释为审核通过。投稿预检会拒绝仍含已知需处理时段的旧成片，候选文件标明是否按当前规则处理。原有投稿和上传回执不会因修改设置自动替换；审核退回仍需核对完整片段。调查与限制见 [B站审核调查](docs/research/bilibili-review-2026-10-05.md)，实现决策见 [ADR-0082](docs/decisions/0082-content-review-and-redaction.md)。

首版采用 Windows 当前用户加密存储。真实账号联调尚待完成；遇到风控、声明或合集限制须在官方创作中心核对，不绕过平台验证。具体边界见 [ADR-0041](docs/decisions/0041-bilibili-publication-boundary.md)。
