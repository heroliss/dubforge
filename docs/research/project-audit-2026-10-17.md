# DubForge 项目审查与优化 · 2026-10-17

## 范围与方法

沿现有 Vue3 / Naive UI、FastAPI API、纯 Python 领域层、runner、配置与指纹边界，检查任务并发、文件提交、失败恢复、状态同步、项目导入、播放器、设置与工作流操作。工作区已有大量未提交开发，本轮保留这些改动；本文列出的修复基于当前源码及隔离复现。

技能分工：Impeccable 用于操作与信息层级；frontend-design 用于保持现有界面视觉方向；UI UX Pro Max 的定向查询核对异步反馈；Web Interface Guidelines 核对语义控件、可访问名称、焦点与状态反馈。使用 [当前官方检查规则](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)，不把风格偏好当成产品缺陷。Impeccable 机械检测输出为空；其对 Vue 的理解有限，不能替代行为和实际网页检查。

## 实际修复

| 范围 | 触发与原因 | 处理与验证重点 |
| --- | --- | --- |
| 发布并发 | 多 GB 文件预检/哈希仍持全局锁，另一稿件暂停、进度写入被阻塞 | 长预检只保留本稿件占用；短锁内入队，预检取消不启动上传，线程池拒绝恢复可重试状态；用阻塞替身验证另一稿件仍能操作 |
| 本地上传 | 异步请求中同步写文件、原子替换、写 DB/manifest，慢磁盘拖住事件循环 | 请求流留在事件循环，磁盘/DB工作进入线程；断线与原生取消等待当前写入退出再清理；阻塞写入和清单时健康请求仍返回 |
| 翻译提交 | 完成一个窗口即覆盖正式译文，后续失败丢失原完整结果 | 过程快照按任务隔离，普通 raw 与下游使用完整产物；显式预览标注部分结果；强制重做、取消和强制结束保留完整文件；见 ADR-0186 |
| 翻译缓存 | 损坏 JSON、无效编码或读取失败直接中止，重试反复撞同一文件 | 可重建的窗口缓存按未命中处理，重新请求与校验；不放宽译文结构要求 |
| 网络与状态 | 任意读取失败都称“任务安全中断”；一个接口恢复清掉其他错误 | 分来源跟踪网络/超时/响应错误与最后成功时间，保留可信状态，明确后台可能继续；模拟 HTTP 503 和真正断线/恢复 |
| 配音试听 | 无视频时 `null?.media === undefined` 可为真，恢复访问空 request；修复后又暴露时钟重复累计 | 明确非空请求身份，恢复时重置音频时钟锚点；测试暂停点恢复、迟到请求隔离 |
| 导入操作 | 放弃导入先清上下文，DELETE 失败仍提示删除成功 | 服务端确认后才清理，失败保留项目、文件和错误可重试，删除期间阻止重复操作 |
| 播放器性能 | 布局缓存命中前已遍历、拆分全部字幕文本；timeupdate 等事件反复触发 | 先比较轨道身份、cue 列表与数量，加载时显式失效；1500 cue 连续 100 次稳定更新从 150000 次文本读取降为 0，另验相同条数的新轨道和事件解绑 |
| 运行范围 | 运行中的勾选框可点，提交却被忙碌门禁拒绝 | 控件可用状态与提交条件一致；锁定执行范围，参数编辑继续遵守原规则 |
| 批量预检 | 串行读取时只显示总转圈，全部完成前隐藏已读结果 | 显示已检查数/总数、当前项目及逐行结果，保留取消和迟到响应保护；不引入无依据的额外并发 |
| 可访问性 | 窄屏导航把当前焦点区域设 inert，却没有焦点交接；模型字段缺关联名称 | 打开聚焦关闭按钮，Tab 循环，Esc 归还，切页移到当前位置；设置字段、启用和测试按钮带配置上下文 |
| 复合设置行 | 评论字号上下界又被 label 包住，内含恢复按钮和多个控件 | 改为有名称的分组容器，保持布局，避免点击触发额外继承恢复 |
| API 边界 | 未知 `/api/...` 被 SPA 兜底成 HTML 200，前端只能遇到 JSON 解析错误 | 未知 API 返回中文 JSON 404；正常页面深链和路径穿越保护保留 |
| 验证工具链 | 默认并发多个 Vite SSR 测试进程，历史出现内存耗尽；TS源码后缀与 tsconfig 不一致 | 默认串行执行并限制每进程 Node 堆；提供 `npm run typecheck`，修复实际空引用与可空组件类型问题；增加领域层禁止界面依赖的架构检查 |

## 保留的架构与后续重点

- API 与领域库分离仍成立，本轮增加 AST 检查防止以后引入 `app` / FastAPI / Starlette 依赖；不依文件行数单独决定重写。
- runner、工作流、发布记录各有真实生命周期；UI共用已有轮询、取消、刷新和执行诊断工具，不建立平行的“完成状态”。
- 配置基础值、项目单独设置、任务冻结快照继续分层。范围选择和正在执行的任务不能混为一谈，修改后的配置按已有生效边界使用。
- `StepView.vue`、`DubbingPanel.vue`、runner 和发布 service 仍较大。后续随真实功能边界抽取完整职责及其测试，优先文本/字幕预览与步骤操作；这次新增过程快照模块是一个局部边界示例。不要先增加一层空壳抽象再逐条透传。
- 构建仍有大于 500 kB 的资源块提示。应基于实际路由加载、首屏耗时和缓存收益决定进一步拆包，不能仅为压掉警告随意重排依赖。
- 磁盘 I/O 进入线程能保护服务响应，不能修复硬盘/驱动故障或保证不会整机卡死。真实长视频、GPU模型及远端 B站审核仍需在正式运行中观察。
