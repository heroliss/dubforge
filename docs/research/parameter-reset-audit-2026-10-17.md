# 参数逐项恢复入口审查

## 设计

参数旁始终显示统一的小回转箭头。有本层覆盖或未保存修改时可用，已继承或被运行状态锁定时禁用。无障碍名称包含字段名及具体动作，悬停说明恢复对象；不用数值相等推断继承，保留显式的同值、false、0。按钮先修改编辑草稿，由所在表单保存或确认。

不把出厂默认、最新全局值、项目基础值、项目共同参数及已保存值混为一个“默认值”。

## 已统一的界面

| 界面 | 逐项恢复对象 |
| --- | --- |
| 成片版本呈现参数 | 删除本版本该项专用值，跟随项目默认 |
| 版本名称、声音与字幕/评论开关 | 撤销本项未保存修改，不改其他结构或参数 |
| 制作步骤项目参数 | 恢复项目基础值；共享服务参数恢复服务设置 |
| 本句参数与朗读文本 | 恢复项目共同参数或跟随本句译文；自动跟随本句的派生项禁用 |
| 全局设置 | 撤销该项未保存修改，不删除已保存全局配置 |
| 系列模板 | 删除模板覆盖，恢复继承 |
| 设置页内嵌成片版本 | 专用参数恢复共同设置，结构字段按项撤销已保存值 |
| 发布参数与互动开关 | 沿父表单的恢复协议；视频资料、项目基础值与稿件快照保持区分 |
| 分 P 名称 | 逐行按版本 ID 撤销已保存名称，保留其他行；整组恢复仍独立存在 |
| 评论排版与字号范围两端 | 删除对应项目覆盖；缺少基础值时禁用，确认上屏方案后保存 |

`ParameterResetButton.vue` 统一图标、尺寸、可访问名称、悬停说明与禁用事件保护。恢复按钮与配置来源标识相邻，替换原先仅覆盖后出现、文字长度和位置不一的按钮。

## 其他已核对的边界

- 配音播放器下方人声/背景滑条是立即试听与自动保存的重复入口，现有 `useDubbingMix` 只有具体数值写入协议，未新增会冒充继承的“恢复 100%”。真正恢复继承仍可通过本项目参数表单操作；若未来直接补在滑条旁，需与拖动保存合并、并发读取及配置指纹共同处理。
- 剪辑范围、翻译背景资料和章节清单是内容或快照，不具备普通参数的上级继承关系，保留现有撤销、读取已保存或载入来源的操作，不按数组位置猜测恢复目标。
- LLM 请求参数的留空或默认选项表示不发送该参数，由接口决定；不等于撤销本地已保存值。
