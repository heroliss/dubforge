# 运行期间编辑锁定与累计优化验收

日期：2026-10-07。决策见 [ADR-0098](../decisions/0098-runtime-edit-locks.md)。

## 编辑规则

- 项目排队、执行、停止收尾、单句配音、发布文案生成、修订成片生成及上传投稿期间，阻止修改该项目的勾选、设置和可编辑产物。
- 系列设置检查绑定项目，全局执行设置检查全部项目；其他闲置项目仍可编辑。任务启动与短暂保存共用门禁，后端负责最终校验。
- 查看、导航、停止及远程审核查询保留。明确支持实时生效的显示追赶距离单独保存，不改变执行快照。
- 全局显示偏好与执行设置混合提交时整体拒绝，不能部分保存。自动流程和步骤内必要写入使用经过验证的执行身份，不放宽外部请求。
- 后台收尾与重试等待也算运行占用；继续本步骤的重试不会被自己的等待标记挡住，其他步骤及外部编辑仍受限制。

## 本机设置与服务

读取本机配置确认请求时限为用户保存的 1800 秒。该值保留在忽略的 `config.yaml` 中，不修改安装默认值，也不参与内容产物的过期判断。其他个人设置与密钥继续留在本机。

常驻服务恢复至配置指定的 8601 端口，健康接口通过，9 个项目正常加载。测试服务只使用 8611，隔离配置、数据库与模拟项目；测试后停止该服务。保护端口 8600 未占用或停止。

## 隔离页面验收

在隔离服务启动后设置一个模拟制作任务为运行中：项目勾选呈禁用状态，停止入口仍可用；全局请求时限显示 1800 且不可编辑，显示追赶距离输入仍可编辑；绑定系列的设置禁用，其他闲置项目的勾选可编辑。

模拟任务恢复空闲后，不刷新页面即可恢复勾选与运行入口。浏览器未捕获控制台警告或错误。验收未启动真实 LLM、配音、编码或投稿任务。

系列模板归档另补当前作用域的禁用、原因提示及方法守卫，避免表单已锁定而归档按钮仍可点击；其他模板保留独立作用域核对。

真实 9 项目环境下连续请求编辑状态接口 10 次，中位耗时 3.4 毫秒，最大 10.0 毫秒。查询只读取运行状态所需字段；前端共享作用域订阅、合并请求、暂停隐藏页面轮询。

## 自动验证

首次全量后端回归为 2552 项通过、1 项失败；失败来自旧测试要求运行中编辑已经完成的步骤。修订后验证编辑被拒绝、原配置和冻结快照不变、流程继续运行，结束后允许编辑。工作流与关联设置共 123 项通过。

修订成片模块另有 14 项通过，覆盖生成文案期间禁止启动修订成片、输出文件保留及原有执行与发布保护。

最终全量后端回归：`uv run pytest -q --tb=short`，2554/2554 通过（762.63 秒）；只有既有测试客户端依赖的两项弃用警告。

前端完整测试 494/494 通过（10.70 秒），构建成功（5.43 秒）；B站上传工作进程测试 45/45 通过。

提交前检查暂存差异空白格式及密钥模式。`config.yaml`、数据目录、虚拟环境和前端构建产物不入库；匹配的密钥前缀均为脱敏正则、隔离测试伪样例或 CSS 类名子串。

## 本次整理范围

一并提交此前累积的全文语义整理与翻译优化、宽松内容提示与严格格式协议、声学留空、LLM 请求时限和流式响应保护、IndexTTS 诊断、过期原因与指纹、断点恢复、成片预览性能、发布进度及可编辑文案、发布前内容筛查与修订成片等修改。个人配置和现有制作产物继续由本机保存。
