# ADR 0090：全文文本处理与请求级低思考强度

日期：2026-10-07。状态：已采用。替代 ADR 0089 的正常整理、翻译主动分窗设计；保留其信息保真、缓存与翻译失败恢复机制。

## 问题

项目 `99211e` 的任务 #279 首窗第一轮输出正常结束，却因为一句跨越 38.84–44.92 秒的真实无声区而未通过质量检查。第二窗第一轮附加“整理说明”，还把 `would go` 推断为 `won't go`，并跨越数处长静音。失败不是网络中断或输出截断。短语模式未完整展示短语内部的词级静音；提示词重复要求完整句、允许重新分配词语、要求避免长停顿，使目标和声学约束存在冲突。

当时选中的模型使用 `reasoning_effort=high`，每个小窗可能花费一至两分钟。用户明确选择恢复全文输入并减少思考，要求重新考虑提示词。

## 决策

- 语义整理一次提交全部原识别稿，不主动分窗，也不在失败后自动二分。完整请求及输出预留超过上下文安全预算时给出中文容量提示，不能悄悄改变输入范围。
- 提示词明确按信息保真、真实时间、自然分句三个优先级组织。允许有依据的听写纠错和噪声清理，不要求逐词照抄或保持 ASR 句数；不能凭常识增删否定、数字或实质事实。真实长停顿导致的半句可以保留。
- 词级与短语级模式均单独展示由词锚点计算的长静音区间。普通犹豫仍由语义判断。没有词级信息时只能使用已知短语间隙，不虚构短语内部静音。
- 用可靠的单调词序映射修复跨长静音的候选，保留候选全部字符与纠错；有歧义的切口仍报质量错误。修复不能删除半句、拿 ASR 覆盖候选或创造时间。零时长识别词保留文本与位置，不能单独伪造语音时段。
- 正常成功只请求一次；质量失败最多追加一次携带同一全文的定向重试。网络、取消、容量及存储失败不扩张成更多质量调用。成功原始响应按实际提示、原文、词锚点、请求参数和整理规则版本原子缓存，使用时重新检查完整候选。
- 翻译尽量全文一次输入。完整请求超预算时才连续分窗，包含系统提示、完整输出预留、术语交接和边界参考；不得为固定40句上限拆开能完整发送的稿件。结构失败时保留有界的局部恢复，不改变最终原文编号、句数和时间对应。
- 翻译将整理稿作为定稿，不再次凭常识改写识别文本。全文语境用于代词、术语等消歧，每行只翻译同编号已有的信息；跨静音保留的半句仍译成半句。事实、数字、币种、否定和比较方向优先于流畅、网络梗或时长压缩。协议检查只能验证结构，不能作为语义准确性的证明。
- 翻译原文附带相邻原编号间至少3秒的真实静音提示，提醒模型不要把前句残词续写到后句。该元信息不作为台词输出；稀疏补行时不把省略的中间台词误标静音。容量规划包括实际提示成本，不额外请求审核或原文回显，仍尽量一次全文调用。
- 新增 `split.thinking_mode` 与 `translate.thinking_mode`：默认 `low`，也可 `follow_profile`。只在已确认的官方火山方舟套餐 Chat 入口、`ark-code-latest` 上请求 `reasoning_effort=low`，不修改全局模型配置。不认识的供应商保留参数，仅用简短提示引导。旧 `fast` 作为兼容别名，与 `low` 的请求、缓存和输入指纹一致；界面直接使用低思考强度名称。
- 不能把 Claude Code/Messages 文档的 `thinking.type=disabled` 跨协议套用到 Chat：实际请求被当前 Chat 入口 HTTP 400 拒绝。因此不发送该字段，不宣称关闭思考或保证固定耗时。`low` 是否缩短内部推理仍取决于路由的底层模型。
- 更新语义整理独立规则版本与翻译请求策略版本；旧整理分窗设置从界面移除且不参与全文整理指纹。低思考模式覆盖掉的全局思考强度也不参与其有效输入变化。下载、分离和原始识别不因这次文字请求策略变更失效。
- 仅凭冠词、介词、连接词等字面结尾，不能证明整段口语错误。这类疑似接续保留为有界中文复核提示；有声学证据的极短碎片、明显密度异常、时间重叠与不可证明的长静音切口仍检查。可在同有声区及长度、时长约束内安全归并的极短片段优先本地处理，保留全部文字。
- 模型模式的最终长度、时长兜底沿用同一软上限，不能在超过软上限后突然改回原严格目标，重新把模型从句机械切碎。普通规则模式保持严格目标。该规则独立更新语义整理版本。
- 对全部具备可靠两端词锚点的候选使用全文单调映射校正时间，不仅校正长静音附近的片段。两端必须精确映射且位于源词边界；纠错区内部、新增词或零时长的不可靠位置不按比例猜时间。不扩大全文字符diff上限，也不以识别词替换候选文字。

## 验证与限制

验证过程与实测数据见 [全文整理验证记录](../research/full-semantic-editing-2026-10-07.md)。确定性检查仍不能证明 ASR、纠错或每条语义完全忠实，否定等存在疑问时需要原声核对。全文必须在模型真实上下文容量内；提示词中的轻量检查要求与低思考档位不是硬性的耗时保证。
