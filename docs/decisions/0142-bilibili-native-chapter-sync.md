# ADR-0142：B站原生章节按网页协议同步

日期：2026-10-13。状态：采用。

## 决策

章节同步使用 B 站创作中心当前播放器编辑器调用的契约：`viewpoint/rule` 读取实时规则，`allcards` 读取当前分P章节，`card/submit` 以 `type=2`、`cards` JSON 和 `permanent` 提交。章节按 `aid + cid` 绑定，不能把一个 BV 的多个分P合并成一套时间轴。

DubForge 在发送前冻结账号归属、规则、现有卡片和指纹，生成服务端预览；用户确认后只发送一次 POST，写后立即回读并比较规范化章节。网络中断、回读失败或结果不明都进入待核对状态，不自动重发。B站审核或播放器展示延迟只通过状态提示和重新读取处理。

YouTube 章节先保存在发布草稿的独立章节选项中，可选翻译标题；不会改变制作产物或项目配置。完整原声/配音版可沿用原时间轴，剪辑、变速或加片头的分P必须重新核对时间。平台规则（数量、时长、标题长度和间隔）以实时响应为准，预检失败时保留本地章节供调整或复制。
