# ADR 0019：当前参数、兼容预设与可选环境

## 决策

配音页已保存的项目参数是逐句及批量合成的唯一参数来源。预设只用于填充草稿或记录当前表单，不存在按预设名称动态覆盖合成参数的第二条路径。替代旧的全局预设应用 API，预设转换与文件读写集中在领域模块，API 不直接修改配置。

沿用 IndexTTS WebUI v1.0 的目录及 JSON 格式，情感编号严格为同音色 0、参考音频 1、向量 2、文本 3。八维向量、文本情感与全部已支持的高级合成参数进入统一 schema，项目表单和全局设置复用控件和说明。

共享预设保存固定参考音频副本与相对路径，先原子写新音频，最后原子替换 JSON。覆盖保留旧音频，避免另一界面仍持有旧引用时文件消失。语言、时长系数与 DubForge 参考方式由扩展字段保留；不宣称原生 WebUI 能恢复这些扩展。视频切片参考规则只允许保存到 DubForge 本地预设库。

识别、分离依赖拆成可选 extras；基础程序不强制安装本地 ML 依赖。统一安装脚本采用锁文件并保留已有组件；设置页只做检测和显示安装命令，安装由用户在程序关闭后执行。TTS 始终维持独立环境，提供官方安装入口、已有目录和远程地址，不捆绑模型或自动更新外部项目。

这是 ADR 0018 中“预设在设置页维护”的调整：项目页现在可读写预设库，但仍不通过预设操作修改全局默认。沿用 ADR 0001 的外部模型运行时边界。
