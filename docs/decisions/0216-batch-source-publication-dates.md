# 批量检查自动补齐原视频发布日期

日期：2026-10-20。状态：采用。

新项目创建只获取标题，尚无平台日期，原先对每个缺日期的合集都提示排序，导致单项目合集也要求核对。批量操作应在检查阶段补齐资料，减少逐项目操作。

- 新建批次的首次检查与用户主动重新检查，通过 `POST /api/project-batches/candidates` 补齐缺失日期；原有 GET、制作预检、列表轮询、手动调序和已有批次恢复均不触发采集。
- 只采集平台资料，不下载视频、评论或调用 AI。已有真实日期直接复用；失败、本地来源和占用中的项目保持未知，不阻断运行。提取并发和总耗时有上限，同项目并发检查合并。
- 日期来自平台上传日期、发布日期或时间戳，时间戳按 UTC 换算；绝不用项目创建或导入时间替代。保存只补来源日期，原有文案、概要、评论、步骤状态和媒体保留。
- 首次检查用补齐后的日期建立初始顺序；重新检查保留用户调整的顺序。已确认批次继续使用原计划，不因补齐日期自动重排。
- 仅相同账号、合集和小节内本批有多个项目且仍缺日期时，就地提醒核对顺序；独立项目和单项目合集不显示排序警告。
