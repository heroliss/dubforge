# 0102：在定稿行内自然翻译

日期：2026-10-07

## 背景

语义整理负责识别纠错与组合，翻译消费定稿原文。旧翻译引导多次重复保真禁令，功能词的机械例子容易掩盖正常句式调整的空间；恢复校对的“不能直接照抄”也可能诱导无错改写。系统要求译文结束立即停止，与非末窗口必须附交接摘要存在措辞冲突。

## 决策

- 编号、行数、顺序和时间对应沿用定稿；翻译不重新做转录纠错，不跨编号增删或搬运信息。
- 在本行含义内自由调整语序、句式和惯用表达，允许自然本地化，不要求逐词直译。事实、数字、币种、单位、否定、程度和比较关系仍保真；风格不能凭空增加事实、笑点或评价。
- 上下文用于理解指代、语气与术语。未说完或不确定的含义按原有范围译出，不借邻句补齐缺失内容；功能词按目标语言处理，专名和字母按实际含义保留。
- 共用系统提示说明语义要求，窗口只强调编号范围、参考内容与协议；去掉恢复小窗重复追加的同一引导。缺行只补指定编号，不改已采用译文。
- 校对有错修正、无错保留。最终输出的停止点包括请求要求的交接内容，避免与窗口协议冲突。
- 分窗以完整请求的 token 预算为第一边界；默认再限制每个窗口最多 100 条字幕行，防止大上下文服务商下的单次响应过慢。行数上限只在字幕行之间生效，设为 0 时关闭，仅按 token 自适应分窗。
- 翻译规则版本升为 `final-source-natural-line-alignment-v14`。语义整理版本及原文不受本次规则调整影响，译文缓存通过提示版本和系统摘要失效。

## 验证

默认基础系统提示从 908 字符降为 498 字符，共用语义引导从 727 字符降为 286 字符。274 项相关回归通过，覆盖请求约定、原文及时间不变、行内换序、本地化、校对保留、缺行补齐、缓存和上下文预算。

测试中的模型输出全部为本地桩，只证明程序与请求契约；实际自然度及逐句准确度仍需观察真实翻译。没有新增内容启发式硬校验、模型调用或配置项。
