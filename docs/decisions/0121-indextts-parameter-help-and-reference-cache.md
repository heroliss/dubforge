# ADR-0121：IndexTTS 参数说明与参考切片复用

状态：已采纳。日期：2026-10-08。

## 问题

IndexTTS 的情感权重、随机情感与生成采样属于不同控制层。沿用同一参考时，权重没有可混合的情感差异；关闭生成采样时，温度、top_p、top_k 不参与生成。原界面仍允许调节这些项，且“均衡／速度”快捷方案会修改用户已经选好的情感与时长。参考切片按整句合成指纹存放，还让同一段原声因句子、合成参数或音色／情感角色不同而重复切片。

## 决策

- 按用户要求移除均衡与速度快捷方案及其接口元数据，保留音色文件预设。推荐起点、适用条件和误区放在参数说明中，不自动修改已保存配置。
- 所有通用设置表单共享悬停说明组件，支持延迟悬停、说明按钮、键盘聚焦和 Escape。弹层不占表单布局；项目和句级表单也使用同一帮助语义。
- IndexTTS 参数说明区分官方默认与工程试听建议。仅在当前模式下无效的控件禁用，原值保留，切回适用模式后继续使用。说明依据当前表单草稿，不依赖后台轮询。
- 情感权重按模式解释：同音色沿用参考情感，独立音频在两种情感间混合，向量／文本缩放额外情感。同内容双参考没有可混合的差异；0 也不代表消除参考本身的情感。
- 参考切片缓存独立于合成指纹，以原声绝对路径、文件版本信息、实际起止范围和输出格式绑定输入，核对输入标记与有效音频帧后复用。稳定开头跨句复用，相同音色与情感范围共用本地文件。
- 切片使用独占临时文件，再原子替换音频和输入标记；写标记失败时下次重新切片。切片期间原声变化则拒绝保存。参考仍严格遵守用户选择，不自动扩展短句或替换说话人。
- 合成请求仅在音频情感模式上传情感文件，向量、文本和同音色模式不上传遗留的无效参考。
- 保留现有句级合成指纹与历史产物，新增帮助和切片复用不触发批量重合成。参考复用减少本地切片，尚不承诺 Gradio 双输入上传去重。

## 外部服务修复

本机 IndexTTS v2/v2.5 将 `do_sample` 读取后硬编码为 True，按照官方 PR #768 仅修正两处参数透传；不升级整个外部仓库或覆盖定制。修复需在配音空闲时重启 IndexTTS 才能载入。关闭 GPT 采样不承诺整个声学生成链完全确定。

## 验证

使用隔离 pytest 验证参考复用、原声／时间变化失效、短句原声、坏缓存恢复、并发原子写、情感模式与参数透传。前端验证说明交互、模式切换保留值、草稿与运行锁、移除快捷方案。外部仓库以不加载模型的回归测试验证两条推理路径真实转发采样开关。
