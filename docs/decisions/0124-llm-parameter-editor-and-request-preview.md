# 0124 — 大模型常用参数与实际请求预览

日期：2026-10-08

状态：参数说明与选项的模型专属策略由 [0125 — 通用大模型参数说明](0125-generic-llm-parameter-guidance.md) 替代；请求构造、预览和运行适配继续有效。

## 背景

模型设置原先只提供一份自定义 JSON，默认值、模型推荐值和步骤覆盖混在说明中。用户难以知道哪些字段没有发送，或语义整理/翻译的低思考模式是否会覆盖配置。JSON 数组、null 和单值还会通过前端语法检查，产生无意义的测试或运行错误。

GLM-5.3-Flash 官方推荐温度 1、top_p 0.95、思考强度 max；思考开关仅支持 enabled。跨轮思考保留和工具流式输出各有适用条件，不能把整套模型推荐值默认写入单轮字幕任务。

## 决策

- 常用控件与高级 JSON 共用同一份草稿；清空数值或选择“不指定”删除对应字段，保留其他字段和嵌套扩展。不能解析的 JSON、无法用控件表示的类型或已有自定义枚举值都保留，显示问题供用户修正，不默默丢弃。
- 参数说明分别列出功能、已确认模型的官方默认值、推荐值及限制。模型别名或未知接口不推断底层模型，不能把 GLM 推荐套用到其他服务。已知 GLM 数值超出官方范围时只提示，不自动夹紧原值。max_tokens 是输出上限，不等于实际 token 消耗；较高思考强度通常增加等待与推理量。
- `thinking.clear_thinking` 是跨轮思考保留设置，依赖回传历史 reasoning_content。`tool_stream` 用于工具调用；字幕整理与翻译没有工具调用，不因推荐列表而自动启用。原配置不自动填推荐值。
- 请求预览通过只读 API 复用领域内实际请求构造和传输参数规则，不联网、不使用密钥、不保存配置。模型配置原值及语义整理/翻译模式分别可预览；步骤模式以当前全局参数为示例，明确项目覆盖、真实提示词和重试会改变实际请求。
- 预览使用占位消息，敏感键和凭据脱敏，展示最终首请求 JSON、已生效的覆盖与说明。折叠时不请求，展开后按草稿变化防抖；取消旧请求及校验代次，迟到响应不能覆盖新草稿的预览。请求和正文读取总计超过 10 秒即显示可重试提示。错误保留草稿，旧预览不冒充当前值。
- DubForge 未指定 stream 时仍默认尝试流式，区别于服务商未指定时的默认值。显式 stream=false 应生效；非流式请求不携带仅流式使用的附属字段。服务商明确拒绝流式时，回退不能再次发送 stream=true。
- 已确认的 GLM-5.3/Flash/FlashX 官方标准接口可在文本步骤使用 low，仅改本次请求的 reasoning_effort，保留 thinking 子项。Ark 已确认路线继续移除其不兼容的 thinking。GLM-4.7 和未知代理不推断支持 reasoning_effort；跟随配置时保持原参数。
- 保存、连通测试和请求预览要求参数为 JSON 对象；保留厂家扩展项。参数错误必须在真实网络请求前说明，页面保留未应用草稿及现有运行中编辑锁。
