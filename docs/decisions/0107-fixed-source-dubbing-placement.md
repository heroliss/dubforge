# ADR-0107：以源时间和实际音频统一配音排布

状态：已采纳。日期：2026-10-07。

## 问题

配音工作台已能显示实际时长，但提示只比较下一句字幕起点，无法区分字幕目标超时、实际人声重叠和视频末尾越界。合成直接按视频长度裁剪最后一段声音，而工作台单句试听会保留尾音；用户可能听到完整配音，却在最终成片中丢失句尾。

YouDub 的实际音频排布可作参考，但延后后续台词会累积偏离原画面，不能直接用于本项目。

## 决策

- 新增纯领域排布函数，固定每句源起点，使用实际选中的配音版本时长；原声使用所选源区间，空位不产生声音。未知时长保持未知，不以字幕时长替代。
- 同一个计划区分字幕目标超时、相邻人声实际重叠、视频结尾越界。字幕目标仍是软提示，合法的视频片尾空档可以承接完整尾音。
- 工作台返回计划和输入签名，包含句子时间、声源、版本、实际时长和媒体版本地址。前端仅在签名及视频时长匹配时使用服务端检查结果；未完成保存的乐观声源切换和版本变化临时重算，避免旧响应覆盖新选择。
- 正式铺轨与区域试合成都读取该领域计划。相邻重叠保留现有混音行为，并明确显示冲突；不悄悄裁掉台词、不累计顺延、不另行自动变速。
- 正式合成在实际人声超出真实视频结尾超过 50 毫秒时明确失败，保留已有声音和成品。先用已有模型缩时重试、译文调整或逐句声源选择解决。音频时长无法读取也明确失败，不能静默变成空位。
- 明确选定的试片区域允许裁剪边界。区域边界不当作全视频边界；视频时长未知时不以最后一条字幕猜测。媒体探测有界等待，工作台按源文件大小和修改时间缓存探测结果，避免轮询重复启动 ffprobe。
- 本轮改变检查及诊断，不修改正常音频的速度与位置，也不递增所有合成输入指纹；已有成片不因新增提示统一变为过期。

## 验证

领域测试覆盖完整尾音、原声与空位、多个相邻冲突、字幕结束与视频结束的差异、50 毫秒容差、未知视频时长和合法区域裁剪。集成测试检查工作台与真实铺轨的选中版本、实际时长和问题一致，并验证视频越界及不可读音频不覆盖旧音轨。前端测试检查三类提示、签名过期、乐观修改和实际视频时长变化。

## 边界

同一时间附近的重叠人声可能是有意的对白，本轮只提示，不以统一阈值阻止全部重叠。波形中真实讲话结束仍需试听；音频容器时长不证明内容完整，也不保证模型没有漏词。
