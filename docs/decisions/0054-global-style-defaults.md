# 0054：全局文字样式与 IndexTTS 参数建议

日期：2026-09-28

## 边界

- 普通步骤参数仍由 `STEP_PARAM_SCHEMA` 单一定义，全局、项目、逐句按既有覆盖规则解析。新增回归测试验证全局和项目字段一致。
- 全局字幕、评论使用同一套 16 款配色选择器。预设仅填入文字色与描边色，不隐式保存或改变粗细、底色等参数。
- 评论的 `comments.overlay` 是新方案起点，不是流水线步骤配置，不计入既有成品指纹。已确认评论（含缺省字段的历史记录）使用原有快照/历史出厂值。
- 尚未保存的全流程建议方案取当前全局评论默认；已保存的全局/项目全流程配方继续使用自身完整快照。运行方案不随全局编辑漂移。
- 新增参数同步 DEFAULTS、配置模板、本机配置；本机新增段保持原来的白字黑描边，不改已有 TTS、密钥或项目覆盖。
- 保存全局步骤设置仅提交变化字段。评论节奏、类型、颜色及范围在写入前校验；失败不部分写入。

## 项目设置对照结果

| 设置 | 全局入口 / 处理 |
| --- | --- |
| 下载、分离、转录、分句、翻译、字幕、配音、合成及超时 | 原有共享 schema，均可设置 |
| 字幕配色预设 | 补全，保留单项色值编辑 |
| 评论语言、位置、字号、边距、节奏、作者、描边及底色 | 新增全局默认；不改已确认方案 |
| IndexTTS 音色预设库 | 补全全局载入/保存入口，明确预设文件与应用参数的区别 |
| 成品组合、P1/P2 顺序、自动评论数量/提示词 | 项目总览 → 全流程方案 → 保存为全局默认；不另造一套配置 |
| 发布账号、合集、声明、可见性、标签等 | 发布中心 → 默认设置与合集模板；保留账号/合集模板覆盖层级 |
| 源视频、选中评论、字幕逐句修改、逐句音色/时轴、实际封面、发布回执 | 内容或项目状态，不复制为全局参数 |
| 原来的选中步骤勾选 | 项目运行选择；全自动生产改由全流程方案的终点和版本组合决定 |

## IndexTTS 2.5 核对

核对本机 `D:/Program Files/index-tts`（官方仓库来源，HEAD `ee40fa7`）的 `webui.py`、`indextts/infer_v2_5.py`，同时检索官方当前代码。

- 均衡采样：do_sample=true、top_p=0.8、top_k=30、temperature=0.8、num_beams=3、length_penalty=0、repetition_penalty=10、max_mel_tokens=1500、每段文本 token=120。与现有出厂参数一致，保留。
- 时长因子从 1 开始；它影响模型预测时长，不是精确对齐保证。保留现有超长重试策略，不把激进缩短音频称为提速优化。
- 推荐填入参考情感权重 0.65；若当前是文本情感则填 0.6。关闭情感随机不等于整个推理完全确定性，普通采样仍开启。
- 速度优先仅将 num_beams 设为 1，减少搜索开销；没有运行本机音质/性能基准，不能承诺固定提速倍数或音质不变。
- 不自动修改现有配置。推荐按钮只填草稿；音色、情感模式、参考文件、语言、服务连接和重试策略不变。先试听再保存/批量配音。
- 固定清晰单人音色参考更适合一致旁白；逐句原声适合需要保留角色变化的素材，但短句、噪声和多说话人会增加不稳定性，不为所有视频强制同一模式。
- 不擅自开启依赖特定环境的加速库或 QwenEmotion，不重启用户运行中的 TTS 服务。
