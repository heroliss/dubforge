# 0105：明确采用项目翻译背景

日期：2026-10-07。状态：采用。

## 背景

项目已经缓存平台标题、简介和中文概要，但翻译主要消费定稿字幕和全局术语表。直接让翻译追随平台资料文件，会令浏览量变化、资料刷新或概要重生成意外改变制作要求；每次翻译再请求摘要则增加延迟和费用。

## 决策

- 在翻译页展示可编辑的标题、作者、简介、已有摘要和项目术语。首次显示已有资料的未启用草稿；用户保存并启用后才进入翻译。
- “填入最新资料”只重新读取缓存，保留手工术语，并更新未保存草稿；不联网、不调用模型、不隐式采用过期概要。需要重新获取资料或生成概要时使用既有获取视频页面。
- 已保存背景保存在项目参数，随项目恢复清单备份；字段和长度受约束，保存检查读取版本，运行期间沿用设置编辑门禁。
- 离开页面和同一路由内切换项目或步骤共用草稿确认，只显示一次；同页 query/hash 变化保留草稿，不拦截。
- 翻译系统提示将背景作为引用参考，用于指代与称谓；冲突以定稿原文为准，不在翻译阶段重新纠错、补入台词或改变行对应。全文优先翻译策略保持。
- 只将启用且非空的字段摘要加入正式制作指纹与窗口缓存。旧配置及旧依赖表示的兼容指纹也必须计入新采用背景，防止旧译文被误升级为有效结果。禁用编辑及缓存元数据刷新不使已有译文过期；本轮运行使用冻结项目快照。
- 更新说明按背景字段展示变化和内容摘要，不保存自由文本正文；背景只影响翻译及实际消费其结果的下游，不使识别和语义整理过期。

## 验证

隔离测试覆盖缓存复用、无额外模型请求、保存及清单备份、字段约束、运行锁、并发版本冲突、冻结快照、逐字段更新说明和脱敏。翻译请求使用离线模型桩，验证全文一次输入与原文、编号、时间不变；前端验证草稿展示、填充、放弃、运行禁用、重复保存保护和失败保留草稿。实际翻译质量仍需同素材评估。
