# ADR-0037：评论精选、人工确认与显式视频叠加

日期：2026-09-27。扩展 ADR-0036，沿用 ADR-0033 的显式操作范围与 ADR-0026 的共享渲染原则。

## 决策

1. 平台原文仍属于 `video_info.json`；译文、筛选建议和人工确认方案保存到项目根目录的
   `comment_studio.json`。这是用户文档，不是合成步骤产物，重跑或重新抓评论不能删除它。
   文档采用临时文件原子替换，失败保留旧内容；领域库不依赖 Web 框架。
2. 翻译显式调用现有 LLM，按最多 10 条 / 6000 字分批，逐批保存并校验完整 ID 集合。
   译文绑定来源 URL、评论 ID、原文和作者指纹；再次翻译只补缺失项，取消或失败保留成功批次。
   单条超过 12000 字拒绝处理，不静默截断。任务最多运行 30 分钟，可查询进度与按任务 ID 停止。
3. AI 筛选接收用户提示词，返回已知评论 ID、中文理由和相关度，不改写原文，不自动勾选。
   最多建议 50 条；跨批次相关度只是模型建议，不宣称绝对排名。采样变化使建议过期。
   平台文本作为不可信资料引用，不能成为指令；未知、重复或遗漏 ID 的结果不落盘。
4. 用户明确勾选、排序、核对上屏文字（每条 1–240 字，最多 100 条），再确认方案。
   原文、作者、来源由服务端核对，客户端不能替换来源身份。旧已确认评论即使不在新采样中也保留。
   文档修订哈希防止多页面覆盖；页面轮询不得覆盖本地草稿，离开未确认草稿时才提示。
5. 正式成品和短片试合成都必须独立勾选“叠加已确认评论”，初始关闭。
   提交携带确认方案修订号，执行器在入队时复制方案到任务数据，后续编辑不改变在途任务。
   评论版使用独立文件名及输入指纹，不将无评论的流程默认版误判为最新，不触发自动续跑。
6. 新增“原声 · 仅叠加评论”方案，只依赖源视频，不需要配音、背景分离或对话字幕。
   已有配音与烧录组合也可叠加评论；不启用评论时保持旧工作流。
7. 默认第 5 秒开始、每 15 秒一条、停留 6 秒、顶部显示。停留不能长于间隔。
   单帧预览和成片共用 ASS 渲染器，短片按原视频时间轴裁剪、平移；字幕和评论按顺序叠加。
   屏幕按 1080 高归一化，自动换行、必要时缩小字号；无法容纳时明确报错，不截断文本。
   ASS 特殊指令字符转为可读普通字符。超出视频结尾的条目不显示，首次出现超过结尾则报错。

## 界面

视频资料区直接显示平台封面、主标题与次要层级的原文标题。正文与辅助元数据分层，功能说明
移到悬停提示，错误与过期状态仍直接显示；简介可展开查看，章节、语言和统计默认折叠。
评论优先显示已有中文译文，可一键对照原文。AI 筛选折叠，不干扰阅读；勾选后在独立的待上屏区
核对文字、顺序、间隔和位置，预览只是临时画面，确认保存也不会自动合成。

## 验证与边界

- pytest 使用隔离目录与假 LLM：完整性、部分成功/续译、取消、指纹失效、旧快照保留、修订冲突、
  禁止自动合成、入队快照、参数边界、ASS 转义和时间裁剪；真实 FFmpeg 验证原声评论版、
  配音版、字幕叠加与短片预览，不访问用户的视频或外部平台。
- Vue/Naive UI 实际组件测试覆盖中文优先、原文转义、建议不自动勾选、勾选顺序、保存确认、
  超长评论、并发读取和离开保护；无真实接口调用。
- LLM 译文与建议可能有误，用户应核对原文；不会自动投稿、发布、点赞或回复评论。
- 评论独立预览只展示源视频与评论，不声称同时预览配音与对话字幕；完整效果使用短片试合成。
- 热门顺序来自平台采样，不代表全部观众意见。默认不显示作者昵称，可按需开启。
- 本次未做真实 YouTube/LLM 付费调用；浏览器连接失败时不能宣称完成截图视觉验收。
