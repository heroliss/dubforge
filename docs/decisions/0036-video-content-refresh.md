# ADR-0036：视频内容资料独立刷新与可选评论快照

日期：2026-09-27。扩展 ADR-0030，不改变 ADR-0016 的实际媒体依赖。

## 问题与范围

视频内容资料原先只随下载采集：普通运行复用旧资料，强制运行又重新下载并使下游过期。
字段集中在标题和简介，缺少章节、主题标签、字幕语言和独立刷新入口。
用户还提出可选收集指定数量的热门评论，以及未来通过 LLM 筛选、在画面顶部轮播。
本次实现资料刷新与评论采集；评论筛选和视频叠加尚不在合成链中实现。

后续实现状态：评论翻译、筛选、人工确认与视频叠加已由 ADR-0037 扩展；以下保留本阶段的历史边界。

## 决策

1. `dubforge/video_info.py` 统一平台字段白名单、规范化、AI 概要、资料更新与并发保护。
   下载步骤复用相同构造器，保留原来的下载后自动整理；API 不调用下载运行入口。
   不建立只有一个实现的抽象平台插件层：yt-dlp 自身已有站点提取器，优先验证 YouTube。
2. 三种操作明确分离：`refresh` 仅提取平台资料；`summarize` 调用 LLM；`comments` 明确抓取评论。
   只保存/登记 `artifacts/download/video_info.json`，不更新项目名称、步骤状态、输入指纹或下游产物。
   刷新可用于尚无资料的旧项目，也不要求视频已下载。本地项目明确禁用平台操作。
   旧版“全部上游产物”指纹兼容计算排除后来新增的 `download/video_info.json`，避免资料补采或刷新
   导致音轨分离、识别及后续步骤连锁过期。其余历史输入和配置仍严格校验，不重写已保存指纹、
   不重跑或删除产物；新指纹继续只使用实际制作依赖。评论上屏方案单独保存，不参与制作步骤指纹，
   新评论成片按提交时确认的方案快照生成，历史成片不变。
3. 标题、完整简介、作者/频道、日期、互动统计、分类标签、章节、字幕语言/格式、封面链接、
   许可/访问范围/直播状态、可用的音乐和分集资料均白名单保存；不落盘媒体直链、字幕签名 URL、
   请求头或 Cookie。字段缺失与数值 0 区分，不推测平台未提供的内容。
4. 元数据子进程使用 `--ignore-config --simulate --skip-download --no-playlist`，限制播放列表为一项并拒绝列表结果；
   不受用户 yt-dlp 全局配置影响，不读写下载归档、不下载媒体。复用项目/全局下载代理与 Cookie。
   资料获取最多 90 秒，评论最多 180 秒，失败保留旧文件。前端请求期间禁重复提交，离开再进入可读后台占用状态。
5. 评论默认不抓正文；独立按钮可指定 1–500 条 YouTube 顶层热门评论，不含回复；保留 ID、作者、原文、
   点赞数、时间、置顶标记、原评论链接和采集时间。按平台返回的热门顺序，不宣称全站最高赞。
   `yt-dlp` 的评论后处理会用已获取条数覆盖 `comment_count`；评论操作因此保留此前纯资料采集的
   平台评论总数，没有旧统计时显示未知，绝不把样本条数当总数。评论关闭/不可用不覆盖旧评论。
6. 原始资料与 AI 输出分开显示。概要仅依据标题、简介（最多 12000 字）、章节（最多 100 条）、
   标签（最多 50 条）和分类；不把评论或平台说明当指令，不声称阅读了整段视频/字幕正文。
   概要绑定内容证据指纹：仅统计变化不使其过期，内容变化保留旧概要并提醒重新整理。
7. 同项目刷新互斥，刷新期间阻止重新下载和删除项目；下载运行/收尾期间拒绝刷新。
   网络等待不持有全局锁，不阻塞其他项目；不占用流水线步骤或触发自动续跑。
   独占临时文件原子替换；登记失败恢复旧文件；更新项目备份索引。

## 界面

获取视频页独立的“视频内容资料”区块始终可见，不依赖视频预览是否可用。
资料刷新、概要生成、热门评论各有清楚的作用范围；原文与统计分区、章节与字幕语言折叠，
长简介、标签、评论各自限高滚动。平台外链仅允许 HTTP/HTTPS，外部文本按普通文本转义。
字幕语言只是可用清单，不替换已有字幕。评论只查看/复制，未经用户确认不进入成片。

## 验证与已知边界

- 隔离 pytest：真实 API、无下载/无 LLM 副作用、指纹/状态不变、故障保旧、摘要过期判断、
  规范化、敏感字段排除、评论限量/去重/总数分离、并发重复与下载/删除保护、原子写与登记回滚。
- 新旧指纹回归覆盖完整制作链的动态 `fresh` 与依赖状态：首次补采、重复刷新、概要、评论采集和
  上屏方案修改均不使制作步骤过期；源视频、音轨或处理参数变化仍须失效，未知指纹不能被误接受。
- 实际安装的 yt-dlp 解析参数/JSON 投影模板，离线测试不访问用户的 YouTube 项目。
- Vue/Naive UI 实际组件渲染及操作测试：旧项目入口、按钮范围、精确条数、错误保旧与重复点击。
- 站点登录、地区限制、Cookie、YouTube 动态规则等仍可能导致缺失或失败；不绕过访问控制。
  评论采集上限不是能获取的数量保证。字幕正文下载、LLM 评论筛选和评论轮播图层另行设计。
