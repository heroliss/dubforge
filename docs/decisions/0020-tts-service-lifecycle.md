# ADR 0020：后台配音服务的生命周期

网页快捷启动保持后台运行，标准输出和错误写入日志；提供日志查看和停止入口。关闭网页或退出主程序不自动关闭模型服务，避免影响其他项目和 IndexTTS WebUI。

只停止由 DubForge 管理的进程树。启动后原子保存 PID、创建时间、可执行文件和命令行；重启时逐项核验才恢复管理，避免 PID 复用后误杀其他进程。停止时包括 Windows 虚拟环境 Python 启动器创建的子进程。其他工具启动的服务不按端口自动接管。

逐句与批量配音共用服务占用计数；批量任务在句间和暂停期间继续占用服务。不同项目只要使用同一服务，任何一个项目正在配音时都不能关闭该服务。运行保护不涉及合成参数，也不影响音频缓存指纹。

日志接口固定读取当前后端与端口对应的日志，不接受任意路径；一次最多返回末尾 64 KB，只有打开日志窗口时才轮询。进程管理依赖轻量 psutil，不依赖可选模型环境。

主控制台通过 `/api/services` 管理同一套服务，枚举全局配置、项目覆盖和仍运行的已登记服务，不另起 Python 管理实例绕过运行中的占用计数。StartDev 退出按进程身份结束自己的前后端，明确排除已登记的配音进程及子树，替换会连带杀掉配音服务的 `taskkill /T`。前后端日志按端口隔离、重启归档；启动阶段及等待过程持续反馈，异常带出最近日志。
