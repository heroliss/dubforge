# 0025 — IndexTTS 超长音频按因子重试

2026-10-07：关于将实际因子写回本句设置的决策已由 [ADR-0112](0112-temporary-duration-factor.md) 取代；自动缩时仅使用本次临时参数。

## 决策

- 新增 IndexTTS 专用 `duration_retry_factors` 文本设置，默认 `0.7, 0.5`，留空关闭。沿用本句、步骤、全局的逐项覆盖和校验；范围与 IndexTTS 时长因子一致，为 0.5～2。
- 这里的超长指音频越过下一句开始时间，末句则超过自身结束时间；允许使用句间空隙，忽略 50 毫秒计时误差。与 HTTP 超时、步骤超时、预估时长偏差容差无关。
- 先按当前实际生效的时长因子合成。仍偏长才按填写顺序重试，跳过大于或等于当前尝试因子的值，时长合适立即停止。单句、所选和补齐配音走同一实现；复用已有配音不会自动重做。
- 模型生成长度不保证单调；每次先生成临时音频并检查时长，再原子保留本轮最短结果。重试失败或收到停止请求时保留已生成的有效音频，不继续调用模型，也不裁剪语音。
- 重试策略本身不改变现有音频指纹。最终保留音频采用了较小因子时，自动写入本句独立设置并同步版本指纹，后续合成沿用；只修改这一句的时长因子，保留其他参数及步骤/全局设置。版本快照保存实际使用因子和尝试时长，界面显示重试状态与结果；新设置可写入兼容 IndexTTS 格式的 `dubforge` 预设扩展。
- 当前句按本次尝试显示真实进度，切换尝试重新平滑显示；总进度为可用尝试次数预留空间，无需继续重试时直接完成该句。旧尝试的迟到进度回调不得影响新尝试。

## 验证

覆盖空值关闭、逐级参数继承、跳过相等或较大因子、提前结束、末句和句间空隙、长度非单调、重试失败、暂停/取消衔接、临时文件清理、版本快照与缓存兼容。实际时长用生成的 WAV 验证，测试不调用真实模型。
