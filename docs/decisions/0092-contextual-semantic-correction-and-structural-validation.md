# ADR 0092：全文语义纠错与结构校验

日期：2026-10-07。状态：已采用。更新 ADR 0091 的内容保真门禁，继续采用全文输入与请求级 `low` 思考设置。

## 问题

ASR 文字是待纠正的识别结果。要求数字、币种、单位、否定表达完全不变，会把 `yen → yuan` 等合理候选直接拒绝；“不能凭常识推断”的提示也会迫使模型复述疑似错误。75%词形匹配及短段删词预算把文本差异当作语义错误，无法可靠区分识别纠正和错误改写。

长静音处还有同类误判：`would@0–1 / go@8–9` 整理为 `won't@0–1 / go@8–9`，已经完整保留实际空档，但旧映射因替换词相似度不足拒绝整稿。

## 决策

- 整理提示明确允许结合全文语境和常识主动纠正错词、漏词、人名、地名、数字、币种、单位、否定和程度。以还原谈话为目标，不要求逐词照抄或解释纠错依据，保持整体含义和内容先后，不概括整段或编造新情节。无法判断的表达可以保留。不对某个币种建立自动替换白名单。
- 数值、单位、否定等变化及普通局部改词、删词降为复核记录，附原词位置和前后内容。记录有界，不能证明候选语义正确。清理参考量只提示，大量精确重复与填充词清理不作为实质遗漏证据；整体明显大幅删稿、长台词搬移、重复抄写继续校验。
- 粗词形匹配不足只提示，不再以75%为通过门槛。明显遗漏检查统一由内容覆盖诊断处理，避免两套阈值再次冻结识别稿。
- 硬约束主要为连续编号、非空文字、有效递增时间、真实长静音与最终可用的分句。联合检查句尾与下一句开头，把 `the/a/I/and` 等归回正确短语；允许改变 ASR 行数。整理定稿与翻译保持相同句数、编号和时间，翻译消费本次纠错后的原文。
- 已经按真实声学区域分开并保留长空档的候选，不能因局部词形变化而被静音检查否决；保留模型文字与合法时间并提示复核。实际跨静音且不能可靠定位切口、明确移词到其他有声区域仍拒绝。
- 本地声学对齐与分句只改变时间、边界和空白，逐字符保留模型候选的纠错内容。校验先快照候选文字，再与最终文字比较，避免后处理意外改词或改数字。
- 仅提升语义规则版本至 `semantic-context-correction-structure-v6`，原下载、预处理和识别指纹不变。整理旧产物保留；重跑后内容变化再使相关下游需要更新。没有新增配置、额外审校模型调用或主动分段。

## 验证与限制

使用隔离数据根和模拟响应验证币种、数字、否定及专名纠正只请求一次、原识别产物不变、后处理保留模型文字。实际长静音、编号错位、明显删稿或搬移等负例仍覆盖；缓存命中也重新校验结构和最终结果。

真实任务 #282 的首轮原始响应以只读输入离线回放，448条ASR短语、2400个词级锚点、157条模型候选通过完整整理后处理，生成185句；候选全部字符和标点保留，仅允许英文合并处补空格，处理约0.14秒。也修正了同一静音侧的小幅时间错位被误认为跨区移词的问题。离线回放没有向模型请求或写入生产项目。

后端全量隔离回归2244项通过、1项因临时副本缺少工作进程依赖路径跳过；补齐路径后该项单独验证通过，累计2245项覆盖。全量耗时779.09秒，仅2条既有第三方弃用提示。前端427项测试和生产构建通过。应用的12个后端源码/测试文件与通过回归的副本逐文件核对哈希；当前自动流程按用户选择停止，已完成产物保留。

规则无法单凭文字确认 `yen → yuan` 是否正确，也无法确认每处漏词补全、实体或否定纠正的语义。保留原始 ASR 和纠错记录供校对，比机械冻结原词更符合本阶段职责。语音内容审核与发布屏蔽仍由独立审核阶段处理。
