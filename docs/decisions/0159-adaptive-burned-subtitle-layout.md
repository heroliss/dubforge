# 0159：烧录字幕先缩字号、再显式换行

## 状态

已采用。

## 背景

实际成片第一条双语字幕中，译文使用 80 号微软雅黑，连续中文溢出画面；同一条英文可在空格处换行。原稿中两种语言各自只有一行，英文的视觉换行不代表存在两条原句。此前原文独立样式使用 ASS，通用样式使用 SRT，两条烧录路径依赖渲染器的自动断词，不能稳定处理连续中文。

## 决策

所有正式烧录、成片试片与烧录单帧预览共用临时 ASS。语言身份继续由统一字幕文档的 `parts` 提供，不能从换行数量猜测；关闭内容筛查时，单语历史 SRT 可通过明确轨道类型恢复语言身份。

默认开启 `assemble.subtitle_auto_fit`。既有 `subtitle_size` 是通用字号上限，新增 `subtitle_min_size=32`；启用原文独立样式后，既有 `subtitle_source_size` 是原文上限，新增 `subtitle_source_min_size=28`。字号仍按 1080 高画布等比缩放；下限高于上限时取上限，避免放大旧项目小字号。

每条字幕的各语言部分独立估计显示宽度。`subtitle_shrink_width_percent=80` 是缩字软目标，`subtitle_wrap_width_percent=90` 是换行硬上限；均为完整画面宽度的百分比，范围为 10–100。超过软目标先缩小字号，达到字号下限后允许占用两阈值间的缓冲区，只有超过硬上限才显式换行。关闭自适应仅关闭缩字，仍遵守硬上限。人工换行保留，中英文优先在合法词边界折行，超长无空格词按字簇断行，保留常见组合重音、ZWJ 表情与国旗组合。不省略正文，不更改源字幕、导出 SRT、语义分句或配音时间。

使用轻量保守 Unicode 宽度估计，不增加字体库依赖或逐句外部测量进程。两个百分比直接乘完整画面宽度，不再乘此前固定的 94% 系数；仍遵守左右各 50 的画布边距，并为描边与底色预留空间。实际字体可能导致字号略保守，用户可用最小字号和两个宽度目标共同决定排版，并通过共用渲染的单帧预览确认。

配置沿用全局、模板、项目及成片版本覆盖。关闭自适应时禁用字号下限与缩小目标宽度但保留保存值；关闭原文独立样式时保留其备用范围。只让实际烧录字幕的成片消费这些设置，关闭自适应后不把无效下限和软目标计入成片指纹，不使翻译、配音或 SRT 导出失效。

启用自适应时要求软目标不大于硬上限。局部更新只校验提交字段的类型与范围，不用默认值猜测其他字段；在全局原子保存、项目/模板的有效配置、成片版本覆盖和预览草稿与项目合并后校验两者关系，失败保留旧配置。关闭自适应时允许保留暂未生效的逆序阈值，重新启用时再要求修正。

## 验证

使用实际第一句制作独立 8 秒小样，保留现有正式成片；对比自适应开启与关闭时的画面。回归用例覆盖连续中文、英文单词、超长标识符、字簇、两种语言的完整性与样式身份、剪辑时间、原文件保留、真实 FFmpeg 安全边距，以及配置保存与失效范围。
