# 0026 — 字幕样式与烧录效果预览

日期：2026-09-25

## 决策

- 字幕与配音页提供「烧录效果」入口，编辑 `assemble` 下的字体、字号、颜色、描边、底部距离、字幕类型和烧录开关。复用步骤参数表单及保存接口，项目覆盖优先于全局默认。
- 保留轻量的浏览器字幕连续预览，用于校对文字与时间。样式使用 FFmpeg 渲染指定时刻的单帧，和最终成片共用 `subtitle_style.subtitle_filter`，避免用 CSS 模拟成片产生字体和换行偏差。不为每次调样式编码整段视频。
- 样式按 1080 高的逻辑画布缩放，画布宽度按视频显示宽高比决定；考虑旋转与非方形像素。字体使用系统字体，缺失时由 libass 回退，用户可通过真实预览确认。
- 预览只读取已保存校对稿，临时样式不落工程配置；与导出共用 `build_tracks`，保持双语顺序、手动时间与最短显示时长一致。原文预览不需要翻译；所有预览不需要配音或预先导出。
- 正式成片仍依赖已导出的对应 SRT，已有依赖检查负责阻止使用缺失或过期文件。SRT 只保存文字和时间。开启烧录才重编码视频。
- 预览临时目录按请求隔离并自动清理；字体、颜色、尺寸在后端校验，避免把任意输入拼入滤镜。

## 同期简化

移除 `tts.tolerance` 的界面入口与使用说明，旧配置与内部任务字段兼容保留。实际超长判断和缩时重试继续比较真实音频时长与可用时间。

翻译初次请求和定向修复均传入逐句时长，时间纳入缓存指纹；语义整理提醒文字与真实时间相称。使用提示引导，不加入固定语言字速阈值、额外模型调用或强制截字。
