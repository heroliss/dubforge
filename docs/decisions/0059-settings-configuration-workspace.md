# 0059 设置页中的统一配置工作区

日期：2026-09-28

## 问题

设置页的「步骤默认参数」与独立系列模板页的「全局默认」写入同一配置范围，但表单覆盖不同：旧入口有音色预设与推荐参数，新入口才有成片版本和发布规则。两处入口容易被误认为两套默认值，字段维护也会分叉。

## 决定

- 侧栏只保留「设置」，默认进入「制作与发布」：全局默认与系列模板并列选取，统一由 ConfigurationForm 编辑，不保留另一份步骤默认表单及保存逻辑。
- 「模型与服务」管理模型连接池、密钥、请求超时及环境检测；「运行与存储」管理并行度、目录、显示偏好与耗时记录。这些本机设置不参与系列继承。
- 音色预设和 IndexTTS 推荐方案进入共享配置编辑器；只填入当前范围允许的字段，保存前不写配置。配色预设遵循同一边界。
- 分类与模板范围进入设置页 URL，支持项目快捷链接、刷新和前进后退。项目入口直接打开绑定模板，无模板则打开全局默认。
- 分类切换保留已打开的表单；模板范围切换和离开由设置页统一保护，避免多个弹窗。保存中禁止销毁编辑器。系统设置与制作设置分别按需加载，不相互阻塞。
- 删除独立模板页面；旧 /templates 地址仅重定向至统一入口，不含独立数据或旧版配置读写。

## 验证边界

覆盖分类草稿隔离、模板切换/离开保护、保存期间导航保护、共享预设填充及范围过滤；保留已有统一配置 API 的继承、修订与并发校验。

## 配置来源的统一视觉语言

- 来源由解析器返回结构化的 `sources` / `parent_sources`：类型与模板名称分离，不通过显示文字推断层级。步骤、句级参数、评论与成片清单沿用同一来源数据。
- 所有字段来源复用 `ConfigurationSourceBadge` 和唯一视觉词典：全局默认为蓝色、系列模板为紫色、项目设置为青绿色、版本设置为琥珀色、本句设置为粉色、稿件设置为橙色。视频资料及来源缺失的冻结快照使用中性色。
- 标识使用相同名称、字号、底色和间距；模板/版本具体名称放入悬停和无障碍说明。保留可读文字，不以颜色单独传达来源，也不把来源与未保存、告警状态混用。
- 编辑或恢复继承立即更新草稿来源，保存语义不变；恢复操作统一称为「恢复继承」，不再误称为恢复全局默认。
- 发布确认快照记录来源，后续模板改名不回写已冻结的历史来源；未记录来源的旧快照只展示「稿件快照」，不从当前配置倒推。
- 增加来源类别、跨界面相同色值、模板重名/改名、恢复继承、冻结快照和文字对比度测试。来源元数据不进入媒体内容指纹。
