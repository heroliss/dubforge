# 0192 · 句子修改与成片版本对照

日期：2026-10-17

## 决策

配音新鲜度与成片输入差异是两个独立状态。未重新合成的参数变化不等于成片已经换用新声音，不以编辑时间或“曾经修改”代替实际输入比较。恢复成相同内容时，差异应消失。

成功正式成片的版本快照附带逐句渲染输入，记录实际显示轨道的文字及区间、采用声音的登记身份、增益和播放区间，并保存全局呈现与音频处理上下文。快照随成功产物记录绑定；失败和试片不能更新正式基准。独立只读 API 按需比较，不把比较加入工作台高频轮询，也不反复哈希大媒体。

局部版本按真实修订范围继承基准输入，保留未知范围，不能在多次修订后把未知升级成完整已知。声音被整体保留时沿用基准音频上下文。全局样式、评论、审查或跨句均衡/归一化变化不能声称仅更新若干句便等于完整当前成片。

## 操作

句子列表提供具名成片基准、逐句差异标签、独立筛选和修订入口。未应用的配音变化继续使用原有生成确认；失效声音阻止自动建议把缺声写入配音成片，仍允许手动选择仅更新字幕。

跨页传递仅含本项目基准产物身份、句号及新旧时间范围，浏览器会话保存临时意图，路由使用请求令牌。成片页重新读取后端上下文，基准改变时拒绝套用；预填不自动创建、不保存、不运行。用户检查范围、添加独立版本、保存后，继续使用既有生成、自动流程和发布绑定。最大范围遵守局部修订现有约束。

筛选的阅读位置以句子 ID 加可见偏移记录，各筛选独立记忆；首次筛选取附近句子，空结果保留历史。识别应用真实的外层滚动容器，播放跟随、定位及用户滚动优先于异步位置恢复。

## 验证

领域测试覆盖轨道相关性、修改恢复、有效旧声音、失效声音、全局变化、快照缺失及多代局部继承；前端测试覆盖跨页身份与并发保护。独立 8611 数据目录验证长列表切换、空结果返回、预填、保存及正式局部生成，不触碰生产项目。
