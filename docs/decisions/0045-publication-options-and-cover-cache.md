# ADR-0045：发布选项自动加载与共享封面缓存

日期：2026-09-27。状态：采用。

## 问题与证据

发布页打开稿件、选择账号后原本只清空选项，没有自动读取；当前真实账号的只读接口正常返回 30 个新版分区、5 个声明选项和两个合集。声明仍标识平台枚举或组件适配表来源，不将适配表冒称为账号实时枚举。

平台资料封面原本直接通过浏览器加载远程图片，而发布导入每次由后端重新下载；浏览器缓存不等于后端已有文件。封面操作还复用了全页 busy，导致文字、开关一起置灰。

## 调整

- 发布页、账号默认、全局默认和合集模板根据当前有效账号自动读取选项。页面内缓存按账号隔离，有效期五分钟，手动刷新可重新读取；并发读取合并，过期响应不能覆盖新账号。读取不修改草稿、账号选择或制作状态。
- 选项读取有独立 loading/error。区分未选账号、加载中、读取失败、空合集；失败可重试，刷新失败仍可查看同账号上次成功的选项。选定只有一个小节的合集时填入唯一小节，多小节保持显式选择。
- YouTube 封面预览与发布导入复用同一后端 URL 缓存，来源 URL 改变使用新缓存；相同 URL 的封面暂不主动重新探测。发布封面仍按内容哈希固定，平台资料变化不修改已选稿件封面。
- 图片缓存固定锁合并并发读取，限制 HTTPS 主机、端口、图片格式和 10 MB 大小，禁止跟随重定向，沿用配置的下载代理，使用原子写入。首次加载仍可能等待网络；缓存后导入只读本地文件。
- 封面设置只锁封面操作及依赖它的保存/上传按钮，其他资料保持可编辑；失败保留旧图，可重试；迟到结果不能修改已切换的稿件。不自动保存、不上传、不投稿。

## 验证

后端 779 项、前端 168 项测试及生产构建通过。新增缓存复用、并发、来源变化、失败重试、安全边界、账号自动加载和隔离、封面局部等待与过期响应测试。真实项目只读/缓存接口实测：首次预览约 2271 ms，随后导入约 66 ms，再次导入约 13 ms；不是所有机器或网络的延迟保证。

未保存真实稿件，未上传或投稿，未启停常驻服务。浏览器自动化连接连续失败，真实页面点击验收未完成；组件渲染和交互通过测试验证。
