# ADR-0028：合成成片的区域试合成

日期：2026-09-26

## 决策

- 「合成成片」页提供源视频与试合成结果的并排预览；窄屏自动上下排列。区域选择只保留起点/终点数字输入，以及各自旁边的 ⏱ 按钮用于取当前播放时间。后端按视频原始时间轴校验 `0 ≤ start < end ≤ duration`，最短 0.2 秒。
- 试合成是 `assemble` 的临时任务，输出 `output/preview_时间戳.mp4` 与对应短人声轨。它复用正式成片的依赖检查、逐句声源、人声/背景音量、ducking、响度归一、字幕烧录和 CRF 设置，只处理与区域相交的句子和字幕。
- 为保证片段边界准确，试合成视频始终重新编码，避免流复制从关键帧开始造成画面与声音错位。烧录时生成临时平移后的 SRT，渲染完成即清理；正式成片仍使用原始 SRT。
- 试合成不删除旧正式产物、不续跑下游链，也不更新 `assemble` 的正式输入指纹。步骤最新性不能由 `preview_*` 临时产物决定；正式实现仍以非临时成片产物为准，只有试合成片段时显示需要更新，避免短片段被误当成完整成片。
- 试合成任务沿用步骤队列、进度、暂停、停止和强制结束保护。上游依赖缺失或过期时沿用「准备/更新依赖」提示，用户可先同步上游再试片。

## 验证

离线测试覆盖：区域任务生成约等于所选时长的 `preview_*.mp4`、不生成 `final_*.mp4`、不把 assemble 判为最新；区域 SRT 裁剪、平移和双语多行保留；既有完整合成与烧录路径回归。外部 TTS 在测试中继续使用桩替代。
