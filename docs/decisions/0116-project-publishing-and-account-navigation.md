# ADR-0116：项目发布入口与账号管理导航

状态：已采纳，2026-10-08。更新 ADR-0041、ADR-0043 的界面入口约定，保留其发布领域边界。

批量制作发布入口的后续流程见 [ADR-0127](0127-batch-production-before-ordered-publication.md)，记录列表的本地归档和草稿回收见 [ADR-0128](0128-publication-record-lifecycle.md)。

## 背景

项目已有第8步「发布到B站」，项目列表也已提供顺序发布。顶级「发布中心」再次提供单项目新稿入口，账号连接、原BV管理与本地发布记录混在同一页面，增加选择和切换成本。

## 决策

- 单项目准备视频、文案、确认投稿、进度、审核和历史记录统一从项目第8步进入；不再提供顶级发布菜单。
- 项目列表保留批量顺序发布，增加次级「全部发布记录」入口。该页面只读取本地资料，可按项目、状态、标题或BV查找；存活及归档项目的记录跳回项目发布页，并通过 `publication` 查询参数打开指定记录。
- 已删除或暂不可读取的项目仍有保留记录页，展示稿件快照、进度和回执，可核对平台状态或补充不确定投稿的回执；不从这里新建、复制或再次投稿。
- 设置增加「B站账号」。连接账号、检查登录状态及管理已有稿件集中于该分类。已有BV管理支持明确选择账号，继续使用原有文案编辑、分P和合集能力。
- `/publish` 旧链接跳转到全部记录；明确指向账号或已有BV管理的旧链接迁移到设置。保留必要上下文，导航不触发远程写入。

## 约束与影响

发布记录、冻结快照和远程状态继续独立于制作步骤。改变发布设置不使识别、翻译或成片过期，重跑制作也不创建重复稿件。所有原有上传、投稿确认和未知回执恢复约束保持生效。

账号检查仍为人工触发；已保存凭据与最近验证成功分别展示。目录变化、分类切换及慢响应不能恢复过时验证结果。扫码登录与已有稿件编辑保留忙态和未保存修改保护。

项目发布页减少账号管理和全项目选择的职责。跨项目记录暂沿用现有接口的最近200条范围，达到上限时明确标注；更长历史的分页属于后续独立改进。

验证覆盖导航兼容、指定记录归属、保留回执只读、账号异步检查、扫码登录、设置分类草稿守卫及既有发布流程。
