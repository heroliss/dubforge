# 0130 开发控制台管理前后端服务

## 状态

已接受

## 背景

开发启动器此前只在启动阶段创建前后端进程。某一侧异常退出后，用户只能退出整个控制台再重新启动，且控制台中的进程引用不会反映后续状态。后端还可能是用户已经运行的复用实例，不能被启动器误停。

## 决策

统一控制台维护一个本次启动的前后端状态，并提供以下命令：

- `status` 查看两侧进程和端口状态；
- `start backend|frontend|all` 启动缺失的一侧或两侧；
- `stop backend|frontend|all` 停止本次控制台创建的进程；
- `restart backend|frontend|all` 按安全顺序停止并重新启动；
- `quit` 结束控制台并清理本次创建的进程。

单独启动时只等待目标一侧就绪，避免另一侧停止导致无意义的超时。端口已被未知程序占用时不强制结束；复用的外部后端只读使用，停止或重启必须回到启动器选择是否结束旧实例。配音服务继续使用后端服务管理 API，和前后端进程命令区分开。

## 结果

前端异常退出后可以在同一控制台使用 `start frontend` 恢复；后端复用实例不会被 `stop all` 误杀。服务输出继续写入现有日志目录，`logs launcher` 可以查看启动、就绪和退出记录。
