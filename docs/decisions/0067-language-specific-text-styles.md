# 0067 — 原文与译文独立样式

日期：2026-09-29

## 决策

- 字幕和评论均提供“原文独立样式”。关闭时原文沿用现有译文/通用样式，不改变既有视觉效果；开启后分别设置字体、字号、文字颜色、描边颜色和粗细。背景盒、位置、边距与语言顺序仍为整块文字的公共设置。
- 配置沿用全局默认→系列模板→项目→成片版本的稀疏覆盖与来源标识，不引入另一套默认系统。原文的隐藏参数保留值；关闭开关不清空已有覆盖。配色选择器明确作用于译文或原文，只修改该语言的两种颜色。
- SRT 保持纯文字与时间，不夹入呈现指令。统一字幕文档为内存中的 `SubLine.parts` 提供带语言身份的正文分段，避免根据换行、首行或显示顺序猜语言。独立原文样式需要的 ASS 临时产物原子写入，预览、版本单帧、短片及两种音轨的完整成片共用生成规则并清理临时文件。
- 评论继续在同一 ASS 事件中排版，按各语言字号换行并同比缩小；颜色和描边不会随顺序反转。原文单语同样使用原文样式。正文不允许注入 ASS；字体、颜色、数字和开关均校验。
- 未启用或当前内容未使用的原文样式不参与成片输入指纹；新增默认字段不使既有统一样式成品无故过期。

## 交互补充

- 配色栏的“原文 · 单独设置”可直接启用当前范围的原文独立草稿，再选择原文配色；不要求先到下方解锁，也不覆盖已有备用样式。开关显示“跟随译文／独立设置”，配色弹层标明通用、译文或原文，减少作用范围歧义。保存、来源与恢复继承语义不变。
- 配置行含恢复继承按钮时使用具名 `div role=group`，不能用 HTML `label` 包住按钮与 Naive UI 复合控件。`NSwitch` 是 `div role=switch`，外层 label 的隐式关联可能额外点击首个原生按钮，造成开关刚启用即恢复继承。统一配置、本版本差异与评论排版同时修复。
- 回归覆盖真实 NSwitch 点击事件到父级草稿的绑定、原文快捷入口、锁定防护、备用配色保留及独立恢复按钮；另以模板结构断言防止再次引入 label 默认激活冲突。测试不联网或保存用户配置。

## 验证

真实 FFmpeg 测试检查两种文字的颜色、描边、相对字号和上下顺序，并验证配音/原声、完整片/短片烧录及临时文件清理。隔离配置测试覆盖全局、系列、项目、分P继承及关闭独立样式时的指纹稳定性。前端测试覆盖字段分组、预览参数和配色补丁边界。
