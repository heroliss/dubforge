# ADR 0096：项目发布文案的可见基础值与明确覆盖

状态：接受，2026-10-07。

## 问题

项目发布设置原先只展示配置继承值。标题、简介和来源默认配置为空，来自视频资料的自动填充只在新稿或自动流程中解析，用户无法在项目设置中看到或修改实际基础文案。账号选项刷新与文案更新也缺少清晰区别。

## 决策

1. 增加项目文案的只读预览入口，与新稿复用同一个视频基础文案解析。预览不创建稿件、不写入配置、不调用模型或平台网络，也不扫描成片文件。
2. 项目编辑区按“本项目明确覆盖 → 上级明确配置 → 视频资料基础 → 默认值”展示。明确空串、空标签仍是用户设置；恢复继承删除覆盖键，再展示上级值或自动基础，不把基础值隐式固定到项目。
3. 将操作分为刷新基础资料、刷新账号选项和生成 AI 候选。基础刷新重新读取本地已采集的视频资料，保留尚未保存的修改；平台重新采集沿用视频资料页的独立入口。账号刷新只更新分区、合集和声明选项。
4. AI 候选只在明确点击后生成，先展示当前值和候选值，再按所选字段应用到编辑区，最后统一保存。来源网址由程序解析。自动流程只生成未明确配置的文案字段；全部文案字段都明确设置时跳过模型。
5. 候选请求校验配置和资料版本，生成期间修改输入或切换项目时不应用迟到结果。按项目限制重复生成，异常释放占位。保存和生成状态向宿主页面传播，未保存修改与操作中的导航分别保护。
6. 项目规则用于新稿和仍在继承项目设置的未冻结草稿。草稿中的明确字段覆盖与已冻结稿件的快照继续优先；编辑既有稿件需在稿件页操作，不能用当前项目值倒推历史快照。

## 验证

隔离测试覆盖只读预览、继承与显式空值、稀疏保存、刷新保留手动修改、逐字段应用、版本冲突、重复请求与迟到候选；自动流程测试确认已设置文案的复用。浏览器验证在 8611 测试服务进行，使用隔离项目和离线候选，不调用真实 LLM 或执行投稿。
