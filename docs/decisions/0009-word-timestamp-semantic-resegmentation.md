# 0009 词级时间锚点与语义整理

## 状态

已采用。

## 背景

如果 ASR 只形成较长短语，再让模型猜短语内部的边界，会让时间轴只能近似分配。Whisper/faster-whisper 已经可以提供词级起止时间，因此本地层生成较短的时间锚点，并把真正的句子组合交给语义模型；是否把完整词级时间轴发送给模型由模式设置决定。

## 决策

- `transcribe` 保留完整 `words.json`，并按停顿、强/软标点和约 2 秒安全上限生成短语级 `src.srt`。
- 软标点和时长上限形成的边界属于可合并锚点；明显停顿和强句末仍是默认保护边界。
- `split` 的每个 token 窗口按 `asr.segmentation_mode` 发送短语级或全部词级时间轴，并附带长停顿提示和相邻上下文；模型一次完成合并、拆分和时间重排。
- 输入使用“开始秒-结束秒: 片段”纯文本，输出使用“序号. 开始秒-结束秒: 片段”；序号从 1 连续用于校验。换行是条目边界，程序发送前保证正文单行。开始时间需有序，允许少量自然重叠。长停顿只作为输入 `# 停顿` 注释，模型不得输出注释、空行或 JSON。
- 请求只包含带时间轴的内容和少量窗口上下文，不再发送无时间轴拼接原文；校验限于结构和时间；模型可修正明显 ASR 错词，产物文本作为翻译和双语字幕的源文。
- 窗口上下文只用于理解，不重复输出；如果硬窗口边界切在连续语句中间，本地仅在无停顿、无强句末且不超硬限制时拼回。
- 超过 token 预算才开新窗口，词级时间轴也计入预算估算；模型失败时本地规则仍能使用词级时间戳回退。

## 结果

ASR 原始结果更细、更容易对齐；最终字幕仍由 LLM 决定自然边界。步骤名称改为“语义整理”，避免让用户误以为该步骤只会拆分而不会合并。
