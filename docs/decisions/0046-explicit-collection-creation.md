# ADR-0046：显式创建B站合集与持久化防重

日期：2026-09-28。状态：采用；真实平台创建待用户确认联调。

后续验收：已在用户明确授权后修复 WebP 封面上传兼容问题，并成功创建及读取核验空合集。原始验证记录保留如下；最终结果与诊断方案见 [ADR-0048](0048-bilibili-cover-compatibility.md)。

## 接入方式

本项目安装的 biliAPI 2.15.0 与已核对的上游创作中心源码均无创建合集封装。根据[社区接口记录](https://github.com/afiuh/bilibili-api-collect/blob/master/docs/creativecenter/season.md#创建合集)，工作进程补充 `season/add` 的表单请求，不修改第三方依赖，也不升级 SDK。Cookie/CSRF 仍只在工作进程内部使用，保留 TLS 校验，禁止重定向与自动重试。

合集选择旁的“新建合集”打开独立表单，绑定开窗时的账号。可复用当前稿件封面或先上传到本地；点击“确认在B站创建”后才上传封面、发送创建请求。只创建空合集，不投稿、不加入视频；不接入付费合集，`season_price` 固定为社区记录中的 `0`。名称20字、简介200字是本地保守限制；平台有最终校验权。

2026-09-29 更新：经与B站创作中心网页核对，平台实际限制为名称50字、简介500字，本地前后端限制已同步放宽至 50/500。

收到数字合集 ID 后先持久化回执，后续列表读取失败不能把成功创建误报失败。当前稿件/模板上下文和原选择未改变时，刷新后选中新合集，唯一小节自动选择；其他字段和保存状态不被覆盖。

## 防重复与恢复

新增独立 PublishCollectionRequest 表，记录请求标识、账号、资料指纹、名称、状态、远端 ID 与脱敏错误。请求发送前持久化 submitting；相同资料重复确认复用回执，单账号的未确认请求阻止再次创建，换请求号或标题不能绕过。

工作进程明确未发出创建，或收到平台拒绝时允许手动重试。网络中断、超时、异常成功响应或进程中断进入待核对；重启后也不自动重发。用户可以从实时账号列表关联同名合集，或到B站明确核对未创建后解除保护。仍在执行中的请求不能被解除。核对接口本身不创建合集。

创建与核对不写制作步骤、项目配置或已有发布稿件。远端创建无法随本地弹窗取消而撤销，界面不提供“取消网络即回滚”的假承诺。

## 验证边界

新增隔离测试覆盖确认、输入白名单、重复请求、账号隔离、在途并发、重启后待核对、明确失败重试、关联回执、跨站请求防护、UI独立等待与迟到响应。工作进程测试执行真实分支、以伪 SDK 替代网络。未在用户账号实际创建合集、上传封面或投稿。

本轮完整验证：后端 796 项、前端 172 项、B站工作进程 23 项测试通过，前端生产构建通过。测试结果不代替真实平台创建验收。
