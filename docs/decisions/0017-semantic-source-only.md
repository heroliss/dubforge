# ADR-0017：下游统一使用语义整理结果

日期：2026-09-24。替代 ADR-0016 中可选择识别原稿作为下游原文的设计。

## 问题

在字幕导出页切换共享的原文来源，会使已有翻译过期，作用范围超出用户预期。识别原稿主要提供较短的时间锚点，直接翻译和配音的实用价值有限，不值得维护两条原文路径。

## 决策

- 翻译、字幕导出和配音计划统一读取语义整理的 `split.txt`，移除 `text.source` 设置和对应界面选项。旧配置中的该字段不再影响运行。
- 语音转文字仍保留 `src.srt` 短语级识别原稿和 `words.json` 词级时间戳，可直接查看、下载。只需要识别原稿时可在此停止。
- 仅导出原文依赖语义整理结果，不依赖翻译；导出译文或双语、生成配音计划时，还需要与整理稿逐句对应的译文。字幕导出仍可跳过。
- 保持实际产物依赖，不新增强制连续执行规则。语义整理产物缺失或过期时，明确指出所需产物和生成步骤。
- 指纹保留固定的 `text.source=split` 历史标记，以复用此前基于整理稿生成的有效结果；它不再是可调配置。基于识别原稿生成的旧结果需更新，避免误用不同分句的译文和时间轴。

## 验证

覆盖旧来源设置无效、识别原稿不能替代整理稿、仅原文导出无需翻译、各消费者使用整理结果，以及旧缓存兼容与失效边界。
