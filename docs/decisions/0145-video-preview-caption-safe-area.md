# 0145：视频预览字幕避让播放器控制条

## 状态

已采用

## 背景

视频预览使用浏览器原生 WebVTT 字幕，同时在视频底部叠加统一播放控制条。原生字幕默认贴近画面底部，控制条出现时会遮住字幕或让字幕与按钮重叠。

## 决策

统一播放器在播放且短时间没有操作时自动隐藏控制条；暂停、结束、移动指针、触摸或获得焦点时恢复。播放器根据控制条状态调整原生 `VTTCue` 的百分比行位置：控制条显示时使用较高的安全位置，控制条隐藏时回到接近底部的位置，并保持居中和适度宽度。字幕定位失败时保留浏览器默认行为，不影响播放。

## 结果

所有复用统一播放器的视频预览都获得一致的字幕避让和控制条行为，不需要为各页面单独计算底部间距。控制条隐藏只改变预览交互层，不修改字幕产物或成片烧录位置。
