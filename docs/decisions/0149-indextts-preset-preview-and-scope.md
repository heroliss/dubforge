# ADR-0149：IndexTTS 预设参数分组与载入预览

状态：已采纳。日期：2026-10-14。

## 问题

选择预设与载入表单是不同操作，用户无法直观看到预设包含哪些参数、哪些参数会保持当前值。参数分散在服务连接、参考和生成控件之间。全局及模板表单还可能因预设读取时发出的 busy-change 锁住父表单，使紧接着的 load 事件被拒绝；项目步骤表单未使用同样的忙碌状态。

另有实际遗漏：DubForge 动态参考预设未保存新增的逐句参考最长时长，保存后再载入会丢失用户设置的非默认值。

## 决策

- 全局、模板、项目和句级表单共享「预设参数」与「服务与运行」分组。预设可控制的参考、情感、采样、语言和时长设置集中显示；地址、安装目录、服务类型、请求超时与步骤兜底独立管理。
- 选择预设仅请求后端读取，并展示当前值、预设值、同值项及保持当前值的项。选择不会填入表单，也不持久化。只读预览不锁住表单或导航；快速切换、安装目录变化和卸载取消旧读取，过期或失败候选不能载入。
- 「载入到当前表单」同步应用已读取的候选，不再在网络忙碌锁内发出载入事件。载入只使用当前配置范围的完整字段集合，包括暂时隐藏的情感向量和文本；继续遵守路径冻结。载入后保留此次变化清单，保存仍是单独操作。
- 原生 IndexTTS 预设不包含的 DubForge 扩展保留当前值。所有预设都不覆盖服务连接与运行参数。保存为 DubForge 预设时补充逐句参考最长时长的往返。
- 沿用已有输入指纹与产物更新规则，不自动合成或删除历史配音。

## 验证

隔离 pytest 验证预设参数和参考文件往返、动态参考时长及运行参数排除。前端测试验证中文差异、完整范围、零值/空值、取消与迟到响应，以及真实父子组件在全局、模板和项目表单中的载入事件顺序。浏览器检查选择只读、参数逐项载入、草稿修改计数与独立保存语义。
