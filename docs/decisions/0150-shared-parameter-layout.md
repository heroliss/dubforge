# 0150 — 参数字段按内容排布，共用紧凑标题和说明

日期：2026-10-15

## 背景

参数网格默认拉伸同一行字段。Naive UI 的顶部标签表单使用 `标签 + 1fr`，内容再垂直居中；邻项的文本框和停用说明撑高整行后，数字框与开关会下沉。长技术名还会将来源徽标推到下一行。

## 决策

- 使用显式的 `df-settings-grid` / `df-setting` 共享样式：字段顶部对齐，表单行按内容定高，控件区顶部对齐。仅作用于选择使用此布局的设置表单，不全局覆盖 Naive UI。
- `ParameterHelp` 的内容按自然高度排列；开关使用最小 28px 控制行，文本框保留自然多行高度。
- `ParameterLabel` 保留中文标题和单位，只收起与字段键完全一致的英文括号后缀。完整标签保留在可访问名称与标题提示中，帮助中补充技术参数名。来源徽标和恢复操作保持独立。
- 不适用设置的行内提示只描述当前条件和原值保留；完整原因继续在帮助浮层及提示标题中提供。
- 项目、逐句、全局和模板参数复用同一实现；翻译背景与模型参数采用相同对齐规则。

## 验证

181 项相关前端回归通过，涵盖参数草稿、模式禁用、来源徽标、继承恢复、帮助键盘操作、字幕、模型与翻译设置。Chrome 实测本项目所有参数控件距字段顶部统一为 28px；修改前部分数字框和开关为 57–70px。构建通过。

本次仅改变展示，不修改配置键、保存语义、运行锁或正在执行的任务。
