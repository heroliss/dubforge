# 下载详情按实际媒体流资料显示格式说明

日期：2026-10-20。状态：采用。

- 平台格式编号只标识媒体流，不作为清晰度或编码查询表。下载器在开始下载时输出当前所选流的分辨率、帧率、音视频编码和音频码率，按实际资料生成可读说明。
- 下载计划按 `format_id` 关联每条流；分离音视频与顶层单文件音视频都必须支持。视频切换为音频或未知流时，显式清空上一流说明。
- `current_format` 保留原始编号用于诊断；`current_stream` 为有界显示投影。界面优先显示“当前媒体流”，资料不足和旧记录显示“流编号”，不硬编码 401、616 等编号的含义。
- 只收集白名单字段，不保存媒体直链、签名、请求头或 Cookie。不改下载格式选择、合并、重试或续传规则；显示投影不参与制作指纹。
- 编码名称采用小型通用名称映射；新格式编号无需更新程序。未知编码保留安全的原始名称，竖屏使用实际宽高，不能根据编号或单个尺寸猜测清晰度。
