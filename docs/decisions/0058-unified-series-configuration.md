# 0058 统一系列配置与运行检查

日期：2026-09-28

## 决定

- 设置只有全局默认、系列模板、项目覆盖三个范围。项目只绑定一个系列模板；未设置的字段逐级继承，显式 false、0、空值及等值覆盖不自动删除。恢复继承是删除覆盖键。
- 步骤页面展示最终值及来源；系列模板复用步骤字段。视频内容、文件、账号凭据与发布回执不属于模板。
- 成片版本清单属于合成设置，版本内部保留呈现差异；分P只引用版本并记录顺序和发布名称。清单整体继承或明确由项目管理，界面标明其范围，不伪称逐项继承。
- 评论准备与发布策略分别归对应步骤。全流程仅生成运行计划、预检和执行，不另存设置；单步、版本预览和自动运行使用相同解析入口。
- 模板修改不启动制作或投稿，只影响实际继承项。项目批量绑定保留覆盖；批量运行逐项目预检，明确确认后启动，失败互不扩大范围。
- 配置迁移一次性搬运旧值，不保留旧版读写分支或双轨配置。项目明确设置优先；旧流程中独有的评论及发布值搬至相应设置。媒体、内容和回执不删除。
- 旧账号默认转为普通系列模板，原项目/稿件保留其生效值；账号只保存身份与凭据，不再成为隐藏的第四层设置。迁移前保存数据库备份，校验失败保留旧数据。
- 运行确认绑定解析结果和修订信息；设置变化必须重新预检，运行中不得混用新旧参数。凭据不进入公开配置或持久化运行快照。

本决定替代 ADR-0052 的独立可编辑流程配方、ADR-0054 的全流程默认入口和 ADR-0057 的新项目复制式模板约定；保留后台调度、独立版本身份、原子输出和投稿去重边界。
