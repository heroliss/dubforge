# ADR 0021：统一配音试听时间轴与逐句参数

状态：接受

## 背景

旧试听单独启动 Web Audio 和视频，暂停、拖动和连续播放没有共同的时钟；单击句子还会强制暂停。配音页只支持单句或全量操作，项目参数无法表达个别句子的声音差异。

## 决策

- `DubbingTimeline` 统一控制视频、背景、人声及逐句配音，以视频为时钟；无视频时使用单调时钟。单句模式只限制时间范围与目标语音，连续模式使用完整时间轴。点击文本只 seek，播放状态保持。
- 长音轨用媒体流，附近两句预载，按视频时间纠正漂移。暂停、缓冲、拖动、变速和音量变化共同作用于音轨；卸载或重合成前释放文件，新音频 URL 版本替换旧缓存。长配音按实际时长播放，连续模式允许相邻配音重叠，与成片时间轴一致。
- 原声优先使用分离人声，回退完整原音时避免重复叠加背景。尚无配音时回退原声。声源选择保存在本机试听偏好中，不修改成片；试听不模拟成片响度归一和背景压低处理。
- 勾选合成顺序复用现有单句接口和同一合成函数，有效句自动跳过，可显式重合成；停止只停止后续句，离开页面不再派发下一句，正在合成的句子完成后保留。没有引入第二套后台队列。
- 项目元数据 `tts_lines` 保存本句覆盖，绑定编号、译文和时间；输入改变后旧覆盖失效。逐项优先级为本句、步骤、全局。复用步骤字段、验证与表单，仅开放 IndexTTS 声音表现参数，不开放连接、语言、安装或超时。GPT-SoVITS 当前由其服务端管理声音参数。
- 缓存指纹、实际合成、依赖检查统一读取有效句配置；本句参考原声需求只阻塞本句，正式全量运行按所有句的需求检查。设置与外部参考文件变化能使相应句缓存过期。
- 动态音色/情感严格使用本句起止时间内的分离人声，短于 2 秒也不回退视频开头；日志记录参考类型、时间和实际传入文件。短参考不足以稳定克隆时提示使用同一说话人的较长自定义参考。开头 8 秒只用于明确选用 stable 的情况。
- 逐句合成有项目占用保护，与正式步骤互斥；日志追加到本项目 `tts.log`。成功的逐句操作继续沿用既有完成判定，不把人工等待或中断计入批量耗时样本。

## 验证

后端覆盖参数优先级、逐句失效与批量复用、输入变更、参考依赖和并发保护。时间轴测试覆盖单句/连续、原声回退、重叠、暂停定位、变速、缓冲、释放与无视频情况；独立 8611 实例验证实际浏览器操作和布局。
