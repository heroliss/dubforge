# ADR-0039：三维成品组合与评论整体时间轴

日期：2026-09-27。扩展 ADR-0029/0037/0038，替代 ADR-0033 中“试片固定使用流程默认方案”的约定。

## 证据

- 配音、烧录对话字幕、叠加评论是三个独立选择。旧界面把前两项列成卡片，评论却是全批开关，
  不能在同一批生成含评论和不含评论的版本；原声评论又被列为特例，历史文件分组混合了评论维度。
- 旧试片总按默认配音方案检查依赖并铺轨，无法验证已选原声组合。
- 评论仅按序号手动取帧，没有整体时间范围；编辑后画面不自动更新，且只有底色，没有文字颜色。

## 决策

1. `assembly_outputs` 统一解析三维组合和兼容旧请求。新正式请求为 `outputs` 列表，每项必须明确声明
   `dubbing`、`burn_subtitles`、`include_comments` 三个布尔值；不允许混用旧 `variants`/整批开关。
   内部有七种需要渲染的组合，全部关闭仍直接引用原片，不复制或重编码源视频。
2. 旧 `variants + include_comments` 请求只在入口转换。新任务保存规范组合及 `output_schema=2`；
   升级前整批评论任务恢复执行时保留原意。评论方案继续通过修订号校验并在入队时冻结。
3. `dimensions()` 供依赖与渲染共用。每个成品独立传入评论快照，不修改共享任务数据；整批只铺一次配音轨。
   文件名保持既有规则，含/不含评论精确分类。包含默认无评论版的混合批次可以完成默认流程指纹；
   仅评论版、仅原声版不能冒充默认配音成片。
4. 页面区分“当前组合”与“本次生成清单”。三个选项构建当前组合，显式加入清单、去重，后续修改不改变已加入项。
   清单初始为空，生成前预检并确认快照；说明收进提示和折叠历史，保留必要的错误与范围提示。
5. 短片显式提交单个 `output`，跟随上方当前组合而非整份清单，也不再跟随流程默认设置。
   后端按这个组合检查依赖：原声不铺配音，字幕与评论分别可选，共用完整成品渲染路径，裁剪保持原时间轴。
   旧未提交 `output` 的接口继续按旧默认运行。总览流程的默认配音版不变，参数改名“流程默认烧录字幕”。
6. 评论 `CommentPreview` 封装整体范围、视频边界提示、游标、实际 FFmpeg 帧请求和资源释放。
   总范围为 `start` 至 `start + (count-1)*interval + duration`，只显示一段总范围，不画逐条区间；
   区分完全超出视频和末条可见评论被截短。视频时长未取得时暂用预计评论终点，明确标识未知。
7. 预览默认自动更新，停止修改 500ms 后串行请求；拖动松手才请求，文字、语言、颜色、排版与排序均参与签名。
   旧响应不展示，合并待刷新状态，错误不无限重试；离开取消请求、清理计时器与 Blob URL，不保存草稿、不合成视频。
8. 新增评论方案局部字段 `color`，默认白色，复用 `text_style` 颜色校验与 ASS 渲染；旧确认方案保持默认白字。
   这是文档样式，不增加全局配置键。预览与完整成品用同一颜色逻辑。

### 同日补充：开始点导航与描边

- 保留上方评论整体范围；评论与字幕预览拖动条复用 `PreviewTimeline`，增加每条内容的开始点刻度。
  相同起点合并提示，不画越界或无效时间；悬停查看时间与内容，点击稍进入该区间以避开渲染边界空帧。
  密集字幕仍保留所有不同起点，可用前后按钮逐项定位，无需强行给每个刻度放置文字标签。
  定位只改变预览时间，沿用防抖串行取帧，不保存草稿、不改字幕时间或播放器位置。
- 评论方案增加局部 `outline_color`、`outline`；默认黑色、宽度 2，保持旧方案外观。
  与字幕共用颜色、0–10 描边校验及 `paint_style`，0 关闭描边，底色与透明度仍独立。
  字幕与评论都按“文字颜色、描边颜色/粗细、文字底色/透明度”组织控件，不新增全局配置。

## 验证

- 隔离 pytest 覆盖 8 种组合的依赖和原片例外、非法三维值、旧请求兼容、逐项快照、失效修订号。
- 真实 FFmpeg 验证 7 种完整成品与 7 种短片；原声试片在无配音产物时可运行，评论不会流入无评论版本。
- 前端测试覆盖清单与当前组合分离、混合批次快照、试片精确请求与时间格式、自动预览防抖/串行/过期响应、
  拖动、视频末尾限制、超出提醒及失败/卸载；实际 Vue/Naive UI 渲染测试验证入口和控件结构。
- 浏览器连接失败时不宣称完成截图验收；不为测试触发用户项目合成、真实 LLM 或常驻服务重启。
