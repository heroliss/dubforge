# 0200：剪辑时提供当前成片参考并同步时间轴

## 背景

成片剪辑需要在原视频时间轴上标记删除范围，但字幕、评论和配音只存在于已生成的成片中。只播放原视频无法确认这些内容对应的准确位置；如果直接把成片时间当作原视频时间，又会在已有删除段后产生偏移。

## 决策

- 原视频仍是剪辑编辑的唯一时间基准，删除范围始终保存为源时间。
- 当前版本已经生成的正式产物，在剪辑编辑器中作为只读参考播放器显示；它展示实际字幕、评论和配音，不会替代源视频编辑器。
- 两个播放器默认开启定位和播放同步。源时间通过已保存的剪辑快照映射到成片时间，成片时间反向映射回源时间；删除接缝反向定位默认进入接缝后的下一段。
- 同步使用已保存的剪辑方案，而不是未保存草稿。这样参考文件的时间轴与映射始终一致，用户仍可继续编辑草稿并明确保存后再生成新成片。
- 用户可以关闭同步，分别试听原视频和当前成片。没有正式产物时只显示原视频编辑播放器。

## 影响

用户可以在看到字幕、评论或听到配音的同时定位源视频删除点；旧成片仍可以作为删除范围来源和只读参考。当前参考播放器是核对用途，草稿范围不会立即改变已有产物。
