# 0144：设置应用预览显示平台名称

## 状态

已采用

## 背景

应用最新设置的差异预览中，分区、合集和合集小节原先只显示 B 站内部数字 ID。数字 ID 对排查有用，但用户无法直接判断这些值对应的远端名称，容易误确认设置。

## 决策

绑定计划只返回当前项目和应用后设置使用的 B 站账号标识及合集标识，不在生成计划时访问远端。预览组件挂载后异步读取账号元数据，并显示“名称（ID）”；元数据读取失败时保留“ID”，同时给出非阻断提示。为兼容尚未重启的旧后端，若计划未带账号上下文且目录中只有一个账号，预览可使用该唯一账号读取名称；多账号时不猜测来源。

## 结果

预览生成不会被 B 站网络请求阻塞，确认应用的语义和请求体不变。名称读取失败不会阻断设置应用，ID 仍可用于核对和排错。后端更新后应重启实际监听端口的进程，才能启用新的账号上下文返回。
