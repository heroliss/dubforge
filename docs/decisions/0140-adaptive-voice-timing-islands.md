# ADR-0140：连续语音岛内的自适应配音铺轨

## 状态

已采用

## 背景

逐句 TTS 只按“本句开始到下一句开始”判断是否超时，会把相邻句之间的空余
分别锁在各自的槽位里。翻译错位或中英长度差异出现时，长句会和下一句重叠，
即使后一段连续台词仍有可用空白。单纯把所有句子压速会损失自然语速，也不能
修复编号错位。

## 决策

TTS 首次请求使用连续语音岛的候选可用范围，避免因为单句短槽位提前触发缩速。
完成后再根据实际 WAV 时长，在没有真实长停顿的连续语音岛内做一次全局排布：
优先保持每句原速，允许句子的成片起止在其源字幕范围左右延展，并保证相邻
音频不重叠。源时间轴和原文字幕仍保留；目标字幕和配音成片在确认铺轨产物有效
时跟随 `voice_timing.json`。

只有整座语音岛的总可用时长仍不足时，才返回 `needs_scale` 和建议因子。无法
容纳的句子不会被静默裁切；混合原声/静音选择、版本指纹不一致或铺轨产物不完整
时沿用旧铺轨并提示复核。

## 后果

同一连续语音片段内可以消除由局部槽位造成的重叠，减少不必要的 TTS 缩速。
真实长停顿不会被吞掉，原文字幕不会被自动移动。目标字幕可能跟随配音时间
轻微移动，因此原声字幕和目标字幕分轨处理。已有成片不会隐式重写；需要重新
运行 TTS/字幕/合成后才使用新的铺轨产物。
