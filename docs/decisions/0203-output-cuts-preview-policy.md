# 0203 成片剪辑试听与草稿时间轴策略

## 状态

已采用

## 决策

成片剪辑区域保留两类预览：原视频是可编辑的源时间轴，当前成片是只读的上次已生成产物。`播放时跳过当前删除清单` 只作用于原视频播放器，并且在播放头进入删除范围时立即跳到下一段保留内容；暂停、拖动和设置起止点不被强制跳走，便于精确编辑。

剪辑范围没有保存时，原视频试听可以立即反映当前草稿；右侧当前成片仍代表已保存方案，不伪装成已经应用草稿。联动开启且两者方案不同，界面必须提示这种时间轴差异；保存后两者才重新具有同一剪辑映射。删除段在成片时间轴中没有独立时间，定位统一收敛到剪辑接缝。

## 原因

把实时试听、编辑草稿和已生成文件混成一条时间轴，会造成用户误以为删除已写入文件，也会在未保存范围与旧成片不同步时反复回弹。明确数据来源后，用户可以先试听和调整，再保存并生成，而无需为每次微调生成文件。

## 约束

- 跳过逻辑只能在媒体播放中执行，不能阻止用户拖进删除段取样。
- 删除范围仍以原视频时间为准，成片映射由 `outputCuts` 的单调映射函数统一提供。
- 双播放器同步应以单一播放主端和有限漂移校正为基础，不能在每个 `timeupdate` 无条件重设另一播放器的 `currentTime`。
