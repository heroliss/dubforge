# 0162：成片设置来源与就地应用基础值

## 状态

已采用。

## 背景

项目按 ADR-0126 保存创建或上次应用时的制作基础值。修改全局或模板后，已有项目不会立即变化。原界面的「全局默认」标签与折叠区提示不足以表达这层快照，原声、配音版本的结构设置又缺少来源。总览应用设置后未刷新状态，也会使已应用的新值看似没有生效。

## 决定

- 保留稳定项目基础值；全局或模板保存后供新项目及显式应用使用，不自动覆盖既有项目，也不自动重做成片。
- 统一区分当前绑定来源、项目保存的基础值、项目覆盖及版本专用值。冻结来源的可见标签为「已存全局值」「已存模板值」，悬浮说明明确保留创建或上次应用的值，不代表最新默认值。
- 版本内部专用参数若来自基础版本清单，沿用该清单的全局或模板来源；只有项目明确覆盖的清单或本页修改才显示项目/版本来源。不通过数值相等推断继承，不自动删除等值、false、0 或空值覆盖。
- 在成片步骤提供「查看并应用最新合成设置」。来源固定为当前绑定模板，无模板时取全局；作用范围为成片版本清单和可供版本覆盖的呈现字段，排除运行连接参数。识别、翻译要求、配音引擎、评论采集评分、发布规则、审查决策和剪辑方案不在本次应用范围内。
- 应用前比较基础值变化及每版本实际有效值变化，说明哪些项目覆盖和版本专用值继续保留。项目已明确覆盖整份版本清单时保留该清单，不把修改一版解释为可以自动改写其他版本。
- 提交时重新核对项目和来源的计划指纹，使用相同的配置启动锁与字段门禁，在事务中仅更新限定基础值及其 configured/origins/sources 元数据。完整有效配置仍需通过交叉校验；当前发布分 P 引用不能失效。
- 正在执行的步骤保持冻结；排队或尚未执行的步骤按现有字段规则允许修改。保存成功后刷新状态和版本工作区；外部刷新保留当前草稿和提交身份，防止误把旧草稿当成最新版本保存。
- 版本参数编辑后设为版本专用，「恢复项目默认」删除该项专用值；「全部参数恢复项目默认」清空当前版本全部专用参数，包含隐藏项，保留名称、身份、声音/字幕/评论开关及其他版本。批量恢复遵守所有相关字段锁定，先修改草稿，仍由「保存版本设置」提交。这里的默认值是本项目已保存的默认值，不是出厂值或最新全局设置；撤销未保存调整与恢复基础清单保持独立语义。
- 逐项恢复统一使用紧凑的 `ParameterResetButton` 回转箭头，始终保留入口，已继承或受锁定时禁用。版本参数不再把「设为专用」与恢复复用为同一个切换按钮：编辑值即形成专用参数，回转箭头只移除本项专用值。步骤、本句、配置、发布与评论排版沿各自真实的继承或恢复语义，不根据数值相等猜测是否继承。版本名称及原声/配音、字幕、评论结构项没有单项继承协议，逐项回退称为「撤销本项修改」，仅恢复此版本已保存定义的对应字段。

## 验证

2026-10-17 补充：步骤页的版本工作区与项目默认参数表单通过独立刷新通知互相回读，不重建组件；脏稿和提交指纹保持，提交期间的更新延后处理。项目参数区也可打开同一基础差异抽屉。差异中的 `before/after` 仍为旧、新基础值，新增 `effective_before/effective_after` 表示项目实际生效值；被项目设置覆盖时明确展示保留的值。检查的来源名称、中文枚举、恢复目标均不冒充最新全局值。

隔离测试覆盖限定应用、模板来源、明确覆盖保留、嵌套版本来源、来源或项目并发变化、归档、运行字段门禁及无关设置不变。通过独立 8611 网页实例核对来源标签、变化预览、显式应用与版本专用值保留；不修改用户项目的当前制作设置。
