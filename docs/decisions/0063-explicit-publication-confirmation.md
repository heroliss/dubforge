# 0063 — 投稿由明确操作确认，不再额外勾选素材权利

日期：2026-09-29

## 问题

“已核对素材发布权利”只是本地布尔值，既不核验也不授予素材授权，却阻止预检和修改已上传稿件。自动流程还把素材提醒与本次投稿授权混在同一个勾选中，造成重复确认和误解。

## 决策

- 删除发布页、单项目和批量自动流程的独立勾选，以及领域层对应的强制校验；新草稿与运行配方不再生成 `rights_confirmed`。不自动填写“已核对”的声明。
- 三个入口使用一致的低强调素材提醒，完整说明放在悬停提示中，不阻塞保存、预检或运行。
- 真正的操作确认保持不变：单稿件“确认上传并投稿”、单项目“确认制作并投稿”，以及批量按钮明确显示运行项目数和投稿项目数。批量统计仅含检查通过、实际会执行的项目。
- 预检、打开页面、保存配置都不触发上传或投稿。后台仍要求显式 `confirmed: true`，保留修订号、输入指纹、请求幂等和重复投稿防护。
- 原创/转载、来源、创作声明等平台设置与校验保持不变；LLM 不推断授权。删除本地勾选不代表平台要求或素材授权发生变化。

取代 ADR 0041、0052、0060 中有关独立素材权利勾选的约束，其余发布边界不变。

## 验证

隔离测试覆盖无勾选的新草稿、历史未勾选草稿、已上传资料修改、自动与批量预检、显式确认、混合批量投稿数量及无真实投稿的完整流程回归。
