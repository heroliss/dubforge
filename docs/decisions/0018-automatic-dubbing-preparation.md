# ADR 0018：配音任务自动准备与试配界面统一

## 决策

配音任务是语义时间轴与逐句译文的确定性组合，仅附带低成本的朗读时长估算，无需独立操作。逐句试配与批量合成本质上共用相同的合成器和缓存，因此统一为一个「配音」步骤：既可合成本句并试听，也可合成全部。

试配、批量配音和成片合成共用任务准备函数，直接依赖 `split.txt` 与 `translate.txt`；按参考方式额外需要原声。不会因打开试配页自动调用模型或补跑上游，未就绪产物仍按缺失、过期等原因提示。字幕导出继续独立可选。

旧 `dubtask` 步骤及导出接口保留兼容，但不再进入导航、默认执行和自动步骤选择，也不阻塞新配音流程。旧配音计划与试配页面地址均跳转到统一配音页。

## 统一边界

- 逐句试听面板嵌入标准步骤页，复用标题、运行控制、依赖提示、进度、日志与产物清单；参数编辑为共用组件，播放与释放为独立 composable。
- 试配参数与批量配音是同一份项目设置，不再通过试配页修改全局预设。全局默认与预设仍在设置页维护。
- 句级音频指纹包含文本、时间轴、声音配置与参考音频；估算时长、容差、间隙和提示标记不使音频失效。兼容输入完全匹配的旧句级指纹。
- 满意标记绑定合成输入及实际音频版本；改音色、改文本或重新合成后需要重新确认。
- 移除独立的试配确认环节。满意标记仅供用户记录；逐句合成到全部音频就绪时，自动完成同一个配音步骤，无需补跑批量操作，也不把人工停顿计入耗时样本。

## 验证

隔离测试覆盖未运行／失败的旧配音计划不影响试配和批量执行、批量复用试配音频、真实依赖门禁、估算参数不触发重合成、声音参数变化与重新合成使确认失效。浏览器检查桌面与窄屏布局、共享表单保存及旧地址跳转。
