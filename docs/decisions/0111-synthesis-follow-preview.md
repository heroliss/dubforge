# ADR-0111：跟随合成结果的逐句预览

状态：已采纳。日期：2026-10-07。

## 问题

原「跟随合成」在正在生成的句号变化时定位视频，会打断上一句试听，并可能播放尚未完成的旧版本。用户需要随着新配音完成逐句听验，播完暂停，等待下一条完整结果。

## 决策

- 「跟随合成」由当前任务成功生成的结果驱动。任务行必须为 done，目标版本和当前选用的配音一致，音频可读；缓存复用、失败、缩时中间结果、原声和空位不自动试听。
- 开启时可试听活动任务最新完成的一句，不回放全部历史结果。任务已经结束时等待下一次合成；开启期间观察到的任务结束仍允许最后结果播完。
- 记录任务、句号、目标版本和媒体版本。已观察到的旧音频不能因完成状态先到而被当成新结果；等待下一轮媒体更新。普通进度轮询不会重复试听。
- 每次通过同一播放器试听一条完整配音，实际语音结束后自动暂停，不继续播放后续尚未完成的区间。先完成视频定位并等待 seeked，再等人声 play() 成功，最后启动视频；准备期间停在句首，避免视频先走后从零追播。
- 音频就绪、结束和加载错误事件直接推动同步与界面更新，不依赖动画帧或视频进度事件；后台标签页与繁忙渲染时也能及时开始和暂停。释放媒体时移除事件，旧音轨的迟到事件不影响新试听。
- 当前句完整播完后再处理待播结果；合成较快时仅保留最新待播句，避免积压，不打断当前完整声音。
- 手动暂停、拖动、定位、试听及连续播放会暂停自动跟随，并显示「继续跟随」。自动播完和程序定位不算手动中断；普通轮询不会抢回用户播放。播放失败须明确重试，不自动循环请求。
- 「跟随预览」继续只选中并滚动当前播放句；两种模式互斥。关闭跟随、离开工作区、替换媒体和组件卸载时取消自动播放意图和迟到回调。新任务清理旧待播状态。
- 此功能是即时查看偏好，不修改制作参数、声源或项目产物，不使流水线过期。

## 验证

控制器测试覆盖完成去重、旧音频快照、最新结果、缓存、失败、任务切换及手动暂停。播放器测试区分自然结束与用户操作，并检查单句按实际声音结束、媒体准备等待和取消。真实 Vue 生命周期联动检查完成结果驱动单句播放、自动暂停、下一条结果接入和用户干预。
