# ADR 0082：本地文本审查与派生展示屏蔽

日期：2026-10-05。状态：已采用。

## 问题

用户要求简单的自动字幕屏蔽，命中相同规则的评论不应入选上屏方案。真实项目 `fc5fd6` 包含 `And while the tragedy of Tiananmen Square` 及译文“天安门广场的悲剧”。只删中文字幕不能改变原文字幕或原声；仅检查人工修改后的文字也无法发现仍在原声中的内容。

自动把“天安门”“历史”“纪念馆”等单独地名或旅游词当作风险，会误杀正常旅游段落。规则匹配也无法判断画面、完整语义或平台审核结果，不能把“未命中”标成“审核通过”。

## 决策

- `dubforge/content_review.py` 提供无 FastAPI 依赖的纯领域匹配器，不自动调用付费模型，不写回字幕或评论原文。
- `review_lines(lines, custom_terms, enabled=...)` 接收字幕校对稿的行对象，独立检查当前 `source_text/text` 及 `base.source_text`。后者标为 `source_audio`，用于识别人工修改显示文字后仍存在的原声内容。旧 `base.text` 不被视为当前字幕或实际配音内容。
- 每个命中行输出一个 finding，含 `id/ids/start/end/source_text/text/source_audio_text/source_audio_start/source_audio_end/rule/matched_rules/fields/context_ids/reason`。原声时间优先读取 `voice_timing`，其次 `base.start/end`，再使用当前时间。
- 内置规则只匹配用户实际遇到的高置信关联：“天安门（广场）的悲剧/屠杀”和 `Tiananmen` 与 `tragedy/massacre` 的短距离关联。支持前后两种次序，例如 `tragedy of Tiananmen Square`。
- 关联词之间只允许有限的连接词，不能跨强句末或任意长上下文。普通“游览天安门广场”不命中；地名与另一句话的航班悲剧也不合并成命中。
- 允许两个连续编号、间隔不超过 0.6 秒的相邻字幕行提供上下文，只有实际跨两行的匹配才标记两行。缺失编号、长停顿或无关邻行不扩大屏蔽范围。原声轨使用原始时间判断相邻关系。
- `content_review.enabled` 控制自动检查，`content_review.blocked_terms` 支持换行文本和字符串列表。自定义词按 NFKC、大小写和空白归一，中文内部空白不改变词语身份；英文词按词边界匹配，避免在其他单词内部误命中。去除空词和重复词，上限 500 条、每条 200 字符，非法设置抛 `ContentReviewError`。
- `blocked_comment(original, translation, ...)` 分别检查评论原文和实际展示译文，返回可读原因列表。集成端对命中评论整条不选用，仍保留完整评论供工作区阅读，不把片段替换后的评论当作原评论。
- `redact_lines()` 只产生展示/导出副本，整句省略命中行，不删改模型产物、校对记录或项目源视频。集成端可根据原始 ASR、用户确认的时间区间及实际配音长度扩展派生输出的屏蔽/静音区间。
- `review_report()` 给项目 API 提供 `findings/blocked_ids/summary/warnings/blocked_terms/mute_audio` 等字段。报告固定说明“仅审文字，无法判断画面，不能保证平台通过”；关闭检查或没有可检查字幕时明确提示，不返回 `passed=True`。
- 当前时间、原声时间都必须是有限数字、开始不小于零、结束晚于开始。重复编号或开始时间乱序也不得生成屏蔽区间。空字幕列表允许返回报告，但不能解释为通过审查。
- 规则版本由 `REVIEW_VERSION` 导出，导出/合成指纹纳入规则与屏蔽设置，防止复用旧的未屏蔽输出。源文、翻译模型缓存与评论阅读原文仍保持原内容。
- 项目审查配置支持原视频时间轴上的人工时段，字幕隐藏与完整混音静音共同生效；静音覆盖原声、中文配音、背景残留以及命中句所选 WAV 的实际尾音。预览按同一原始时间轴平移和裁剪。普通旅游地名不扩大处理范围。
- 成片记录保存生成时的审查凭据和实际烧录的评论方案。发布预检按文件哈希匹配该记录，不能用当前编辑状态证明旧文件已处理；长上传结束、正式投稿发送之前再次核对当前规则。未命中只标作本地规则未命中，不显示平台审核通过。
- 对已完成配音而上游模型提示词已升级的成片，提供独立的 `pipeline/review_render.py` 修订入口：从登记的原视频重建画面和当前字幕，复用已完成成片的音轨，生成新的不可覆盖文件及版本定义，旧成片、投稿快照和步骤指纹保留。该结果明确标为“审查修订（复用旧文字与音轨）”，不能当作新语义整理或翻译已经完成。编码器、输入哈希及处理范围写入旁侧审查记录。

## 验证

独立 `tests/test_content_review.py` 使用隔离数据根，覆盖真实中英文表述、普通旅游与无关悲剧的误杀防线、NFKC 和自定义词格式/边界/限制、相邻行与原始时间上下文、人工字幕编辑不能掩盖原声、无效时间阻断、报告透明性及副本不修改原数据。

只读检查真实 `fc5fd6`：当前整理/翻译第 47 行 `117.340–119.580` 命中；原始 ASR 第 60 行 `117.340–119.160` 也命中。此处确认的是狭窄词语语境，周边完整论述需用户确认时间范围，不能由地名或普通历史词自动扩大。

## 限制

本地规则会漏掉同义改写、隐喻、画面文字和未转写的音频。派生字幕隐藏与音频静音也无法消除画面中的内容。平台指出某一完整片段时，应由用户确认时间区间；不能从一个关键词推断整段是否应删除，也不能保证任何发布结果。
