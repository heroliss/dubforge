# 0160：项目成片剪辑与源时间轴映射

## 状态

已采用。

## 边界

内容审查的字幕隐藏和声音屏蔽继续保留各自语义。新「成片剪辑」明确删除画面及同一时段的声音，适用于广告、不要的画面和用户核定片段。它是项目视频专属的编辑方案，不属于全局默认、模板或 TTS 音频槽；所有成片版本共用一份源视频时间轴。

原视频、识别词时间、语义稿、翻译、逐句音频与源轴字幕导出不变。字幕和评论先沿现有源轴完成渲染与混音，随后在同一个 FFmpeg 过滤图中，对视频和音频应用相同的保留区间并拼接。正式成片和试片只编码一遍，不先生成完整成片再重复压制。没有其他制作选项的原声版本若启用删除，也必须生成剪辑成片，不能走「原片直用」捷径。

保留区间按源时间递增且不重叠，避免重排造成的帧缓存。多段剪辑使过滤图变长时，将过滤图写入本次任务的 UTF-8 临时脚本，退出时清理，防止 Windows 命令行长度限制导致合成无法启动。

## 编辑与持久化

项目目录 `output_cuts.json` 原子保存方案：源身份、原时长、启用状态、区间身份、起止秒数、备注与逐项启停。最多 200 项；重叠或相邻范围在执行时合并，备注和禁用项不影响制作指纹。不能删除全部视频。

保存校验方案修订号和源视频指纹。换源后旧范围不生效，需人工核对并明确重新绑定；状态读取仍能打开编辑器，不把修复入口挡在制作错误后面。所有时间输入、标记与短片试合成都按源时间，画面精度受源视频帧率限制。

界面使用独立折叠卡、统一播放器、起止标记、毫秒输入、多区间清单、删除/保留色带和可选跳过试听。保存、放弃调整、读取已保存与生成成片分别执行。未保存剪辑阻止同页面正式生成及试片，切换页面提示保留/放弃；保存后通过项目状态反映成片需更新，不自动生成或发布。

## 流程、并发与恢复

预检提供当前剪辑预览，真正取得执行槽位时冻结最新方案到任务及每个版本的成功快照。排队阶段可保存新范围；正在编码时可准备下一份方案，当前运行仍使用原快照。自动评论准备重解析版本时沿用任务冻结的剪辑，不重新读取文件。剪辑仅使受影响成片失效，不要求重做识别、翻译、TTS 或源轴 SRT。

输出先写暂存文件，成功后原子替换并登记；失败/取消保留已有成品。发布继续使用既有文件哈希和新鲜度门禁，不能把待更新的成片当作采用新范围的产物上传。

短片范围与删除区间求交，实际输出可短于选择时长；全被删除时明确提示重新选择保留范围。预览单帧仍是源时点的样式核对，若该点将被删除会明确标识。正式成片播放器章节使用该文件成功快照，不能直接使用源章节时间。

## 章节与兼容

每个上传分 P 按自己的产物编号和哈希读取成功剪辑快照，对源章节区间求保留交集。整章被删除则移除，部分保留的章节按累计删除量前移，不把删除中的起点误映射到下一章。新投稿在确认时冻结各 P 的时间轴与章节候选。旧发布详情的派生显示放在独立 `chapter_parts` 中，不改变原投稿快照和确认摘要；B站已有手工章节继续优先保留。

旧「审查修订」复用原成片混音并假定原片时长，不能安全处理删除后的时间轴。对于已剪辑文件或当前启用剪辑的项目，明确引导从正常成片流程重新生成，避免复活已删除的画面或混入错位音轨。

## 后续 AI 接入

自动广告/内容分析只需产生相同源时间轴上的候选区间及理由。候选与已采用方案应分开，保留分析依据、源身份和采纳状态；人工或明确配置的自动化规则采用后，进入现有区间清单、预检、冻结和渲染链路。此次实现手动剪辑和稳定执行合同，不调用模型猜测删除内容。

## 验证

隔离领域测试覆盖范围校验、重叠合并、乐观并发、换源重绑、原子失败、冻结与时间映射。真实 FFmpeg 测试覆盖删除中间颜色片段、原声及配音、烧录字幕、短片求交、正在运行与排队期间保存。发布回归核验各 P 文件身份、章节映射及旧确认摘要保持。另在 8611 独立数据实例通过网页操作核对标记、保存、草稿保护与试片。
