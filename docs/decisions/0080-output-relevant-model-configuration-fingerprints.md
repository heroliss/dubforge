# ADR-0080：制作结果只跟随实际消费的模型配置

日期：2026-10-05。状态：采用。

状态更新：模型执行配置与已有产物有效性的关系、已有项目的实时继承已由 [ADR-0126](0126-stable-project-settings-and-model-services.md) 替代；模型配置仍用于运行合同和中间请求缓存。

## 背景

语义整理和翻译的 `cfg_keys` 都包含整个 `llm` 段。轮换 API 密钥、修改请求超时、编辑停用组，甚至编辑另一条已明确选择模型的步骤所不使用的配置组，都让文字指纹变化，并沿依赖传播到配音和成片。这些变化并不改变制作要求。ADR-0075 的剩余步骤边界原来同样消费整个 LLM 段，因此也会出现无关设置修改后暂停。

## 决策

- 保持 ADR-0058 的全局→系列→项目稀疏继承。已有项目实际继承的制作参数改变时，相关结果显示需更新；保存设置不删除旧文件，也不自动重做项目。项目明确覆盖可固定所需参数。
- `pipeline/config_fingerprint.snapshot` 集中解析每个步骤实际消费的制作配置，供产物指纹和新工作流边界共用。LLM 密钥、超时、停用组与组的展示名称不进入制作指纹；服务地址、模型、请求参数、启用的降级顺序仍参与。
- 固定模型组的步骤仅消费该组；跟随全局的步骤消费有效降级链。关闭 LLM 的规则分句不消费模型配置。转录不消费下一步的分句发送模式；TTS 安装目录与等待超时不参与结果及边界快照。
- 术语表绑定文件内容摘要，同路径编辑也使翻译需更新。旧术语表缓存没有内容证据，不升级为有效新缓存。
- 新工作流保存 schema=2 的逐步骤配置快照；边界只比较剩余步骤，以免已完成整理步骤的模型修改打断另一模型组的翻译。旧已确认运行继续使用原有快照格式，不默默改写其合同。
- 自动评论步骤同样核对它实际使用的全局模型链。源文件大小和修改时间一律使用 JSON 列表，避免本地视频的快照往返被误认为变更。
- 启动时只把严格匹配当前完整旧配置/输入/提示词版本的已完成文字指纹升级为新指纹，并更新恢复清单。未知、已过期、失败或运行中的结果不被宣称有效。不凭旧 SHA 猜测历史配置，也不更改媒体、字幕、译文或声音文件。

## 限制与验证

既有结果如果在升级前已经因设置变化过期，缺少历史生成配置就不能安全恢复其有效状态；仍需核对并更新。文本时间对齐和翻译提示词的质量修复是实际制作语义变化，仍会正确使旧文字及相关下游需更新。

隔离测试覆盖密钥/超时/停用组、固定模型组、降级顺序与请求参数、关闭模型、旧指纹保守且幂等升级、剩余步骤模型组边界及旧运行兼容。
