# ADR 0091：保守语义校验与相邻句边界

日期：2026-10-07。状态：已采用。补充 ADR 0090 的全文整理策略，不改变全文输入和请求级 `low` 思考设置。

后续更新：本决策的数字、否定、单位、删词预算及75%覆盖硬门禁已由 [ADR 0092](0092-contextual-semantic-correction-and-structural-validation.md) 取代；相邻句边界、真实长静音及全文输入策略继续沿用。

## 问题

项目 `99211e` 任务 #282 首轮响应正常结束，但校验因原识别中的第1722个词 `hug` 未保留而拒绝全文。原识别为 `I got the hug the duck…`，候选为 `I got the— the duck…`。没有原音证据，逐词差异不能证明这是一处实质遗漏。重试保留 `I, got the hug the`，反而产生更差的分句。

首轮还在已分开的长静音两侧保留了独立的 `I`、`There's`，并在后半句再次加入主语。全局静音切口检查因为新增词无法唯一映射而报错，尽管候选已经完整留出了真实空档。最终第二轮218句中的冠词、主语悬尾则来自模型本身；另外，长度兜底也存在把 `and` 留在前句的反例。

## 决策

- 默认校验只把明确证据用于阻断。连续1–2个无法确定含义的普通ASR删词降为带原词位置的中文复核提示，累计计入原有清理预算；不针对某个错词建白名单。提示不代表删词正确，也不把大小写当作可靠实体识别。
- 连续至少3词的未知删除、超过累计清理预算、大段覆盖不足、可证明的词序重排、重复抄写仍阻断。数字和否定的已有双向保护继续生效；货币符号及有足够上下文的货币、计量单位不能遗漏或变更。多义词或疑似人名不能仅因词形当作单位。单位只承认明确等值的英美拼写，如 `meter/metre`、`liter/litre`，不推断币种来源或换算单位量级。
- 对长静音处不确定的短新增词，仅在两侧有精确源词锚点、新增块位于既有分句边界、相邻时间与真实静音端点一致且所有候选都没有侵入空档时，保留模型时间和全部文字并提示复核。新增块最多3词、32个归一字符；端点容差沿用11毫秒。实际跨静音、插入位于同一候选内部、没有可靠两侧锚点或无法安全分配时间仍报错。
- 整理提示词要求联合检查前句句尾与后句句首。`the/a/an`、`I`、`and`可能是下一短语或分句的开头，搭配明确且没有长静音时调整分句及词级时间，不为解决边界错误删除它们。真实长静音两侧仍允许半句。
- 模型模式超长候选的本地兜底，以及过短尾段的平衡，只在合法长度范围内优先避免冠词、主语、连接词切口，保留逐字符内容并继续使用词锚点定时。不据此重组已经分开的候选，也不改变普通规则模式的严格长度策略。词形可疑只提示，不能升级成全文语法门禁。
- 翻译保持整理定稿的编号、句数、顺序与时间。上下句用于理解功能词，但不能把下一句的事实补到本句。确认是功能词时按目标语言自然表达；中文冠词通常不必单独落字，避免残留或音译英文功能词。专名、字母和数字不能套用省略规则；无法确认的实词和专名仍不猜改。
- 独立提升整理与翻译提示版本，重新计算文字链的新鲜度和缓存键；原识别和下载等前置产物继续可用。已有生产产物保留，由用户重新执行需要更新的步骤。

## 验证与限制

实际首轮响应以只读输入在临时目录离线回放：448条ASR短语、157条模型候选，经全部覆盖、保真、声学、长度和最终质量检查生成185句，候选全部文字保留，没有最终时间问题；记录4条清理提示、2条静音边界复核提示。未向LLM额外请求，未替换生产项目产物。

回归覆盖少量删词只提示、累计预算、明确数字/否定/单位与大段遗漏仍阻断、静音例外及负例、相邻功能词的兜底切点、完整请求不增加重试、缓存复核和翻译逐编号契约。确定性检查不能证明ASR、删词或译文的语义正确；纯功能词孤行仍应在整理阶段解决，不能靠译文新增实体填满。

最终后端全量回归：2209项通过，540.38秒，只有2条既有第三方弃用提示。诊断采样显示等待发生在隔离数据库初始化、测试视频生成及后台任务完成；没有改变生产逻辑或测试断言来缩短等待。前端未作本轮修改。
