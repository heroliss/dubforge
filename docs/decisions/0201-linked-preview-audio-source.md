# 0201：联动预览只保留一个声音来源

## 背景

剪辑页同时播放原视频和当前成片时，两段视频都带有音轨。原声、配音和背景音叠加会造成听感混乱，也无法判断当前正在核对哪条声音。

## 决策

- 两个播放器继续同步时间和播放状态，但联动试听默认只播放当前成片。
- 在当前成片参考工具栏提供“声音来源”三选一：当前成片（默认）、原视频、静音。
- 切换声音来源只切换两个媒体元素的 `muted` 状态，不改变各自音量值；因此用户可以在保持监听音量的情况下快速比较两条音轨。
- 即使关闭联动，仍保持唯一声音来源策略；用户切换来源后即可单独试听另一条，避免误操作再次叠音。
- 非选中播放器的静音按钮不能绕过该策略；选中播放器仍可按需静音。

## 验证

- `frontend/tests/outputCutsEditor.test.ts`
- `npm run typecheck`
- 浏览器中确认联动播放仍只保留所选音轨
