# ADR-0043：最后的发布阶段与显式 AI 文案助手

日期：2026-09-27。状态：采用。

界面入口约定已由 [ADR-0116](0116-project-publishing-and-account-navigation.md) 更新：项目第8步发布，设置管理账号，项目列表保留跨项目记录。发布领域边界继续适用。

## 界面是最后一步，领域不是制作管线的一步

项目侧栏与总览在合成之后显示「08 发布到B站」，沿用独立发布领域和既有项目发布路由。全局发布中心继续管理跨项目队列和模板。导航只读本地最近更新稿件的摘要，不读取账号凭据、扫描视频或请求B站；单独加载失败不影响制作步骤状态。

不把发布加入 STEP_ORDER、StepRun、输入指纹或自动执行队列。制作完成不等于已发布，「运行勾选步骤」永远不会上传或投稿；上传、确认投稿仍分别明确确认。上传完成、待审核、仅自己可见与公开发布保持不同状态。

## AI 只产出候选文案

复用已配置 LLM，显式点击生成标题、简介、标签和动态。领域边界白名单拒绝其他设置。仅发送有界平台资料、当前文字及最新整理稿的均匀字幕节选；不发送账号、Cookie、配置、视频文件或本地来源路径。来源署名由程序保留，缺少字幕明确告知。过期字幕或摘要不作为证据，不能把原文指令当成系统指令。

候选不写数据库、不修改制作状态。用户可选择字段、只填空缺或应用所选，然后另行保存。AI 不决定版权、权利确认、创作声明、账号、可见性、分区、合集或发布时间。服务端修订检查与同稿件并发门禁防止无效请求和旧结果；界面再次检查生成时的文案与稿件身份，不能覆盖生成期间的新编辑。模型请求不占用发布锁或数据库事务，校验与重试有界。

## 开关事件与适配范围

Naive UI 的 NSwitch 根元素是非原生 `div role=switch`。外层 HTML label 会将其第一个原生按钮（恢复继承）作为关联控件，点击开关可能额外激活该按钮。使用具名分组 div 替换包围整组的 label，保留开关自身无障碍名称；继承按钮独立操作。锁定稿件显示不可编辑的原因。

对照固定版本 biliAPI 2.15.0 与上游实际集成，转载不传水印，界面显示不适用；原创/其他类型显式传 state 0/1。创作声明采用组件映射时说明来源，不能假称账号实时返回。合集在回执后独立加入。

当前不是官网全部功能的镜像：话题活动、商业/付费推广、卡片、章节、平台外挂字幕、杜比/Hi-Res、空间隐藏未接入。平台权限和最终参数校验仍须真实账号联调，单元测试不等同真实投稿验证。

参考：[biliAPI 投稿实现](https://github.com/renmu123/biliAPI/blob/master/src/platform/index.ts)、[上游发布界面的字段映射](https://github.com/renmu123/biliLive-tools/pull/454/files)。

## 验证

后端全量739项、前端158项、通信组件21项测试通过，前端生产构建通过。实际内置浏览器核对了第8步导航、AI入口和表单布局；点击「关闭弹幕」保持开启，独立点击恢复继承后回到原值且保存按钮恢复禁用。测试改动未保存，没有上传、投稿或真实LLM调用；未启停用户常驻服务。后端保留两条既有依赖弃用警告。
