# ADR 0022：列表选择统一用于试听和成片

日期：2026-09-24。状态：采用。取代 ADR 0021 中的本机试听偏好及参数变化即禁用旧音频的约定。

## 决策

- 项目 `dubbing_edit` 按句保存原声/配音及选定版本，绑定译文和时间轴。试听与成片读取同一份选择，无额外传递操作；列表复选框仅用于批量操作。
- 声源和版本切换先更新本句试听，再独立保存；只锁定本句的选择控件，保存失败恢复原选择。保存完成前禁止发起合成，避免成片使用旧选择；后台列表刷新不阻塞操作，保存前发出的旧响应不能覆盖新选择。
- 每句保留多个配音版本：首版继续使用 `<句id>.wav`，更多版本使用 `<句id>_v<版本>.wav`。选择现有版本时合成覆盖它，选择空位时合成新增版本；成功后选用新结果。始终保留空位入口。
- 原声按句截取分离人声；配音按实际长度铺轨；空位不加入此句人声，不删除时间、视频或背景。全空位也能输出。依赖只检查实际选中的音频；缺失的已选版本不能自动换成原声。
- 无声提示与试听共用声源判断：空位和失效的已选配音用琥珀色底、静音图标和文字标记，并可按“无声”筛选。空位提示保留背景与画面；失效配音提示成片前需处理。仍选用原声的未配音句子不标为无声。
- 句子列表固定原文在上、译文在下；当前实际声源对应的文字更大、更亮，切换原声/配音只改变主次样式，不交换位置。静音空位两种文字均作次要显示。
- 新工程未生成配音的句子默认原声。明确编辑为原声/空位后，步骤级“补齐配音”不改变该选择；列表“合成所选”是明确的生成操作，仍可生成这些句子。全选列表即批量合成全部。
- 单句、列表批量与步骤级“补齐配音”共用当前句和服务阶段进度；IndexTTS 通过 Gradio 任务状态读取，百分比沿用服务原值，条形更新时用 0.8 秒过渡，不按时间自行增长、不估算剩余时间。未上报进度的服务仅显示“合成中”；进度只在本次合成期间保留，完成或失败后清除。列表顶部显示当前合成编号并提供定位入口，复用缓存的句子不显示为正在合成。
- 生成快照记录输入身份、参数指纹和文件版本，参数变化后旧版本仍供对比和成片，同时提示“使用之前参数生成”。文本、时间轴或文件改变会使旧版本无效。旧文件没有快照时仍采用原有严格缓存校验。
- 满意标记绑定具体音频版本，只作质量记录，不是完成或导出门槛；覆盖该版本后标记失效。步骤强制重跑和中断清理不删除其他配音版本。
- 人声/背景音量默认 1，配音页和成片参数共用保存值。成片可另外应用响度归一、句首尾淡化和背景压低；实时预览不模拟这些后期滤镜。
- 音量调整即时试听、后台串行保存，连续修改合并为最新值，不锁定页面；旧轮询不能覆盖新音量。保存失败保留试听值并提供重试，保存完成前禁止从本页发起合成。音量参数与句子选择的服务端写入共用锁，避免同时修改项目参数时相互覆盖。
- 视频是唯一主时钟；切换声源/版本不重建或定位视频。小音频漂移用有限变速追齐，开始播放、拖动或明显偏移时才定位音轨。单句与连续播放共用此逻辑。
- 配音时长优先取浏览器媒体的实际值；到达时间轴边界后，已开始的配音以媒体自然结束为准，不按视频时间提前暂停或释放尾音。视频先结束时允许剩余尾音播完；手动暂停、定位和切换声源仍即时生效。
- 当前播放标记在句间保留到下一句起点，语音结束后由绿色变为灰色“句间停顿”；单句试听只标记正在试听的句子。所选配音超过下一句起点时显示超时秒数及调整建议，不自动裁剪、拉伸或移动用户的音频。

## 验证

隔离测试覆盖多版本新建/覆盖/强制重跑保留、逐版本满意、空位与原声的真实铺轨、实际选定文件依赖和指纹变化。前端测试覆盖区间勾选、空位静音、版本切换不写视频时间、音频漂移；独立 8611 实例做浏览器操作验证。
