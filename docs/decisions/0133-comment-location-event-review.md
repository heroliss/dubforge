# ADR 0133：高敏感地点与暴恐事件组合的评论复核

日期：2026-10-11。状态：已采用。

## 问题

顺序发布的第 7 项 `fc5fd6` 在 B 站被退回，平台指出 P2 的 `00:05:26–00:06:01`。生成快照里的第 13 条评论于 `00:05:30–00:05:45` 叠加，内容同时包含“全国最敏感的地方”“确实发生过恐怖袭击”及英文 `most sensitive place / terrorism`。它的模型评分为可入选，本地规则只识别 `Tiananmen + tragedy/massacre` 或自定义词，因此确认和最终合成都保留了这条评论。

区间重合是定位依据，不能证明这是平台唯一的退回原因。修改当前评论工作区也不会改变已上传视频里的像素。

## 决策

- 在评论入口增加组合复核规则：同一语言文字的 600 字符范围内同时描述“最敏感的地方/地区/区域/场所”或 `most sensitive place/area/location`，以及恐怖袭击、恐怖主义、暴恐、`terrorism/terrorist attack` 等事件表述时，先整条排除上屏，并给出“需人工复核后再上屏”的明确原因。
- 不由单个暴恐词或普通地名推断风险；新闻学习、反恐与安全主题在没有该组合时不命中。字幕文字继续使用 ADR 0082 的现有窄语境规则，不新增声音静音范围。
- 复用现有人工决定机制，按这条评论的原文、译文与规则证据绑定决定；允许复核只对该证据有效，不创建全局白名单。
- 规则版本更新为 `local-context-v2`，内容审查报告、成片指纹和投稿前门禁均按新版本核对。历史快照中的评论仍需要检查，当前编辑区已移除它不能证明旧视频已处理。
- 原评论与译文缓存保持原内容；实际新成片使用经过筛查的评论方案，不改写第三方评论。

## 验证

隔离领域测试覆盖中英文组合、普通旅游、单个暴恐词、反恐新闻、安全主题、历史快照仍被阻断、最终渲染过滤以及不扩大字幕声音处理范围。

## 限制

文本规则不是平台完整审核模型；同义改写、画面和未转写声音仍可能漏检。该规则只把有证据的评论组合送入人工复核，不能宣称内容违法，也不能保证平台通过。
