# 0125 — 通用大模型参数说明

日期：2026-10-08

## 背景

模型型号、默认参数和支持档位变化较快。设置页维护各型号的推荐表容易过时，也难以涵盖第三方兼容接口。用户选择由自己查阅服务商文档并配置具体模型，工程提供稳定的参数用途与使用说明。

## 决策

- 参数说明仅描述用途、通常的影响和使用注意事项；不列出具体型号的推荐值、默认值、范围或输出上限。
- 不按模型名限制候选档位或判断配置是否兼容。常用候选只是填写便利，不能代表接口支持；未知自定义枚举仍可显示并在高级 JSON 中维护。
- 沿用服务商默认时不发送自定义值；保留用户已有参数、未知字段和嵌套扩展，不代填、不迁移、不夹紧数值。
- `stream` 的 DubForge 默认行为与服务商默认分开说明。实际请求预览继续复用运行时构造，可查看步骤覆盖、传输字段和脱敏后的最终请求 JSON。
- 保留 JSON 格式、对象结构、字段类型及运行中编辑保护。已有请求适配属于实际运行行为，不能因为移除型号推荐说明而取消；预览如实展示适配结果。
- 模型文档由用户查询；设置页不建立持续维护的型号知识库，也不自动拉取外部模型信息。

## 验证

前端回归覆盖不同模型共用说明、已有枚举和数值保留、控件与 JSON 同步、输入保护以及预览竞态与超时。验收不调用真实模型或保存用户配置。
