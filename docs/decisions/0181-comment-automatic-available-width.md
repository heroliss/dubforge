# ADR-0181：评论自动宽度使用可用画面区域

日期：2026-10-16
状态：已采纳

## 背景

旧自动宽度按横竖屏和位置分别采用 68%、90%、84%。这些经验比例是额外的排版宽度约束，既有边距和手动最大宽度已经能表达留白需求；自动模式的差异不易理解，也会使长评论过早换行。

## 决策

- 0 自动与 100% 共用扣除左右边距后的完整可用宽度，所有画幅与位置规则一致；短评论保持自然长度，不拉伸、不强制两端对齐。
- 1–99% 仍可主动限制排版区域，百分比相对整个画面且受边距约束。字号范围、软高度、锚点和边距的安全限制保持不变。
- 不改写已保存参数或用户草稿。预览和新成片使用同一规则；已有自动窄版成片保留，指纹应提示需重新合成。
- 指纹将缺省/0 宽度规范为 100，历史兼容分支也使用相同规范化，避免将旧自动窄版错误识别为最新；显式非零宽度的既有指纹不变。新自动与 100% 互换不触发无意义的成片过期。
- 审查修订配方记录实际采用的评论宽度规则，缺少记录的历史自动窄版不能按新规则归一后误判有效；历史显式宽度按未改变处理，无评论配方保持原状。

本决策替代 ADR-0180 中保留旧自动宽度比例的部分。
