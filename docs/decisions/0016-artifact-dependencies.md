# ADR-0016：步骤按需选用，运行依赖实际产物

日期：2026-09-24。替代 ADR-0003 的“必需步骤/连续勾选链”约束，替代 ADR-0011 的字幕延长重叠规则。

## 问题

步骤顺序同时承担展示、运行门禁和缓存依赖，导致跳过字幕导出后不能配音，未选步骤也影响项目完成度。配音计划原先读取原文；字幕显示参数位于 tts 配置下，也使无关配音缓存失效。

## 决策

- 保留固定的步骤列表，所有步骤按需选用，不增加通用工作流编辑器。
- `pipeline/dependencies.py` 统一解析实际输入、依赖状态、执行计划和受影响的下游。API 和界面使用同一结果；不再检查所有排在前面的步骤。未生成或已丢失的文件属于缺失依赖；有产物但需重跑属于过期依赖。正在更新和设置冲突也单独标识，统一纳入未就绪检查。
- `运行所选` 允许不连续的步骤，启动前检查整个计划。`准备依赖并运行` 先分别展示需生成和需更新的产物对应步骤，确认后执行；只有过期依赖时按钮显示“更新依赖并运行”，只有缺失依赖时显示“补齐依赖并运行”。不悄悄启用模型、分离音轨或改变字幕导出设置。失败/取消停止后续队列。同一项目依次执行，避免两个计划争用产物；不同项目可并行。
- 文件必须有登记、存在且未过期。启动时核对实际输入哈希；日常轮询只检查文件大小和指纹。某个兄弟产物丢失不会单独阻塞仍有效的文件。未留指纹的早期登记兼容消费；有指纹的旧下载、预处理、识别、语义整理和默认来源的翻译结果，在旧指纹仍匹配时继续复用。
- 新指纹只包含实际消费的文件和本步设置。字幕导出不影响配音计划或 TTS。生产者重跑时只标记真正依赖它的后续步骤；生产者输入变化后下游不能消费其旧结果。
- 项目完成度以 `auto_steps` 所选步骤计算；未选步骤的待运行或失败不影响完成。默认仍选中全部可执行步骤；工作台保留手动操作。

## 文本与字幕

原文来源选择已由 [ADR-0017](0017-semantic-source-only.md) 简化：翻译、字幕导出和配音计划统一使用语义整理结果；识别原稿保留直接下载入口。

语音转文字保留 `srt/src.srt`；字幕导出可以生成 `source.srt`、`trans.srt`、`bilingual.srt` 全部或单种。双语默认译文在上、原文在下，可交换。单语不插入固定字符数换行；最短显示时长只利用到下一句或已知内容终点之前的空隙。识别原稿和配音时间轴不受影响。

配音计划使用逐句译文和语义整理后的时间轴，严格校验编号、顺序、句数与非空。字幕导出无需运行即可配音。字幕参数移至独立 `subtitles` 配置，兼容旧的最短时长设置。

## 音频与成片

预设音色不依赖分离人声，stable/dynamic 原声参考模式才需要 `vocal.wav`。关闭人声分离仍可提取 `raw.wav` 进行识别。背景音量为 0 时成片不需要背景音；烧录开启时才需要指定字幕。外挂字幕从独立字幕目录取用，不自动复制可能过期的字幕文件。

成片逐一检查配音计划对应的 WAV，缺句不能悄悄跳过。句级音频缓存用旁置 `.input` 文件绑定文本、时间、音色和参考源；原声参考切片亦按该指纹隔离。旧配音计划因输入语义修正需重新生成，旧 WAV 无句级指纹时重新合成。试配已生成全部有效音频时可直接合成成片；部分失败的批量配音不记成功，重试复用仍有效的句级缓存。

## 验证

离线测试覆盖原文导出、最小依赖计划、配置冲突、不连续执行、所选任务完成度、缓存相关性、旧识别结果兼容、译文配音、字幕顺序/换行/时间约束、缺失音频及输入内容变化。外部 ASR、LLM、TTS 不在这些回归测试中实际调用。
