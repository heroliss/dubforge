# 0055 — 本地合集模板的删除、恢复与目标核对

## 背景

合集模板是本地发布设置，不是 B 站合集本身。模板可能被草稿、全局/项目全流程方案和历史任务引用；物理删除会让继承失败，或悄悄回退全局默认。平台列表请求失败也不能等同于目标合集被删除。

## 决策

- 模板采用 `archived` 可恢复删除，SQLite 启动时轻量迁移。全局默认不可删除。
- 删除前只读展示所有已保存引用，确认时重新核对模板版本和引用指纹。删除、恢复不请求 B 站、不修改制作步骤状态。
- 已删除模板从正常列表和新选择中移除，在“已删除模板”中只读展示、可恢复。已有引用继续使用保留的设置；全局全流程方案的继承关系也保留。删除不是停止自动流程或取消投稿。
- 已有稿件与已确认任务的冻结快照、回执不变。既有草稿仍可保存，新绑定已删除模板则拒绝，要求先恢复。
- 合集仍按 ID 绑定，改名后刷新账号选项展示新名称，不自动修改本地模板名。
- worker 返回合集列表完整性：分页失败、结构异常、重复页、总数变化、超出读取上限均不算完整。只有成功完整读取后，才提示目标合集/小节不可用；未知状态保留原 ID 并建议重试。
- 上传前和正式投稿前复用相同校验，区分“无法核对”与“已不可用”，均不得静默取消加入合集、自动创建同名合集或切换目标。

## 验证

隔离数据库测试删除确认、引用变化、版本冲突、恢复、旧库迁移、冻结记录不变、继承与新绑定边界；真实 Vue 组件测试按钮、确认/取消、只读和失效占位；worker 测试完整/不完整分页。测试不对真实账号上传、投稿或删除合集。
