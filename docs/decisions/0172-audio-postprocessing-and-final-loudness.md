# ADR-0172：逐句音量后期与最终成片响度

状态：采用。日期：2026-10-15。

## 问题

模型配音、人声/背景混音、播放器监听与最终编码响度是不同职责。原实现将人声峰值归一、PCM16 中间文件和单遍动态归一串联，背景避让由调整后的听感音量触发，最终混音没有统一测量与峰值检查。用户也无法只修正某一句音量而不重做模型声音。

## 决策

- 保留既有人声响度开关和人声/背景比例。人声整轨先测 EBU R128，再采用统一静态增益接近 −16 LUFS；不在其前面重复峰值归一。关闭人声归一时沿用原峰值语义。铺轨和中间文件使用浮点，避免尚未进入最终增益前量化或削顶。
- 新增最终成片响度模式 `off` / `normalize`，兼容默认关闭。开启时测量完整的混音、声音屏蔽和成片剪辑结果，在首次 AAC 编码前应用统一增益。真峰值空间不足时宁可保留较低综合响度，不强行动态压缩。编码后测量实际 AAC，只有峰值漂移超限才允许一次有限降增益纠偏，仍不合格则不替换旧成片。
- 原声、配音、审查修订与既有区域试合成消费同一方案。试片使用完整成品混音的测量与增益；短片的综合响度不应被误认为全片目标是否达标。测量只解码声音，不渲染整段画面。原声无音轨时显示无音轨，不伪造响度。
- 后期逐句增益独立保存在项目 `audio_line_gains`，范围 −12 至 +12 dB，绑定源句身份、声源、配音槽与实际文件版本。更换声音后保留旧修正并提示需核对，不自动套给新声。增益不修改 WAV、模型指纹、满意状态或源时间，运行锁仅占用其实际消费者合成成片。人工增益放在可选保守句间均衡之后，避免自动算法抵消人工精调。
- 可选句间均衡默认关闭；按有效声音块估计能量，中位参考、保留小幅情绪差异、修正幅度有限，绝不放大静音。此功能不替代试听，不默认引入降噪、门限、EQ、强压缩等额外处理。
- 背景避让检测信号与人声听感增益分开；人声为零时不避让。异采样率素材用带限重采样；真实剪辑接缝增加 5ms 短淡化，不交叉叠音，不改变视频或字幕时间轴。
- 成片完成时原子保存声音报告，绑定成品文件身份。GET 只读取报告，不隐式触发整片扫描。报告含实际 LUFS、真峰值、响度范围、静音区间和可定位的逐句风险；接近满幅样本只提示风险，不断言已经存在可闻失真。
- 原声直用在开启最终声音处理时需要生成独立成品。仅启用的后期字段与有效人工输入影响成片新鲜度；关闭的新默认键或空逐句记录不使历史成品失效。旧文件保持原样，显式重合成使用优化后的处理链。

## 验证

隔离测试使用实际 FFmpeg 检查整轨 LUFS、真峰值、静音、AAC 后实际值、输出时长、超过满幅的无损混音在首次有损编码前降增益、带限重采样、逐句身份与版本并发保护、均衡限幅与默认关闭兼容。既有成片、区域预览、多版本、审查修订和剪辑测试继续运行；不启动真实模型，不重启用户制作服务。
