# 0071 批量创建项目的清单与确认边界

日期：2026-09-29

## 决定

- 项目空间提供统一批量导入入口；纯文本一行一个网络视频或本地绝对路径，结构化清单采用 `dubforge.batch.v1` JSON。浏览器读取文件内容后提交文本，服务端不接受任意清单文件路径。每批1–100项、最多1MB。
- 先只读解析/预览，再明确确认所选项目。导入不调用外网或模型，不展开频道/播放列表，不执行工作流。新项目之后复用现有批量运行预检，不增加第二套运行配置。
- 模板优先级为预览逐行选择、项目指定、清单默认、界面默认、全局。只写清单明确给出的参数作为项目稀疏覆盖，其余保持 ADR-0058 实时继承。环境连接与凭据字段禁止从外部清单写入。
- 重用统一配置/版本校验；前端只传文本、模板选择、勾选序号及预览指纹，不提交自行拼装的可信项目计划。导入时重新验证内容、模板指纹及本地来源。
- 同批和已有项目的重复来源默认不选，但允许用户明确选择另建。YouTube 各链接形式按视频标识去重；其他网络链接保留查询参数，本地路径按平台路径规范化。不访问 URL 来判断可下载性。
- 请求 UUID 绑定输入摘要与冻结计划。新增持久化回执；每项的项目、步骤、配置与成功回执同事务提交。双击、并发重试、断线重试只补失败项；已成功后删除的项目不重建。服务使用现有单进程模型，进程内锁串行化导入和目录命名。
- 目录只由本次排他创建，事务失败才可清理；数据库提交后清单文件写入失败不得删除已登记目录。manifest 继续原子写入并给出可见警告。
- 浏览器会话保存正在执行批次，状态轮询不得覆盖较新的最终回执。未知执行结果保留原 UUID，禁止另起批次；确定拒绝可回到编辑态，已完成的失败项可单独转成新清单。
- LLM 使用指南从当前参数元数据与实际模板列表生成，不复制当前设置值和密钥；静态样板与动态样板都纳入测试，避免版本参数漂移。

## 限制

导入不验证外站链接的可下载性、B站权限或服务可用性，这些由运行预检和对应步骤负责。浏览器会话存储不是完整的批次历史中心；关闭标签页后仍可通过已有项目重复检测避免误建。
