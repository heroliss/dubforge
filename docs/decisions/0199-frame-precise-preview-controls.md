# 0199 · 通用视频预览逐帧定位

## 状态

已采用

## 决策

- 所有共享视频播放器提供上一帧、下一帧按钮；播放器获得焦点后，逗号和句号也可逐帧移动。
- 逐帧操作自动暂停，按帧序号计算目标时间并限制在媒体首尾；长按逗号或句号允许连续逐帧。
- 成片剪辑编辑器的源视频通过 ffprobe 读取平均帧率并传给播放器；没有可用帧率时显示“约 30fps”，不把估算值宣称为精确帧率。
- 起止标记仍保存源时间轴秒数，用户可逐帧定位后点击“当前位置设为起点/终点”，再保存删除范围。

## 原因与边界

浏览器没有跨浏览器可靠的编码帧率属性，也没有统一的“下一帧” API。播放器只能用已知帧率换算 `currentTime`；可变帧率视频使用 ffprobe 的平均帧率或回退近似步长，必要时仍可输入毫秒时间并在最终 FFmpeg 处理中核对帧边界。逐帧控件用于字幕、章节、配音同步和片段审查，不改变源视频或剪辑方案，只有保存剪辑方案后才进入制作流程。
