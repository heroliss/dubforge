# 0146 语义整理思考预算与预览字幕换行

## 状态

已采用

## 决策

语义整理的正文受响应体积和格式守卫保护，reasoning 通道不按字符数截断，也不因文档长度自动关闭显式思考。low、high 或跟随模型配置等思考设置保持原样；reasoning 只受整次请求的总超时约束。正文预算错误只允许切换到已配置的其他候选，避免重复发送同一条会再次超限的请求。

`split.target_word_count` 保持软参考。完整语义、声学停顿和词级时间锚点优先，避免用机械字符或词数切割破坏配音节奏；界面明确标注为“软参考”。

浏览器预览使用的 WebVTT 在生成时按显示宽度插入保守换行：中日韩字符按双宽度估算，英文按单宽度估算，双语保留语言分界，超长无空格标识符也允许断开。换行只改变预览 cue，不改正式字幕文字和时间。

## 原因

思考型模型可能在返回时间轴正文前生成较长的内部推理。不同模型的思考长度差异很大，按字符中止会误伤正常的 low/high 配置，因此改用总请求超时作为唯一兜底，正文仍由体积、格式和退化检查保护。浏览器原生 WebVTT 对长 CJK 或混合文本的自动换行并不稳定，预览层先换行可以避免尾部被裁掉，同时不污染制作产物。
