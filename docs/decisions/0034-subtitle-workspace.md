# 0034 — 集中的字幕设置与页内烧录预览

## 背景

烧录预览原在侧边抽屉，样式同时出现在抽屉和合成步骤参数中；导出参数另在导出卡片里。用户无法同时看效果与全套设置，也难以判断修改在哪保存、是否已用于成片。

## 决策

- 「字幕与配音」采用「校对与配音 / 字幕工作区」两个页内标签。字幕工作区左侧是实际 FFmpeg 单帧效果，右侧是分组设置，下面是导出与文件。小屏按相同顺序纵向排列。
- 合并 `assemble.subtitle_*` 与 `subtitles.*` 的表单，复用现有项目参数端点，一次读取、一次保存。保持领域配置归属、指纹和项目覆盖不变，不迁移旧项目数据。
- 合成页仅显示已保存字幕方案摘要和直达链接；混音、画质及流程／试片默认烧录开关仍归合成页。删除旧预览抽屉与导出卡片的重复表单。
- 编辑只更新草稿；停止调整 650 ms 后自动预览。传入双语顺序与最短显示时长，与实际导出的字幕构建共用逻辑。请求串行合并，旧草稿响应不得覆盖新画面，隐藏工作区停止自动请求。
- 页内切换保留编辑状态，离开页面／切换项目步骤／刷新时提醒未保存。草稿未保存时禁止导出、禁止返回合成执行；允许放弃草稿。预览不保存配置、不生成正式字幕或视频。
- 字幕工作区不展示全项目配音运行入口及历史配音日志；运行中的任务控制仍保留，避免操作归属混淆。

## 验证

前端覆盖跨步骤保存、失败保留草稿、放弃修改、重复控件过滤、预览串行与过期响应、隐藏／无视频及错误状态。后端覆盖草稿顺序／时长不落盘、非法参数拒绝与组合保存失败不产生部分更新。浏览器检查真实页面、标签间草稿保留、合成入口回跳和响应式布局。
