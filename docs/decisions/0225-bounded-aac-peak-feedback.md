# ADR-0225：AAC 编码真峰值的有界反馈纠偏

状态：已采纳（局部替代 ADR-0172、ADR-0183 中的单次 AAC 纠偏约定）

## 背景

无损完整主音轨符合目标，仍不能保证编码后的 AAC 真峰值符合上限。单次按超出量加 0.3 dB 余量降增益后重新编码，新的 AAC 瞬态可能再次超限。旧实现会在二次复测通过之前替换内部候选；外层虽能保留旧正式成片，但仅有通用错误，清理临时文件后无法追溯初次峰值、纠偏量和复测值。

## 决策

- 保持编码前的完整混音测量、uniform 无损主音轨、normalize 固定增益以及 off 语义。目标参数和原有 0.05 dB 编码复测容差不变，不通过关闭处理或放宽阈值恢复任务。
- 实际 AAC 超限后，最多三次反馈纠偏；每轮累计降增益为上一轮累计值加当前实测超出量及 0.3 dB 余量。累计衰减最多 24 dB，遇到边界或尝试耗尽仍未达标则失败。
- 每轮从同一原始编码候选生成新候选，只重编码声音，视频直接复制；不串联多代 AAC 纠偏。仅在复测通过且取消检查通过后原子替换候选。未收敛、取消、测量或编码失败均清理临时候选并保留原候选，正式产物继续由既有外层原子提交契约保护。
- 日志保存初次实际 LUFS/真峰值、目标、各轮累计衰减和复测值。成功报告 processing 附带反馈过程；失败沿用公开错误码 `AUDIO_TRUE_PEAK_EXCEEDED`，中文消息含目标、最终实测和尝试次数，detail 含结构化过程。不能从已删除的旧候选推测历史实测值。

## 取舍与验证

正常达标的 AAC 不增加编码。纠偏仅保留最终选定候选，其声音会经历一次额外 AAC 编码；各次尝试独立以原候选为输入。直接从无损主轨重封装需要把试片、剪辑、原声与配音的准确声音范围贯通至 finalize，本轮不扩展该契约。

隔离 pytest 覆盖三轮后收敛、不能收敛、累计衰减上限、原候选和旧正式成片/报告保护、取消及子处理失败、静音、off、normalize 和 uniform。短真实 FFmpeg 样本验证编码后真峰值复测通过、声音确有替换且视频流 hash 不变；不使用用户媒体、模型或平台发布，不据测试成功宣称生产已恢复。
