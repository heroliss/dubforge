# 0194 · 按内容选择成片更新

日期：2026-10-17

## 目标与合同

已有成功成片、当前工作稿与本次目标是三个不同的对象。差异清单只显示实际变化，用户勾选的是内容，不是编码时间窗。本次目标从成功基线复制，仅把选中差异替换为当前值；未选内容保留历史输入，并在成功后的下一次对照中继续待更新。

同一成片定义原位更新，沿用版本 ID。选择方案是本项目不可变的 `update.plan_id`，不是新增一个供用户管理的声音/语言版本。成功原子替换该版本的成品与成功记录；失败保留旧文件和旧记录，可重试同一方案。旧式手工时间范围修订仍独立存在，明确其范围内采用当前画面的语义，不能冒充内容选择。

## 可重建依据

`sentence_inputs` 继续提供实际事件比较；新增 `render_manifest` 保存字幕语言分段、逐句音频引用与偏移、各条评论的完整样式和独立时段、输出参数及已应用审查结果。逐句声音和背景采用内容寻址的必要素材副本，原子落盘并去重；源视频保留可核验引用，不复制整条大视频。读取差异不创建素材或扫描大媒体。

旧记录只从真实成功证据恢复；缺少逐句记录、语言分段、评论样式或必要声音时明确提示历史能力限制。声音缺失不妨碍保留基片整轨的纯视觉局部更新。不能把当前工作稿、文件日期或编辑前 base 当成已经烧录的历史。旧式局部更新的混合证据未经完整重建时，不附虚假的整份当前稿 manifest。

## 选择与执行

`update-plan` 检查所选差异 ID、基片、目标设置组合与必要素材；`update-create` 绑定基片摘要、目标清单、明确选择与检查摘要，并保留独立基片。计划引用只能在所属项目解析。真正运行前强校验基片和实际消费的素材。

可安全复用的视觉改动沿用现有等时局部编码；声音、全局设置、剪辑等走完整生成。编码方式与是否替换声音独立：仅改字幕样式等全局视觉项时，完整重绘画面后直接复制基片整轨，不要求旧逐句 WAV、不重新混音或归一。两种方法都消费同一个目标清单，不再读取未选的当前字幕、评论、配音槽或重新排布声音。整轨均衡、峰值/响度处理属于明确联动项，确认前说明完整音轨的音量可能变化。时间联动、字幕轨道开关、审查效果与剪辑渲染修复等不可拆分影响统一展示依赖，后端拒绝缺少关联项的请求。

渲染时填充共享字幕预备缓存，防止双语/审查支路重新载入当前工作稿；显式评论事件与冻结审查终态不再二次套用当前筛查。成功快照只记录实际目标输入，运行时计划不递归写入成功历史。

## 自动流程与界面

差异可逐项、分组、全选或取消。刷新保留用户取消选择，新出现的变化不静默勾选；不同基准重新初始化选择。未知历史不作为精确差异行显示。预检给出应用/保留数量、生成方式、范围及联动影响；确认后自动保存方案并通过统一版本预检启动生成，不增加重复确认。

选择性版本的制作内容固定，名称可修改；进一步修改在差异清单选择下一次更新。版本状态显示“所选改动已应用”，不把方案完成称为所有工作稿已同步。同一版本 ID 继续由现有流程/分P引用，不会同时多出普通基准和更新子版。界面明确后续生成和自动流程沿用固定方案，并提供“改为采用全部当前内容”：先改为普通版本草稿，明确保存后后续生成才跟随全部最新工作稿。排队转运行不把最新项目剪辑灌入固定方案；自动评论准备和当前配音检查不影响只消费历史清单的版本。缺失成片重试仍执行原固定方案，不能改成全量工作稿；复制新版本供重新编辑时解除固定方案。

## 修订入口收敛（2026-10-17）

`AssemblyChangesPanel` 统一持有唯一基准及互斥的“按改动更新 / 按片段重制”模式。已知差异采用前述精确选择契约；旧成片无可比较历史时默认展示片段模式，不能将编辑记录冒充尚未应用的差异。手工候选、全部句子和搜索结果共用 `AssemblyPartialEditor.lineIds`，不再由父级复制一套勾选、声音开关、预检和创建逻辑。嵌入编辑器不显示第二个基准下拉和展开入口；时间段与名称渐进展开。

片段模式明确选定时间段使用当前全部画面内容，范围外沿用基片，声音单独选择，输出为独立版本。两模式均为“选择 → 检查 → 确认生成”，确认后由同一版本工作区保存、预检和运行；保存或运行失败保留方案以供重试。普通版本列表的勾选语义为选择要生成的版本，与上方内容选择有明确标题区分。

跨页带入继续验证项目、有效时间和基片 ID/摘要。句子新旧位置由后端依据最终勾选重新计算，不能把旧的合并范围作为显式附加范围留在取消选择之后。切换基准清空旧范围，筛选/搜索不丢失勾选，刷新不卸载正在编辑的范围表单。

## 验证

领域测试覆盖同窗字幕/评论独立选择、音频覆盖保护、旧历史拒绝、关联与组合校验、同 ID 连续更新、失败保留和重试，以及真实编码和自动流程。浏览器验收仅使用 8611 与隔离数据；第二个项目的真实片段和字幕用于建立可证明的新基线，再验证先更新原405句、保留原406句，随后更新406。真实生产旧成片缺少逐句历史，不冒充已恢复；生产素材、常驻服务和 B 站稿件不作测试性修改。
