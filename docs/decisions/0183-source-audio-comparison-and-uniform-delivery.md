# ADR-0183：原片声音对照与跨项目统一响度

状态：采用。日期：2026-10-16。补充 ADR-0172。

## 问题

播放器监听、配音与背景的比例、成片总体响度属于三个不同职责。跟随原片总体音量会继承原片之间的偏差；仅依靠固定增益又会因峰值空间不足而无法统一输出。旧报告的完整混音参考也不能充当原片测量。动态处理若分别作用于试片和整片，会产生试听与最终输出不一致的问题。

## 决策

- 三层操作语义一致：本机监听只改变播放器；人声与背景平衡作用于混音；统一输出响度作用于最终完整混音。全局、项目和版本使用相同字段、分组与帮助说明，继续保留显式继承及版本覆盖，运行任务仍消费冻结的设置。已有配置和旧成品不被自动改写。
- 保留 `off` 与仅固定增益的 `normalize`；增加 `uniform`，面向跨项目一致性。统一模式先测量完整的剪辑后混音，再执行两遍响度处理：峰值空间足够时使用线性增益，否则使用动态处理。LRA 上限取算法允许的 50 LU，避免额外要求收窄正常声音起伏；真实处理方式写入报告，动态处理不伪装成固定增益。
- 统一模式缓存完整的 48 kHz 双声道无损 FLAC 主音轨。源声音、混音设置、审查声音屏蔽、成片剪辑和目标参数共同决定缓存；临时铺轨按内容标识。字幕、评论或画面变化不应无故重做相同声音。操作系统文件锁、取消检查、文件摘要及音频格式和时长检查保证并发与中断恢复；失败不得替换有效成品。
- 试片从同一完整主音轨按成品时间轴截取，不再次归一、裁剪或屏蔽。原声、配音和审查修订的最终输出均在 AAC 编码后实测，沿用一次有限峰值纠偏与上限检查。首次统一处理需要扫描完整声音；复用缓存时不重复处理整片。
- 原片对照读取真实源视频，使用与当前输出完全相同的源时段、剪辑保留段及接缝短淡化。单独缓存原片测量；普通对照错误显示原因但不丢弃合格成片，取消、超时和中断继续向上抛出。GET 只读取已保存报告，不隐式扫描长视频。
- 报告显示原片同范围、当前输出和统一目标，明确源时间与输出时长；完整主音轨编码前基准与局部试片分开展示。试片不判断整片目标是否达标，短于 60 秒的 LRA 标为统计参考。历史完整混音参考仍保留原义，缺少原片对照时不伪造数据。
- 指标名称、数值与相关设置统一提供悬停、问号及键盘说明，解释单位、范围、生效条件与操作建议。产品建议可选择 −18 至 −16 LUFS 的一个固定目标及 −1.5 dBTP 上限，不声称属于 B 站官方标准。总体 LUFS 不能证明人声与背景协调，仍需试听；原片始终只作参考。

## 验证

隔离的真实 FFmpeg 回归覆盖不同输入接近同一目标、线性增益真实倍率、峰值受限动态处理、静音、超满幅浮点输入、剪辑与跨接缝试片、原片身份与范围、无损主音轨复用、缓存损坏及并发、取消与失败清理。前端检查指标帮助、历史报告兼容、短片语义、三层设置、继承覆盖，以及关闭处理时禁用但保留目标值。网页验收只在 8611 的隔离数据中运行，不调用模型或发布平台。

技术依据：[FFmpeg loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm)；[EBU R 128 的总体响度、响度范围与真峰值描述](https://tech.ebu.ch/publications/r128)。EBU 的广播目标并非本产品建议的网络视频目标。
