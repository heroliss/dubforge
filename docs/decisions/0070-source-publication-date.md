# 0070：发布简介保留原视频日期

日期：2026-09-29

## 决策

- 普通草稿和 AI 文案共用来源署名逻辑，自动附加原作者、原视频发布时间和来源链接。
- 日期使用已采集、校验通过的平台 `release_date`，缺失时使用 `upload_date`；只有日期就只输出日期，不补造时分秒。不使用下载时间、资料刷新时间或文件修改时间。
- 来源事实由程序追加，并计入 B 站简介 2000 UTF-16 单位上限；自动摘要可以截短，但来源署名应保留。重复生成不重复添加来源行。
- AI 可以看到日期作为文案证据，但输出的来源行不能取代平台资料。
- 全流程默认文案也走上述规则；系列模板、项目和稿件的手写简介保持原有继承/覆盖关系，不暗中改写。
- 已有可编辑草稿可在简介标题旁点击“补入原视频日期”。该动作只改当前表单，需要用户保存；超长时提示精简，不截断手写内容；不会操作已发布稿件。

## 验证

覆盖有效日期与错误日期回退、缺失日期、AI/非 AI 自动流程、重复来源行、emoji 长度、草稿刷新只读、手写文案保护和界面锁定等回归。
