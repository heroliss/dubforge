# ADR-0184：试片工作区、历史管理与编码资源保护

状态：采用。日期：2026-10-16。延续 ADR-0174、ADR-0183。

## 问题

试片生成按钮与任务状态分散，静帧、短片、正式成品和测量报告同时占据主区域，用户难以判断当前动作、进度和结果。页面重新载入后，旧试片缺少生成快照而被一概认为过期；磁盘保留的部分试片登记却在下次运行时清除，无法完整管理历史。4K60 软件编码自动选择线程，又会在其他大型应用占用提交内存时放大帧缓冲压力，最终只显示笼统的 FFmpeg 失败。

## 决策

- 版本工作台按真实操作顺序组织：调整当前版本、试片验证、确认后生成正式成片。版本清单紧凑展示；编辑与试片在宽屏并排，窄屏堆叠。审查、项目基础与剪辑、静帧排版、正式声音报告及完整成品文件属于辅助内容，默认收起或按需挂载，避免同时加载多个不使用的播放器。
- 试片生成、提交中、排队、运行阶段、真实进度、失败及停止均紧邻有声预览。沿用共用执行过程组件，按 job 与版本识别任务归属，不把其他版本或正式成片的任务误认为当前试片。已接收任务不依赖整页刷新才反馈；提交结果未知时先核对状态，禁止盲目重发。运行使用冻结快照，本页之后的新调整留待下次试片。
- 有声试片成功后自动显示新结果；失败或停止保留上一次成功结果。静帧只用于字幕与评论排版，另作次级展示；关闭时不自动计算静帧。数值测量靠近其对应结果，完整成品与局部试片继续沿用 ADR-0183 的同轨声音语义。
  2026-10-17 补充：快速画面预览与原片定位条放在同一区域，明确显示取景时间；仅字幕/评论版本显示。此处移除密集字幕刻度，保留前后定位。相同状态轮询不触发重取帧，相同画面复用；明确手动刷新可重新取帧，关闭预览中止待处理请求。
- 试片原子保存安全生成快照，绑定实际文件身份、源时间范围、版本生效参数、评论及剪辑方案、任务与输入指纹，不保存服务凭据。界面只在已知信息吻合时说明参数与范围一致，明确这不等于上游素材仍未变化；旧资料缺失时说明历史信息不完整，不伪造一致或强制失效。
- 试片历史只读列举合法项目输出文件，兼容旧磁盘孤儿，保留后续合法试片的登记。提供按版本播放、时间与大小、目录及资源快照。回收使用已有可恢复回收机制，先核验整个选择的文件身份、项目锁及发布引用，再执行；保护当前播放及最新试片，不允许操作正式成品、源文件或其他目录。部分失败如实返回结果，不宣称移入回收站会立即释放磁盘空间。
- 编码统一约束视频解码、滤镜与输出编码线程，保留画面 CRF、preset 与音轨策略。检查输出磁盘、系统盘、临时目录和 Windows 提交内存；未知或一般压力只提示，已知最低写入空间不足或提交余量几乎耗尽才停止。真实 malloc/ENOMEM 和磁盘满映射为可恢复的中文稳定错误，并保留旧成品，不自动关闭外部应用或修改分页文件。
- 清理由产物创建者负责：铺轨失败清理本次 WAV 与完整临时副本；版本最终收尾覆盖铺轨已返回但封装前取消的边界。静帧、滤镜及审查中间文件使用项目工作目录，避免把体积性工作默认为系统盘。

## 验证

领域与 API 回归覆盖线程参数实际可执行、同轨试片与裁剪、内存和磁盘错误分类、系统盘低空间不误挡输出盘、异常清理、原子快照、旧历史只读发现、范围播放、身份变化、归档/运行/发布门禁和回收恢复。前端覆盖任务归属、重复提交、迟到响应、不同版本切换、旧结果保留、历史操作与响应式布局；真实 Chrome 只操作 8611 的隔离小媒体项目。所有本轮测试临时目录设在 D 盘。
