# ADR-0120：绑定证据的人工复核与短片核对

状态：已采纳，2026-10-08。

## 问题

本地文字规则只能识别部分语境，需要人工判断误报。原面板缺少逐条复核和片段听验入口，关闭检查时仍可能显示「未命中」，候选成片也可能把仅处理字幕的结果显示成声音已经处理。

复核不能变成全项目词语白名单。字幕、原始识别稿、评论译文或时间变化后，旧判断不能静默套用到新内容。确认和备注本身不改变字幕或声音，也不应造成不必要的重新制作。

## 决策

- 保留 ADR-0082 的本地规则、原文和派生产物边界。此次不增加模型调用，不在语义整理或翻译阶段改写审查内容。
- 报告分别展示原始识别稿、整理原文、译文和评论的检查数量，标明规则版本和本次检查时间。关闭、缺少文字、部分译文缺失、规则未命中是不同状态，都不等于平台审核通过。成片候选保留服务端给出的处理状态，包括声音未静音。
- 项目根的 `content_review_decisions.json` 原子保存人工决定，使用独立递增版本。每项包含稳定的证据键、证据指纹、允许或屏蔽的决定、备注和时间。未复核项继续按原有规则自动屏蔽；确认屏蔽不改变其效果；允许误报只解除该项自动屏蔽。
- 证据身份绑定实际命中的文字、时间、相关上下文及规则版本。周围未参与命中的文字供人阅读，无关编辑不使决定失效。字幕和原始识别稿分别复核，人工时间区间仍独立生效；解除其中一项不隐式解除其他重叠命中。
- 评论在挑选、保存、实际渲染和发布检查中使用一致的命中身份。保存方案冻结核对所需的原文及译文依据，不能用今天的缓存推断历史画面；其他评分、可用性和内容筛选仍各自生效。
- 人工决定的保存校验配置版本、配置指纹、决定版本和证据指纹。旧页面或生成期间变化返回可识别的冲突，让用户刷新核对。运行期间沿用已有编辑锁，不允许更改制作依据。
- 制作指纹只吸收实际范围或评论选用效果的变化，确认时间、备注和无关复核不影响制作。原文、译文、TTS 缓存保持原有独立输入。已生成文件仍按文件哈希和生成时的审查凭据执行发布门禁。

## 原声片段核对

点击一条时间命中后，按需生成同源的「处理前」与「当前屏蔽效果」短片，默认包含前后各两秒，最长20秒。只使用源视频原声音轨，沿用当前字幕轨、样式、最短显示时长及派生屏蔽规则；处理后使用正式输出共用的音频范围和滤镜。页面明确说明没有混入中文配音、评论或删除画面，不能替代最终成片核对。

通用审查面板未指定某个成片版本。核对短片始终展示当前字幕轨供前后比较，并按实际展示的字幕计算隐藏数量；不能用旧的项目烧录开关推测版本效果。最终成片的字幕开关和轨道仍以各版本方案为准。

播放器只有一个，不自动播放，切换或退出释放旧流。生成最多一个并行编码任务，限制线程并缩小到最高720p。相同媒体、字幕、配置与实际处理范围复用片段，项目最多保留近期16组缓存；缓存不登记为成片，不改变流水线完成状态。

片段先写临时文件，生成后再次核对源文件、文字、所选配音尾音和当前规则，再原子转正。地址只接受本项目缓存指纹和固定模式，支持 HEAD/Range。生成期间变更不返回旧效果。

## 验证

隔离测试覆盖确认不改变制作指纹、允许与重叠命中、证据失效、评论各环节和并发冲突。真实 FFmpeg 短片测试比较处理前后音频能量，验证命中区间静音、区间外仍有声音，并覆盖字幕隐藏、缓存复用、20秒限制、失败清理、编码槽位释放和媒体 Range 响应。前端覆盖准确状态、覆盖范围、逐条操作、旧请求、配置草稿保护和单播放器切换。

## 限制

规则仍可能漏掉语义改写、画面文字及未识别的声音。人工允许只是该项目当前证据的复核决定，平台判断保持独立。长片段会明确提示此次只核对前20秒；完整画面、配音和最终文件需要另行核对。
