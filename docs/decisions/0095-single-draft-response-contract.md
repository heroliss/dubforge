# ADR 0095：文本生成的单份结果契约与流式验收

状态：接受，2026-10-07。

## 问题与证据

首个项目任务 #287 在约 86 秒内返回一版覆盖全片的编号时间轴，随后正文包含自我检查、从 1 重写和持续重复，直到用户取消。独立 `reasoning_delta` 仅 27 字符，`assistant_delta` 共 59,520 字符。旧流程必须等整个响应结束才解析，活动中的 token 又会重置网络读取超时，因而异常生成无法及时停止。

旧日志没有保存 SSE 消息形状，不能把本次异常唯一归因于某个实际模型、供应商网关或累计消息重放。离线协议复现另证实旧客户端可能重复追加 `message.content` 全量快照，交错多个候选，并接受没有结束回执的提前断流。

## 决策

1. 语义整理仍全文一次输入，翻译仍全文优先；保留低思考强度和上下文 ASR 纠错。任务只要求交付一份定稿，移除“输出前自检”等反复检查指令。内容、相邻词归属、真实停顿及时间轴的最终验收属于程序。
2. 逐行接收并检查已完成的输出行。明显的非协议正文、重复或乱序编号立即关闭本地请求；不会删除某句元文本、提取第一个草稿或拼合多个完成稿来伪造成功。空白、常规空格差异和既有明确短尾注兼容仍保留。
3. 通用响应守卫限制正文体积、持续周期重复及整个请求的墙钟时间，区分正文和思考。体积由源文本与行数推导；不增加服务商私有字段。字幕中合法编号行允许重复对白或歌谣，重复检测不能用来猜测其语义；编号唯一性、体积和最终内容检查仍生效。
4. 沿用 `llm.timeout`：整理/翻译将它同时用于每次请求的总时限，覆盖响应头、静默等待、思考和持续输出；其他调用保留读取超时。总时限触发直接失败，不以切换服务商或重复请求延长等待。
5. 格式或退化中止沿用原步骤的有限校验重试额度，下一次为独立全文请求，保留原始输入和短诊断，不携带异常输出。翻译补缺的编号集合在重试前重置；所有守卫失败实时计入已有共享恢复预算。已存在的翻译结构恢复仍受原深度和总预算约束；超时、体积或单纯思考退化不会触发结构拆分。
6. 标准 `delta` 作为增量，不对相同增量模糊去重；兼容接口的 `message` 作为累计快照，只取新增后缀，不一致快照明确失败。固定选择候选 0，分离已识别的思考块，拒绝未知非文本块、冲突结束原因和未确认完成的 EOF。终态后的正文不能继续拼入结果。
7. 日志增加流模式、增量/快照帧数、候选数和结束回执；中止记录稳定错误码及有限证据，不记录凭据。断开只确认本地连接已关闭，不能承诺服务商停止计算或计费。

## 验证与限制

离线重放本次日志在 12:51:54、第 189 物理行即发现正文偏离协议，收到约 15,812 字符便中止，比原用户取消早约 3 分钟。保留协议反例：逐字输出、CRLF 跨包、合法重复对白、跨语言重复歌谣、空 usage 包、全量快照和多候选；验证静默请求关闭、有限 fresh 重试、补缺状态复位及恢复预算。

提示词和 low 档位不能保证模型每次都给出正确语义。格式通过也不能证明人物、数字、币种或所有边界修订忠于音频；有疑问的内容继续记录复核提示。正式产物只接受完整响应及最终领域校验；失败和取消保留旧产物。
