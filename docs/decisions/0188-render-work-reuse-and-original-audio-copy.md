# 0188：原声音轨直拷与合成重复工作复用

状态：采用。日期：2026-10-17。

## 背景

原声成片烧录字幕、评论时，画面必须重新编码，但未改动的原声音轨不必再次有损编码。“保留动态”模式每次试片和重做还会重复扫描完整混音；同版字幕在准备 SRT 和烧录 ASS 时重复解析，字幕、评论也会重复探测源画幅。

## 决定

- 完整原声成片仅在源第一音轨为 AAC、没有剪辑、静音或最终响度处理时直接复制音轨。字幕、评论可以继续单独重新编码画面。其他编码、未知编码、区域试片及实际音频处理继续使用 AAC 编码路径；音轨探测失败报错，不将失败冒充无声。
- 第一音轨是否存在与编码格式通过同一次探测取得。完整原声合成使用调用方已经核对的时长；区域试片仍读取完整源时长。日志和进度说明实际是否复制原音轨。
- 在项目音频目录缓存未施加最终增益的完整混音测量。指纹绑定真实输入身份、完整音频滤镜、声道与时间处理、剪辑、时长和测量算法。生成铺轨按内容身份绑定；目标 LUFS 与峰值不属于原混音测量，变化后复用测量但重新计算增益。
- 复用已有主音轨缓存的进程锁、取消检查及输入身份逻辑；错误、取消和测量期间输入变化不保存有效缓存。缓存损坏重新测量，缓存目录不可写时保留可直接测量的路径。
- 字幕解析结果仅在当前版本上下文使用，保留语言分段，不能跨任务或从旧共享 SRT 推测。源画幅在本次任务或请求按文件身份复用，换源或文件变化重新探测，不建立无限期的全局结果。
- 保留已存在的同批人声铺轨复用、完整响度主音轨与原片对照缓存。继续对新成片实际音轨测量并核对峰值；继续校验既有成品的完整性、输入与配置指纹。原子写入、失败保留旧成片和冻结设置语义保持不变。
- 这些优化不自动重做已经有效的成片，不改变用户参数或已有版本身份。素材和实际呈现参数不变时继续按原有新鲜度规则复用。

## 验证

隔离的真实 FFmpeg 回归比较原声 AAC 压缩包与时间戳、确认烧录后视频包变化，覆盖无声、未知或不兼容编码、区域试片、剪辑、静音和两种响度处理。重复混音测量通过实际进程调用次数验证复用，另检查输入、滤镜、算法变化、取消、失败、并发和损坏缓存。字幕与画幅复用通过真实渲染及解析、探测调用次数核对，并保留审查、双语、旋转和非方形像素的已有回归。
