# 0198 · 成片版本级剪辑方案

## 状态

已采用

## 决策

成片剪辑方案继续使用原视频时间轴，但保存范围改为 `output_cuts.json` schema 2 的版本映射：

- 每个成片版本可以有独立的启用状态和删除范围。
- 旧 schema 1 项目级方案继续作为没有独立方案版本的回退默认值。
- 显式保存的版本方案（包括禁用或空范围）不会再回退到项目默认方案。
- 可从同一项目已有正式成片读取不可变基准摘要（版本、artifact、哈希、源文件身份和原范围），再在当前版本中删除、恢复或调整范围。
- 旧成片文件只读保留；新的剪辑方案必须重新生成新的当前版本产物。
- 章节和发布交付继续使用生成产物快照中的剪辑方案映射，不能读取当前未执行的草稿。

## 原因

项目级剪辑会让不同版本互相影响，也无法安全地以某个旧成片作为基准恢复片段。版本级方案可以让原声、配音、字幕和评论版本各自独立，同时保留旧项目的兼容行为。所有渲染和指纹仍以源时间轴范围为准，避免对已剪辑 MP4 做二次时间轴映射。

## 运行边界

排队任务在真正开始时冻结本次版本方案；运行期间保存的编辑只影响后续任务。含剪辑时间轴的旧成片不走句子级局部替换或审查修订的复用路径，需要从源视频按版本剪辑方案重新生成。
