# 0193 · 统一检查与更新已有成片

日期：2026-10-17

## 对照依据

每份成功成片绑定产物摘要和实际消费的字幕、音频、评论、呈现设置、剪辑输入快照。字幕记录同时保存可读文档投影与真实烧录事件：仅复制可被覆盖的当前 SRT 不足以还原版本轨道、最短显示时长、声音排布或审查过滤后的画面。

旧成片没有逐句记录时不得从当前文字、修改前 base 或文件时间推断历史字幕。旧指纹仍可判断整片过期；手工字幕编辑仅作为“待核对”候选，不能当作精确差异或把其余句判为一致。英文原文仅在所选版本实际显示原文时影响字幕差异。

## 更新入口

合成成片页集中展示字幕、声音、上屏评论、剪辑、呈现设置五组变化，并提供已知文字的前后对照。字幕与配音页继续展示同一依据的逐句标记；保存操作立即触发新对照，核对期间不使用旧结论。

实际是否需更新与局部更新能力独立判断：`needs_update` 表达实际输入变化或文件缺失；`partial_unavailable_reasons` 只说明能力限制。已带剪辑但输入一致的成片不能因暂不支持局部替换而一直提示完整更新。旧记录未知但整体指纹一致时，仅提供可选的建立对照操作。

自动局部方案合并全部真实旧、新字幕、音频与评论范围，评论删除与时间变化也必须覆盖旧画面。检查后用户添加独立更新版本、保存并通过现有预检与运行入口生成；自动流程可以使用该版本。手工局部范围入口保留，用于历史记录不足或明确只改部分内容的操作。

本次“全部改动”方案绑定完整实际渲染输入；执行前若产生新增改动则要求重新检查，不得把固定旧范围重跑后的产物声称为全部已更新。手工范围仍遵守其明确的保留范围外内容语义。

评论的指纹摘要会去掉人工选择来源，不能把该摘要再次当待渲染方案执行候选筛选。当前比较必须投影实际审查后的方案；历史已渲染合同只还原当时文字、样式与时段，不推断人工来源、不重新应用自动候选的 240/600 字符建议。历史文字或时长证据损坏时标记未知。真正的评论错误需注明“上屏评论”及可读作者，并在成片对照入口提供返回评论页的操作。

## 完整更新边界

现有引擎以同一源时间轴执行等长替换。裁剪时间轴、源素材、全局呈现、跨句声音处理或缺失历史证据时，统一入口明确选择完整生成。普通版本原子替换自己的成品；局部版本需要完整更新时建立普通版本，保留固定基片语义。

“完整更新并建立对照”必须真正生成，不能因旧指纹仍有效而复用无逐句快照的旧文件。显式 `force_rebuild` 参与确认合同，仅影响本次选定正式版本；日常生成继续幂等复用。失败保留旧文件，成功后记录真实输入，不能补造旧成片历史。

未来可将音轨替换范围与画面替换范围解耦：整轨重新混音时保留未变化画面；通过源区间到输出区间的编辑映射复用裁剪后的旧 GOP。当前没有实现该优化，不能把“完整生成兜底”描述为这些变化理论上必须全片重编码。

## 验证

隔离复现包含仅修改 405/406 英文且旧快照缺失的 410 句工程，以及同时修改字幕、声音、评论和删除区间的工程。所有网页验收使用 8611 与独立数据；不改变生产项目、常驻服务或 B 站稿件。
