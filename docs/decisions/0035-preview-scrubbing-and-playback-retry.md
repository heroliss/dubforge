# 0035 — 字幕定位拖动条与试听失败恢复

## 决策

- 字幕工作区使用拖动条快速定位，保留精确秒数与句子选择。优先使用视频元数据时长，未就绪时回退到字幕终点；避开视频的精确终点，防止请求不存在的下一帧。
- 拖动期间只更新位置，松开后防抖请求一帧；保持原有串行合并与旧响应丢弃规则，不写入字幕时间或改变校对播放器位置。
- 配音试听遇到非主动取消的播放错误时记录失败媒体并暂停。仅在用户再次点击播放／试听时释放并重建失败媒体；健康媒体、声源、版本和音量保持不变，不自动循环重试。
- 页面保留中文错误说明，区分浏览器有声播放权限、解码失败和一般加载失败。重试是媒体播放操作，不是重新生成配音。

## 验证

回归测试覆盖拖动过程无请求、松手只请求最终位置、精确输入防抖、时长回退与越界限制，以及单／多音轨失败恢复、原生视频按钮恢复、持续失败不无限重试。保持既有时间轴同步与尾音测试通过。
