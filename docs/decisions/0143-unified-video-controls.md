# 0143 统一视频播放控制层与章节标记

## 状态

已采用

## 背景

各页面使用浏览器原生视频控制条，并在部分页面额外绘制章节条。原生控制条无法可靠插入应用自己的 DOM，导致章节条与进度条分成两行、宽度不一致，点击章节只能近似跳转，窗口尺寸变化时还会发生位置跳动。

## 决策

所有视频预览统一使用 `VideoControls`：播放器容器内只有一条自绘时间线，缓冲、播放进度、章节起点、悬停时间和拖动都使用同一个媒体时钟。控件同时提供播放/暂停、精确拖动、音量、倍速、字幕切换和全屏，并保留键盘左右键每次 5 秒定位。

完整源视频从项目的 `download/video-info` 只读资料中读取章节。短片或审查片段不直接显示原视频章节，除非调用方能提供可靠的源时间偏移，避免把源时间误当成片段时间。画面单击负责播放/暂停，双击负责进入或退出全屏；单击动作延迟判定以避免双击造成额外切换。

### 键盘控制与焦点范围（2026-10-16）

播放器外壳可以通过 Tab 聚焦，点击画面也会聚焦外壳。键盘事件只在该外壳中处理，不维护全局的“最后选中视频”，以免离开播放器后仍接管页面方向键。所有预览共用左右每次 5 秒、上下每次 5% 监听音量、空格/K 播放暂停、M 静音、F 全屏及 Home/End 首尾定位。

输入框、可编辑内容、下拉选择和非进度条滑块保留自己的键盘语义；按钮上的空格仍激活该按钮。忽略修饰键、输入法组合和已经处理的事件；切换类快捷键不接受按住连发，方向键接受连发。媒体切换和组件卸载时撤销监听与组件新增的焦点属性。

时间跳转仍操作同一个 video 时钟，通过原有 seeking/seeked 同步配音；音量仍调用共享监听控制，保证配音与多音轨预览调整的是实际可听见的声音，而非被强制静音的视频。快捷键不改变项目制作参数或生成产物。控制条提供按键提示，并在定位、音量变化后显示简短反馈。

## 结果

章节标记直接嵌入播放进度条，页面之间的外观和交互一致；去掉原生 `controls` 后，不再出现第二条浏览器进度条。自绘控件的全屏目标是播放器外壳，视频在视口中按比例完整放大，配音跟随逻辑也把外壳全屏识别为同一媒体的全屏切换。浏览器禁用 Fullscreen API 时使用可退出的视口全屏回退，避免按钮无反馈。

## 验证

`npm run build` 通过；步骤页、片段审查、配音跟随、成片预览和媒体恢复相关前端测试通过。
