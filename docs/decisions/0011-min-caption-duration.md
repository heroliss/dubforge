# ADR 0011：在语义整理后合并过短字幕

> 2026-09-24：配置位置和重叠策略由 ADR-0016 更新；显示延长不再制造字幕重叠。

## 状态

已采用

## 决策

新增 `tts.subtitles.min_duration`（默认 0.5 秒），在字幕生成阶段执行。低于该时长的目标语言字幕直接延长显示结束时间；这允许相邻 cue 短暂重叠，但不合并文字，也不改变 `split.json` 的语音和配音时间轴。

## 原因

语音转文字阶段必须保留 Whisper 的识别上下文和词级时间戳，过早调整会影响后续语义整理。字幕生成阶段只负责展示，适合单独延长 cue；翻译、配音计划和 TTS 仍使用原始语音时间轴。
