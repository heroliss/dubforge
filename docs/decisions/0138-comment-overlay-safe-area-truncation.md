# ADR-0138：评论叠加安全区的双语预算与省略

日期：2026-10-12。补充并局部取代 ADR-0037 中关于评论排版的约定。

## 背景

评论确认方案允许每条中文与原文分别保留完整文字。视频画面上的评论卡片还受
横向宽度与竖向安全区限制。旧的兜底逻辑按字符簇从尾部截断，英文可能留下半个
单词；双语内容则给两种语言套用同一个行数上限，短语言会浪费高度预算。

## 决策

1. 确认方案（`comment_studio.json`）始终保留用户确认的完整原文与译文，不因渲染
   空间不足而改写、覆盖或重新确认。仅在生成 ASS 事件时生成临时排版文本。
2. 排版省略优先沿 `_tokens` 的完整词与标点边界回退，并保留省略号；只有没有
   词边界的中日韩字符或 emoji 串才按 grapheme cluster 回退。单个无法放下的
   超长英文词不伪造半词，显示省略号并保留计划原文供编辑。
3. 双语排版共享同一个竖向安全区。先为每个非空语言分配一行，再按实际换行数、
   字号和剩余内容量分配剩余行数；同字号时两种语言不会各自重复占用完整预算。
   分配后仍无法容纳时，沿既有错误码 `COMMENTS_LAYOUT_OVERFLOW` 停止，不把
   卡片绘制到安全区外。
4. 单帧预览与正式成片继续共用同一 ASS 渲染路径，排版算法变更通过已有
   `render_version` 指纹使旧评论成品重新生成。

## 验证

- 回归测试覆盖英文词边界、单个超长词、组合字符和 emoji grapheme，以及短中文
  与长英文双语内容的共享行数预算。
- 测试不访问用户项目或外部服务。
