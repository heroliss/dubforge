# ADR-0031：统一工作台视觉与操作分层

日期：2026-09-27

## 问题

项目筛选、批量运行和创建挤在同一行，设置页将全部配置串成很长的页面；步骤日志占据参数前的大段空间。各页留白、字号与颜色不一致，窄屏导航和表格占用较多宽度。

## 决策

- 保留 Vue 与 Naive UI，通过应用主题和共享样式统一背景、表面、边框、主色、状态色、间距和焦点反馈。图标使用本地 SVG，不引入外部字体或图片依赖。
- 桌面保留常驻项目步骤导航，窄屏改为可展开侧栏；面包屑说明当前位置。步骤入口继续常驻，状态同时提供可访问文本。
- 项目空间分为主标题与创建入口、状态筛选卡、筛选工具栏、批量选择区和项目卡。批量待处理运行只作用于当前筛选列表，明确标注文案；重命名、文件夹和删除收进更多菜单。
- 总览保留各步骤的单动作模型。顶部按是否缺少依赖选择一个主要运行入口，依赖计划仍由已有确认弹窗展示。
- 设置分成模型连接、步骤默认参数、运行与存储、环境与服务、耗时记录。分区切换保留草稿，每区独立保存并标记未保存状态；成功保存只更新此次提交的快照，不能清除其他分区或请求期间新编辑的标记。非法 JSON 阻止保存并提示修正。
- 步骤详情以参数、运行日志与对话、输入与产物分类展示，保留组件实例和既有日志、预览、校对与任务行为。
- 帮助增加目录，关于页的工作区数量取自导航定义；表格可横向滚动，网格在窄屏堆叠。

## 验证

前端生产构建成功，62 项 Node 交互回归与 477 项后端 pytest 通过。新增设置草稿回归覆盖默认空目录、删除最后一组、非法 JSON、分区独立保存和慢请求期间再次编辑。浏览器验证项目创建、搜索选择、详情分类、帮助目录和 390px 窄屏导航与配音列表；使用 8611 和独立临时数据、配置，不占用 8600 常驻服务。未调用外部模型进行真实生成。
