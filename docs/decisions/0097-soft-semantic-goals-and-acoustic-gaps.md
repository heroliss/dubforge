# ADR 0097：语义软目标与基于证据的时间校验

状态：接受，2026-10-07。

## 问题与证据

首项目语义整理任务 #291 的两次完整响应分别包含 242、294 句。LLM 原本正确输出了 “in Nanjing, China” 等完整搭配，本地字符兜底把它们切开，再以悬空介词和极短尾句拒绝自己产生的片段。配置为 20 字符时，旧模型模式还采用 40 字符的放宽预算，既无法解释用户看到的长句，也不能统一衡量中英文语义长度。

词形和文字密度只能说明值得复核，不能仅凭它们证明口语句尾、独立短应答或 ASR 纠错有错。另一方面，真实时间轴和响应协议能够提供明确的结构证据，仍必须验证。

## 决策

1. 语义整理保留全文一次输入和低思考强度。提示词只讲目标、语义编辑权限、边界、时间事实和单份结果协议，移除冗长的自检与机械长度补救说明。
2. LLM 使用 `split.target_word_count`，默认约 10 个词；英文按单词，中文按自然语义词理解。单句时长默认参考 7 秒。二者均是软目标，优先完整搭配和真实声学时间，不按字符数、模型 token 或固定倍数机械拆句。中文没有可靠的自然分词定义，程序不把汉字数当作词数。英文词数或时长超标只汇总复核提示。
3. 旧 `split.max_split_length` 的值保持原含义，仅关闭 LLM 后用于本地规则。模式未消费的长度项从制作指纹中排除，也不进入语义响应缓存，避免无效设置变化导致过期或重复请求。
4. 句尾功能词、极短片段和文字密度只产生有限复核提示，不触发重试，不自动移动或删改台词。仍验收编号、非空文本、完整响应、合法时间及可靠的声学空档。失败和取消继续保留旧产物，完整候选按原子写入协议发布。
5. 整理提示、时间修复和空档校验共享词轴覆盖范围的并集。两秒及以上的无台词区独立于普通停顿阈值，正文中只出现一次内联标记，不再发送重复的前置长静音表。短语模式也显示词轴揭示的短语内部空档；缺少词轴时只说明短语之间可观察的空档。无台词不等同于波形静音，不静音原声或背景声音。
6. 重叠或嵌套词用累计覆盖结束时间，避免把仍有声的区间误认为静音。零时长词保留文字，但不扩大有声范围；空档内部缺乏声学归属的零词仍报告时间问题。浮点误差采用统一的十亿分之一秒容差。
7. 翻译继续消费定稿的原句数量与时间轴，完整上下文优先；相邻编号间两秒以上的空档也作为非台词标记提交，稀疏补缺请求不把未发送的台词误认为静音。更新整理与翻译版本，避免复用旧提示产物。

## 验证与限制

离线重放任务 #291 的两份完整响应，新流程分别保留 242、294 句，候选正文逐字符保真；19 个两秒以上空档均未被字幕跨越，其中 8 个此前介于两秒和三秒之间。未请求模型或修改真实项目产物。

软目标不是长度保证；模型可能选择保留较长的完整片段。格式与时间校验也不能证明所有专名和事实正确。复核提示保留不确定性，人工仍可结合原音编辑。当前测试和服务验证见 [验证记录](../research/soft-semantic-goals-2026-10-07.md)。
