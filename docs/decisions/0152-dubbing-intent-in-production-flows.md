# 0152：制作流程中的配音意图、精调保护和同轮恢复

## 问题

声音参数是下一次合成的输入，已生成音频是可选择的制作成果。将两者等同，会让保存参数或恢复流程悄悄覆盖逐句精调；完全只复用音频，又无法从项目空间或总览明确更新声音。单句、制作链、完整流程与顺序发布必须遵守同一规则。

## 决策

中央 `pipeline/dubbing_policy.py` 统一解析本次配音策略和影响摘要。策略作为运行意图进入预检、确认指纹与任务记录，不写成全局默认或删除逐句参数。

- 默认 **继续已有配音**：保留可播放的音频和当前选用槽，只补缺失或文字、时间已失效的句子；参数不同单独展示，不代表旧音频不可用。
- **按当前参数更新**：按每句实际有效参数与生成指纹比较，只更新不同及待补的句子。逐句覆盖仍优先。
- **重新生成全部配音**：明确重新合成制作范围。默认保留手动选用原声或静音的句子，需要改变这些声源时另行勾选。
- 2026-10-16 调整：明确发起的更新与重做默认覆盖各句当前槽，修复同一声音不自动积累版本。需要比较不同声音时，可明确选择共同新槽或指定槽。只有成功的句子选用新音频，覆盖目标槽后重新确认满意；旧任务已显式记录的目标槽策略继续按原意图恢复。
- 默认保留逐句精调。可明确勾选本次统一使用项目参数，仅执行时忽略逐句覆盖，不删除其设置和历史音频。
- 原文或译文尚未生成时，预检展示延后计算。任务真正进入配音执行时冻结实际句子身份与目标槽；排队期间和尚未开始步骤继续允许按既有运行设置规则修改参数。
- 每次制作轮有稳定 operation_id。中断后同轮、同策略、同字幕身份沿用目标槽，核验成功音频版本并跳过；剩余句使用当前保存参数。策略或输入身份改变时建立新轮并展示说明。
- 各句强制覆盖与任务恢复分开。当前槽第一次主动覆盖必须强制；恢复已成功句不因外层 force 再次覆盖。
- 实际待生成句的参考文件进入预检。只沿用旧音频的方案不要求模型服务在线或无关的新参考文件存在。
- 生成程序正常选用新槽只刷新本轮负责的选择摘要；字幕编辑、逐句参数、评论和成片版本的恢复门禁仍保留。

## 界面

“运行或继续”先选择制作/完整流程/恢复意图；后续执行方案统一展示可展开的“本次配音”。修改策略会撤销旧预检，确认发送已经展示的策略与指纹。批量按项目列出实际影响；已创建的顺序发布批次沿用所保存的配音意图。

保存项目参数不启动合成。全局或模板改动仍按 ADR-0126 主动应用到项目，自动运行使用项目已经保存的值。本文扩展 ADR-0151 的目标槽语义，保持 ADR-0132 的按步骤冻结规则。

## 验证

隔离数据库与模拟模型通过正式运行入口覆盖默认复用、参数更新、精调保留/临时忽略、手动声源保护、共同新槽和指定覆盖、确认期间方案变化，以及制作链、完整流程和顺序批次的同轮恢复。浏览器使用独立测试端口 8611 和测试数据，不调用真实配音模型或发布平台。
