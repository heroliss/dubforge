# 0104：以配音语意组织字幕，并保留识别证据

状态：已采纳

## 问题

只提示“不超过参考词数”会让模型倾向保留过碎的 ASR 锚点。短语字幕还会把极短或零时长的词扩展到最低显示时长，全文短语输入看不到原始对齐疑点。已有转录仅保存词文字及时间，无法从历史产物确认是否真的有人说话。

最新生产稿还显示：模型组合好的 `The line` 与 `And just like that` 被后处理对齐到较早的孤立词，重新拆成单词配音片段。由文字匹配结果强行回拉，不应取代模型有上下文的边缘纠错。

## 决策

- 整理以参考范围内长度适中、可连贯配音的自然语意为目标。连续叙述的短碎片优先归并；参考词数及时间仍是软目标，不设置硬性最短句长，也不为凑满长度堆成长句。
- 有明显间隔且有意义的短句、应答、感叹、数字答案及真实中断保留。结合全文主动清理无意义识别残留，不按关键词表或时长删除，也不为保留孤词补造台词。
- 时间校正优先保护有本侧连续词锚的完整语义单元，允许有限分句边缘纠错。候选只对应一个声区时，紧邻边界的单个前缀词可按模型上下文归属保留并提示复核；这是有范围限制的例外，文字和时间本身不能证明该词是误识别。来自另一侧唯一正时长词的尾部附加或边缘替换仍沿用停顿分隔校正；候选确实覆盖两侧有声区时必须留出长空档。修复不删除候选文字，可收窄多覆盖的无台词时间。
- 原始长空档内部的零时长词若已被候选明确删除，不再阻止结果通过；保留或归属不明确时仍不能为它补造有声时间。
- 正常转录时附带保存模型已返回的有效词概率、片段无语音概率及关联；不改变识别算法，不增加推理请求。历史字幕和缺失指标保持未知。
- 全文输入增加有界的识别参考注释，仅描述原始零时长或联合置信度疑点。它们不是核听结果，也不能单独作为删词、补词或编造时间的依据。
- 整理规则版本递增，旧响应缓存不能沿用。更新不覆盖生产产物；需从语义整理重新生成，再保持定稿原文与译文逐行对应。

## 验证边界

离线候选回放用于确认后处理不再制造孤词、保留短答及无台词时间，并保护原始转录。提示词约束不能证明模型下一次一定清理所有错误识别；实际质量仍需结合新产物及原音判断。
