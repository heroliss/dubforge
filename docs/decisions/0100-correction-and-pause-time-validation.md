# ADR-0100：分开转录纠错与无台词区的时间校验

日期：2026-10-07。状态：采用；补充 ADR-0097 的宽松内容复核与真实时间门禁。

## 证据

首项目任务 #296 首轮输出 427 句。146.970–160.860 秒的无台词区已经由候选第 62、63 句留空，但另一处尚未修正的时间重叠让当前区间的纠错例外失效，继而误报“新增文字”。仅移除这一无关前置条件后，完整候选可经现有后处理获得合法时间，19 个长空档全部保留。

另有离线回归揭示：已分开的纠错句保留 4–11 秒空档，随后全文模糊对齐却可能再次覆盖它；局部检查若排除了原空档左锚点，会遗漏这个真实时间错误。

## 决策

- 跨停顿理解上下文、删除多识别和补回漏识别属于转录纠错。文字的增删、替换及相似度本身不是“字幕跨越”的证据，疑点继续作为复核提示。
- 每个长空档只核对当前区间是否被占用、附近分句与声学区域是否对应，不让远处待修复的原始时间重叠否决本区间。最终仍对整个候选检查合法时间与重叠。
- 已修复的空档不能被后续近似对齐重新填上。全局或局部对齐的建议时间若占用空档，保留已修复的时间；最终使用完整词轴再检查，不从当前候选时间截取词轴后推断空档。
- 保留两秒及以上无台词区，检查完整跨越和局部占用；约 11 毫秒的既有边界容差保持一致。确实占用空档而又没有可靠切口的候选仍需修订。
- 不能确定切口的错误附具体空档、附近候选编号与有限文字，使用户和一次定向重试能定位问题。诊断不包含连接配置或密钥。
- 提示词明确跨停顿纠错权限与时间约束，语义整理版本升为 `semantic-contextual-boundary-noise-v10`，避免旧候选按新规则直接复用。

## 验证

语义、时间、纠错、缓存、输入指纹和翻译链相关 601 项测试通过。任务 #296 首轮离线重放保留全部 427 句文字，最终零时间重叠，19 个长空档零占用。没有请求模型或覆盖真实产物。
