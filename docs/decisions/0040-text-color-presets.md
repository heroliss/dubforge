# ADR-0040：字幕与评论共享配色预设

日期：2026-09-27。扩展 ADR-0038/0039。

## 需求与边界

用户需要比暖象牙白更有活力的配色，同时保留旧配色备用，并将备选扩展到至少 16 款。
预设是两种颜色的快捷输入，不是新的视频渲染方式，不自动保存或合成，不改变其他项目。

## 依据

- 用 [W3C 相对亮度与对比公式](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
  计算 sRGB 文字色与描边色的对比；每组未取整结果均 ≥ 7:1，当前实际约 7.20–13.69:1。
  这是色对筛选，不是成片 WCAG 认证：描边粗细、抗锯齿、背景亮度和运动都会影响实际阅读。
- 参考 [CSS Color 4 的 OKLab / OKLCH](https://www.w3.org/TR/css-color-4/#ok-lab) 区分明度、彩度和色相。
  测试将文字色转换为 OKLab，用两两欧氏距离 ≥ 0.08 防止加入过近颜色。
  0.08 是本列表的策划门槛，不是标准规定、通用感知阈值或美观度分数。
- 场景和冷暖搭配由人工设计判断；不宣称某色会必然引发情绪。以明度差为阅读基础，不只依赖色相。

## 决策

1. `textColorPresets.ts` 是字幕与评论共用的唯一预设清单。16 款分为活力暖色（5）、清新梦幻（5）、
   浅景深字（5）、柔和中性（1）。包含同色系明暗、暖字冷描边、深字浅描边等不同用法。
2. 「暖象牙」固定保留 `#F7F3E8 / #202631`。为当前项目选择「晴日金」`#FFD65A / #30213A`，
   不改变全局默认或其他项目。后续用户可随时选择或手动调色。
3. `TextColorPresets.vue` 展示可筛选的色卡列表、明暗两种底上的文字示意、当前项与自定义状态。
   普通按钮支持键盘选择，选中有文字名称和勾号，不仅靠颜色识别；宽度和高度适配窄屏。
   设计理由、对比数字和局限放在悬停提示与折叠说明，不占据主编辑区。
4. 项目字幕参数表与评论排版分别把预设映射到已有的两个字段。只写草稿，由各自原有保存动作持久化。
   不新增后端配置字段，不存预设 ID，实际色值才是保存与渲染依据，旧文档继续有效。
5. 保留所有手动控件。选择不改字号、宽度、底色/透明度、位置、语言或时间；描边为 0 时仅提示，
   不悄悄启用。沿用已有防抖预览，正式成片仍使用同一 ASS 渲染。

## 验证

- 对比公式黑白/同色/灰色基准、全部色对对比门槛、感知色差去重、分类和 ID 唯一性。
- 实际组件脚本覆盖选择、禁用、筛选、自定义识别、CSS 色值安全及不隐式保存。
- 字幕只保存两色、评论保留文字和其他参数、可恢复旧预设、保存冲突保留草稿。
- Vue/Naive UI 实际渲染测试、前端构建和后端全量回归。浏览器连接失败时不宣称截图验收完成。
