# 0163 自动投稿后的章节交付

日期：2026-10-15。状态：采纳。补充 ADR-0142。

## 问题

此前只冻结源视频章节并提供手动同步计划。章节开关没有进入全流程配方，翻译开关没有后台消费者，审核监控在投稿和合集核对后结束，导致自动流程显示完成但没有章节。

## 决策

- 项目发布设置提供自动章节、标题翻译精简、App 默认展示三个可继承开关。新草稿和新自动流程冻结这些设置；旧发布快照不追溯开启。
- 开启后，本次自动投稿的统一确认也授权后续章节交付。稿件审核通过后，由独立后台队列执行标题翻译、按成片裁剪快照映射、逐分P预检、单次提交和回读。无源章节直接跳过。
- 章节状态保存为 Publication.chapter_sync，独立于投稿回执。监控线程只负责调度，不等待 LLM 或章节网络请求。手动上传、单项目全流程及顺序发布均消费同一冻结章节策略。
- 分P绑定优先使用真实上传回执中的 CID；缺少可靠归属时明确等待或失败，绝不凭模糊标题猜测。远端已有不同章节时停止自动覆盖并引导手动预览。
- 使用 ADR-0142 的修改计划与回读保护。写入结果不明只核对，不自动重发；分P完成回执和翻译结果持久化，中断或重试复用，不重复生成或提交已完成部分。
- 章节异常明确显示“视频已发布，章节待处理”，重试只处理章节，不重新上传或投稿。已发布但未开启的记录提供显式“补充视频章节”入口，由用户确认后启用。

## 验证

使用隔离数据库和平台/LLM替身验证配置继承、分P映射、一次翻译、多P写入、结果不明核对、中断恢复与调度。真实已发布稿件未经新的明确操作不被本次代码升级自动修改。
