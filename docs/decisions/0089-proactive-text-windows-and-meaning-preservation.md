# ADR 0089：主动文本小窗与分层信息保真

日期：2026-10-06。状态：已采用。补充 ADR 0086、0087。

正常语义整理、翻译的主动分窗已由 [ADR 0090](0090-full-semantic-editing-and-fast-inference.md) 替代；本文保留此前决策与失败恢复的历史依据。

## 问题

项目 `99211e` 的整理任务 #277 将 448 个识别短语、约 11,989 字符一次发送。界面字段 `split.window_max_chars` 缺少默认配置，全局和项目都未设置时解析为空，执行时空值被当成 `0=不限制`，使原字符上限失效。两次模型输出均正常结束；首轮被碎片和长停顿检查拒绝，第二轮又引入遗漏。只为某处失败重做完整视频，修好旧问题时可能产生新问题。

此前“任何纯删词都拒绝”的规则过严。源文 `least a I stole` 中的 `a` 是可能的悬挂冠词或识别噪声；不能把逐词相同当作语义整理目标。用户明确要求允许合理纠错与清理。原始识别稿也可能漏词，静态对比不能证明实际音频说了什么。

## 决策

- 语义整理主动限制每窗最多 2,400 正文字符、32 个原识别短语，并受原上下文预算和用户更小的字符上限约束。`0` 不取消内置质量窗口。硬范围末四分之一优先强标点或真实停顿，不把短语切成两份；单条过长仍保留原短语所有权并受实际请求预算检查。
- 原文前后参考只用于理解，本窗正文所有权不重叠。整理允许改变识别句数；通过所有窗口和接缝检查后统一生成最终编号。翻译必须沿用这些编号、句数和顺序，时间从同编号原句继承。
- 每个整理窗口最多两轮定向质量校验。仅已分类的模型解析/质量失败允许二分，最多两层、每个主动窗口恢复树最多 14 轮输出校验。网络、限流、取消、上下文及存储错误不扩张为质量重试。单条原短语不能继续二分。
- 原始成功响应以输入、实际提示、规则、制作参数、前后参考和词锚点为指纹原子缓存；读取后重新经过全部门禁。质量失败后的拆分决定也缓存，后续重试直接使用子窗口成功缓存。强制重做不使用这些缓存。
- 接缝先尝试满足长度、时长、标点和真实停顿约束的安全拼接。有邻句证据的碎片仍在本窗内检查，不用“边缘句”豁免窗口内部问题。需要模型复核时使用两侧原 ASR 叶窗并集，不能把候选文本或模型时间反推成新的原文。修复后向前复查接缝；并集限制 64 短语、4,800 字符，每次接缝最多两轮，不递归扩张。最多执行叶窗数量减一的接缝并集请求组；最终全稿再检查信息与时间质量。
- 保真改为分层门禁：数字与明确数值格式、否定、实质词纯遗漏、大段概括、已有词重排、明显重复参考内容仍被检查；允许有局部上下文依据的有限识别填充词、悬挂冠词及识别重复清理，并在日志/模型事件记录位置和原因。每叶窗清理额度有限，接缝和全稿按所有权合并预算，不能因为合法小窗的累计改动超过单窗额度而失败。
- 翻译首轮主动限制 40 句、2,000 估算正文 token，保留各两句只读边界参考。前一成功窗口随响应提供术语、称谓、主语指代和未完话题的交接摘要；术语表和风格提示保持一致。模型仅返回本窗绝对编号，摘要不能代替原文。实际初次、补缺及重试均经过包含提示、边界、摘要和输出预留的 90% 上下文守卫。
- 正常翻译成功不追加校对调用；原有结构失败后的局部补缺、二分、恢复额度和逐句校对保留。主动窗口缓存使用独立策略版本并绑定实际系统提示与术语内容。
- 更新整理规则和独立翻译分块策略版本，更新原因提供中文说明。无需重新下载、分离或识别；重新整理后的内容和时间实际变化通过输入产物指纹传递到下游。不自动恢复发布模式的生产工作流。
- 补齐窗口字符设置的默认值、配置示例及本地配置；关闭 LLM 的本地规则整理不消费窗口设置，该项不参与其输入指纹。

## 限制

这些是保守的错误识别和局部恢复机制，不是语义等价证明。原识别漏掉否定、人物名称等实质信息时，需要结合原声核对；模型认为合理并不足以证明源声确实如此。小写专名重复、刻意重复、方言、低频口语及上下文之外的识别错误仍可能需要人工判断。模型校对也不能保证每句翻译忠实，短窗口和边界参考只能减少任务难度。

验证、真实失败候选重放和隔离模型请求见 [本轮验证记录](../research/proactive-text-windows-2026-10-06.md)。
