# ADR-0112：自动缩时因子与用户配置分离

状态：已采纳。日期：2026-10-07。取代 ADR-0025 中自动写回本句时长因子的决策。

## 问题

配音超长时自动使用更小因子重试，旧实现把最终采用值写入本句配置并重算输入指纹。这让生成过程修改用户设置，后续合成起点发生变化，并污染项目的设置变更判断。

## 决策

- 用户配置是合成的请求输入，每次从当时实际生效的本句、项目或继承因子开始。重试因子只作用于本次请求，不写回任何层级，也不影响下一句或下次合成。
- 保持合成前的输入指纹。自动缩时属于本次生成过程，生成完成后不能因为实际尝试值不同而立刻出现参数变化或缓存失效；用户随后真正修改配置仍能被识别。
- 配音版本快照保留实际采用的 `settings.duration_factor` 和 `duration_retry.used_factor`，首个 `attempts.factor` 记录生成起始值。模型长度可能非单调，实际值必须取最终采用结果，不能用最后一次尝试推断。
- 在本句参数的可编辑时长因子下方显示只读生成记录，包括所选配音版本、合成起始值和实际采用值；旁注当前配置用于下次合成。配音详情也显示同一记录。切换配音版本随之切换记录，缺失记录显示未记录，不用当前配置冒充历史值。
- 不自动清除历史本句覆盖：旧记录只有 identity/settings，没有来源或人工编辑时间，无法可靠区分自动写入与人工修改。用户可点击时长因子的恢复继承并保存，保留其他参数和既有音频。
- 本次变化不增加制作参数，也不触发对历史音频的批量重合成。

## 验证

隔离 pytest 覆盖全局、项目、本句来源和值不变、正常缓存复用、显式重新生成从原值开始、连续多句互不污染及手动修改后失效判断。前端验证起始/实际/当前配置分别读取、非单调重试采用值、历史缺失记录与版本切换。
