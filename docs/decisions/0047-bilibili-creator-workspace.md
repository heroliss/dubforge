# ADR-0047：B站创作管理与已有 BV 更新

日期：2026-09-28。状态：采用；真实写入待用户选定稿件后验收。

## 功能与界面边界

- 发布资料内折叠展示平台标签建议、标签校验和话题搜索。只按点击添加，不覆盖人工标签；话题需确认活动条件，保存草稿不参加活动，正式投稿才提交所选话题字段。AI 文案助手不决定话题、版权或发布动作。
- 独立「B站稿件」页读取账号投稿、逐P审核/转码原因及基础统计。列表分页，统计明确为本页合计，不声称全账号分析、留存或收益。
- 已有 BV 支持文案修改、保留全部分P的重排、追加新分P，以及转入/移出合集。不提供删除或替换分P。私密、联合投稿、付费等特殊稿件限制在官网编辑。
- 追加使用当前账号已上传但未投稿的本地清单。用户先上传新版本，再在目标 BV 预览追加；沿用目标稿件文案、封面和原有分P。根据 [ADR-0050](0050-advisory-ai-declaration.md)，含配音版本时仅提醒核对声明，保留目标稿件原声明；如需修改声明，单独预览编辑。成功后该上传清单关联已有 BV，不能作为新稿再次提交。
- 官网模板先只读展示，再按人工选择的标题/简介/标签导入本地。不导入旧分区、版权或官网默认标记，也不覆盖已导入模板；没有写回官网模板的隐式操作。

## 冻结预览与失败处理

新增 PublishChange 表；不扩展制作步骤的状态机。预览读取稿件所有权和资料版本，持久化精确字段差异、分P顺序和已上传文件回执。提交只接受计划 ID 与明确确认，不能用前端重新拼装后的参数覆盖计划。预览有效期10分钟，提交前再读远端版本，平台变化时拒绝并要求重新预览。

单个稿件以及同一份追加清单的在途/未知修改互斥。提交前持久化 committing，成功持久化回执；超时、断线、进程中断留下待核对，不自动重发，也不允许绕过保护正式投稿、复制或编辑追加清单。只读核对必须完整匹配预期文案和有序CID；不能凭相同标题判成功。合集小节暂不能完整自动核对时，保留官网人工核对和明确解除保护，解除不重发旧计划。

使用 biliAPI 2.15.0 的低层编辑方法，不使用会自动上传/重试投稿的高层函数。适配 SDK 丢弃 human_type2 的行为，处理平台将新版分区返回为对象、提交时需要数字 ID 的差异。简介同步生成纯文本 desc_v2，避免旧富文本覆盖新简介；新文案不会误带原文中的@用户标记。保留已返回的杜比/无损标记及二创许可；分P回执缺失或CID重复时拒绝编辑。写请求禁止重定向和自动重试，不改动依赖版本。

## 评论与字幕来源

- 评论按热门一级评论分页、ID去重，单次最多200条；平台总数可能含回复，不把它当成可采集的一级评论数。来源以 `bili:BV:rpid` 标识，独立原子存储后合并到现有评论翻译、评分、上屏工作区。YouTube资料刷新不删除导入评论，导入不覆盖翻译或上屏快照，也不修改制作步骤状态。
- 字幕明确选择 BV、分P及语言，精确匹配字幕 ID，失效不回退其他语言。下载仅允许 HTTPS 平台字幕主机、不跟随跳转、不发送账号 Cookie，有超时和体积限制。由于 SDK 的下载函数直接写最终文件且会回退首个语言，不直接使用该函数。
- 导入先保存不可变来源文件和原子索引，不立即替换制作产物。用户在「语音转文字 → 原文获取方式」选择平台字幕后再运行，才生成 src.srt 和统计，不加载 Whisper；平台没有词级时间戳，words.json 写空数组，下游按句级时间处理。
- `asr.input_mode` 默认 speech；默认项从历史识别指纹中移除，保证升级不令原产物全部过期。选用平台字幕时把来源内容纳入指纹；导入新的源字幕会使消费该来源的制作步骤需要更新。

## 验证边界

隔离测试覆盖：字段白名单、归属、预览/提交分离、冻结参数、防双提交、防重复追加、异常跨重启保留、在途互斥、读取核对、模板不覆盖、评论合并、字幕来源与指纹、真实SDK编辑方法的请求体，以及前端取消/迟到结果/错误恢复。

真实账号只读联调已验证投稿列表、推荐标签与校验、话题搜索、稿件详情和合集归属、官网模板列表（当前为空）、评论读取、字幕分P读取。没有修改真实稿件、创建合集、上传、投稿或向真实项目导入内容。真实写接口和活动参与仍需用户选定目标后验收，不能用模拟测试替代平台验收。
