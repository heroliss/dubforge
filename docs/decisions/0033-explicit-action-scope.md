# ADR 0033：操作范围显式化，成品勾选与流程默认分离

- 日期：2026-09-27
- 状态：采用
- 部分替代 ADR 0027、0029 中的运行入口与默认勾选交互；不改变成品文件命名。

## 问题与证据

1. `StepView.vue` 通用运行走 `/steps/assemble/run`，后端按 `assemble.burn_subtitles` 选择一个默认配音版；`AssembleOutputsPanel.vue` 的复选框走独立 `/assemble/outputs`。视觉相邻，但前者不读取后者，且后者过去自动勾选默认版。
2. `Dependencies` 原来只按默认烧录开关检查依赖，与显式成品方案不一致：原声烧录也被配音阻塞；默认不烧录时显式烧录缺少预检。
3. 普通流程运行、项目批量运行缺少统一范围确认；筛选保留的隐藏勾选不醒目。确认到执行之间重新读取勾选，可能扩大执行范围。
4. 参数表单中的恢复只是草稿动作，运行入口却仍可能使用旧保存值。步骤状态返回全局配置，项目覆盖未反映到试片说明。
5. 项目刷新暗含补建索引；字幕导出依赖不足时容易把用户引向全项目字幕与配音同步。

## 决策

### 正式成品、试片、流程三类入口

- 成片页顶部仅导航到方案选择区，不运行。方案初始空选；空选不发送请求，不隐式补默认。
- 正式成品先只读预检实际方案依赖，再确认种类、数量、整段视频、保存参数与版本保留策略。确认提交独立选择快照，后端重新检查依赖。
- 原声烧录只依赖视频与选定字幕。配音版按逐句声源、音轨和混音需求校验；烧录依赖由实际方案决定。
- 手动成品任务清除遗留续跑链，不启动其他步骤。非默认方案不能写入一个会被默认流程误判完成的输入指纹。
- 试片单独成区，明确起止时间、默认方案和只生成短片；不读取正式成品勾选。
- 为兼容已有自动流程，保留 `assemble.burn_subtitles`：重新命名为“流程／试片默认烧录字幕”，不增加配置键。总览及项目列表确认时列出这个默认配音方案，不暗示全组合。
- 任务状态返回实际 scope/variants/range，刷新页面后显示提交时的范围，不以此时空勾选误报没有任务。

### 一致的作用范围

- 总览、项目列表：执行前列出项目、步骤顺序、依赖、保存参数与成片默认方案；执行已展示的步骤快照。项目批量 API 的可选 `steps_by_uid` 兼容旧调用方。
- 字幕与配音：顶部全项目、当前句和勾选句分开命名；提示筛选隐藏勾选；覆盖当前配音版本先确认。
- 字幕导出：有自己的仅导出入口；缺依赖时只规划字幕所需步骤，不附带配音。
- 参数：编辑、填入父级默认都先进入草稿；保存不自动重新生成。未保存时相关运行按钮禁用并就近提示。状态接口显示项目实际生效参数。
- 刷新只读；找回项目单独确认扫描目录、只补登记、不移动文件、不运行步骤。

## 审核覆盖

| 页面/区域 | 主动作与范围 | 防误操作措施 |
| --- | --- | --- |
| 项目列表 | 勾选项目 / 当前列表待处理项目 | 项目数、隐藏勾选数、逐项目计划与确认 |
| 总览 | 勾选步骤 / 单步及依赖 | 默认成品提示、实际执行计划、按计划启动 |
| 普通步骤页 | 本步骤运行或重做 | 区分缓存运行与忽略缓存、参数草稿拦截 |
| 字幕与配音 | 全项目 / 本句 / 勾选句 | 清楚命名、隐藏选择提示、覆盖确认 |
| 字幕导出 | 字幕文件及必要上游 | 不生成配音、视频或烧录字幕的说明 |
| 正式成品 | 本次勾选方案 | 默认空选、预检、确认、版本并存、任务范围反馈 |
| 短片试合成 | 明确区域与默认方案 | 单独区域，不替代正式成品 |
| 参数与设置 | 本句 / 本项目 / 全局 / 各设置分区 | 保留既有分区独立保存，补充草稿/父级默认说明 |
| 帮助与找回 | 与实际入口一致 | 去掉旧“刷新即找回”、全局单任务及强制重跑笼统说法 |

## 验证与取舍

- 后端隔离测试覆盖空/非法方案不入队、依赖按方案校验、真实 ffmpeg 原声烧录不生成配音、默认成片不误跳过、项目参数和运行快照。
- 前端直接渲染真实 Vue/Naive UI 组件，覆盖七个步骤的三种历史状态、默认空选、取消无执行及确认选择快照；另有范围摘要与筛选测试。
- 保留现有产物和配置，不触碰常驻服务或真实项目任务。默认方案仍是配音版，复杂多方案必须在成品区显式选择。
- 这是核心工作流的交互语义审计，不宣称穷尽所有设备、数据和视觉组合；实际浏览器逐项人工验收仍有价值。
