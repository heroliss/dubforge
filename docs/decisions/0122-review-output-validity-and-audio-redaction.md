# 0122 — 审查修订有效性与语音屏蔽

状态：采用

## 背景

审查报告、生成后的修订文件和平台审核是三个不同的状态。重新检查文字只能刷新本地报告，不能改变旧成片。发布页此前将各种失效原因合并为一个提示，难以分辨人工屏蔽范围、文件或实际输出设置的变化；未消费的当前评论设置也可能误使修订失效。

命中区间原先对最终混音静音，人声和背景一起消失。项目已有分离背景轨，可以在移除原声和配音的同时保留该时段的背景。

## 决策

- 以生成快照和文件身份核对修订有效性，返回具体中文原因及安全的前后变化。比较实际消费的评论呈现方案，排除被冻结设置覆盖的当前评论参数。存储配方必须通过自身摘要校验，不能以当前状态补写历史值。
- 发布页明确区分重新检查文字和重新生成视频，并提供前往合成页的入口。发布确认、实际上传和提交继续核验选中文件；失效文件阻止发布并提示修复，不借由刷新报告绕过检查。
- 保留 `content_review.mute_audio` 开关，新增 `content_review.audio_mode`：默认 `voice_only`，另可选择 `all_audio`。
- `voice_only` 移除命中时段的语音。配音使用独立语音轨处理；原声或旧混音先屏蔽该段，再用源时间轴同一时段的分离背景补齐。`all_audio` 对该时段整条混音静音。
- 背景只允许来自可验证的 `preprocess/background.wav`。分离关闭、背景过期、缺失、损坏、过短或背景音量为零时，使用全部静音并说明原因；不从含原声的视频音轨回退，也不凭空生成背景。
- 配音、原声、审查修订和核对短片共用声音处理计划。实际声音处理方式与消费的背景身份进入生成凭据和指纹；没有命中时不引入音频模式依赖。声音方式不影响语义整理、翻译、配音合成和文字字幕的缓存。

## 边界

音轨分离不是语义判断，背景仍可能残留可辨识人声。用户需要试听；若有串音，可切换全部静音。文字筛查也不替代画面核对或平台审核。

修改设置不会改变已经上传的文件。正常自动制作按当前规则生成；选用过期修订文件的自动发布需要重新生成并重新选择文件。

## 验证

隔离项目覆盖设置继承、旧页面兼容、并发版本冲突、实际音频频率的语音移除与背景保留、短片非零起点寻址、安全回退、输入指纹和具体失效原因。前端覆盖模式草稿、保存与恢复、报告刷新语义和恢复导航。
