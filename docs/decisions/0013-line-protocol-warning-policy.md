# ADR 0013：行协议采用宽松兼容与结构定向重试

## 背景

大模型偶发输出空格差异、空行、停顿注释或小幅时间偏差；这些不属于语义错误，却会让严格解析触发不必要的重试。跨长间隔合并也可能是有意的语义选择，强行拆回反而会破坏模型判断。

## 决策

1. 行协议读取端兼容常见空格差异、全角/顿号式编号、空行、代码围栏、注释和小幅时间越界；这些情况记录警告。
2. 长间隔合并只记录警告，不再由本地强制拆回。
3. 缺号、重复号、未知号和乱序是结构性错误；保留已可确认的行，只对受影响行号或同一时间轴发起定向重试。
4. 正式产物仍序列化为标准行协议，保证下游解析稳定。

## 结果

自动修复更保守，减少误报和不必要请求；同时保留关键对齐完整性，避免把结构性错误静默写进产物。
