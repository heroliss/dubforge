# ADR-0213：发布设置显式调整分P顺序

日期：2026-10-19。状态：采用。

## 决策

- 发布设置的分P清单提供逐项上移、下移，显示最终 P1/P2 编号。排序直接编辑既有有序字段 `publish.version_ids`，与其他项目设置一起通过版本校验保存，不增加另一份排序配置。
- 默认全部版本时，第一次调整转换为明确的版本ID顺序；成片定义、制作目标及按版本ID保存的分P名称保持对应。运行锁、归档、保存忙态与首尾边界同时约束按钮和处理函数。
- 自动流程和顺序批次使用已确认的发布清单顺序生成草稿及最终视频清单。原BV追加分P按所选顺序追加；只有明确同步 `part_order` 时才重排原稿。仅按CID替换视频继续保留远端位置。
- 修改项目设置不改写已有手动草稿、已上传清单或在途任务。已有草稿使用发布记录中的顺序编辑器；继续旧任务沿用已确认配方。顺序批次若显式选择刷新现有未上传草稿，须重新预检确认。

## 验证

前端覆盖排序保存与重载、ID与名称对应、边界与运行锁、保存冲突及撤销。后端以隔离数据库和伪平台验证保存设置、配方指纹、批次、上传及投稿清单，另覆盖追加/显式重排/保留原CID位置的最终更新请求。浏览器仅在8611复制的隔离夹具中操作和保存，未向B站提交。
