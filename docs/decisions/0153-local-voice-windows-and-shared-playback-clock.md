# ADR-0153：有界邻句排布、布局后缩短重试与统一播放时钟

状态：已采用。日期：2026-10-15。

## 问题与证据

最新249句配音中，62处音频容器范围相撞；部分相撞区确实含人声。
选句任务（包括全选）不生成旧铺轨报告，工作台预览一直按源起点播放。
每句又各自把到整座语音岛末尾的容量视为自己的余量，逐句重试不能发现
整个片段的容量不足。最终排布只报告 needs_scale，没有实际第二轮模型重试。
任意一句放不下或混入原声/静音时，全片退回源轴，扩大了局部问题。

本决策取代 ADR-0140 中“大停顿不可借用、原文字幕固定、全片全部可行才采用”
的限制，以及 ADR-0107 中正式成片允许未解决配音重叠继续混音的默认行为。
识别原稿、校对源轴、音色参考切片仍保留原始时间。

## 方案比较

1. 逐句向右顺延：容易理解，但不能利用前方空白，连续顺延会偏离画面。
2. 全片排布：容量利用高，但远处句子也可能受影响，解释和精调困难。
3. 固定加速全部句子：实现简单，却浪费空白，并压快本来正常的短句。
4. 有界邻句排布：局部共享空位、限制漂移，只有真实放不下时才调用模型。

采用第四种。默认最多9句联动，每句起点相对源起点最多前后移动2秒；
间隔0.08秒。窗口3～15句、位移0～15秒、间隔0～1秒均可配置。
超过窗口上限时优先在3～N句中的较大源间隙断开；等大的切点选更远者。
原声、静音和缺音频的行作为固定障碍；已知视频边界时才使用片尾空白。

## 排布与缩短

固定实际WAV长度，先求有界保序的最小平方起点偏移（PAVA），允许相邻
3～5句整体移动。窗口不可行时，优先减少超过原字幕槽的部分，给出容量建议；
建议不是裁音频，只有全窗原速可行时才能采用该窗的新时钟。

本轮先生成用户指定因子的自然音频，再排布。仅对本轮新生成、排布后仍不足
的句子，按已有缩短因子列表逐个重试。每次真实音频返回后重新排布，再决定
是否需要下一次；同一因子不重复请求。模型长度不保证单调，保留本轮最短
的完整结果。临时因子记录在版本快照，不写回项目或逐句精调设置。

以下历史配音限制已由 ADR-0155 的可恢复自动时间修复取代：
复用的历史精调音频不自动重做。工作台提供“为冲突句生成新槽”入口，继续
使用统一生成确认弹窗。默认保留旧槽，成功后选用新槽。缩短关闭、后端不支持
或所有因子耗尽时保留音频并明确失败；正式成片不再悄悄混入未解决冲突。
明确的区域试片仍允许试听问题片段，排布开关关闭时保留源轴行为。

## 同一派生时间轴

`voice_timing.plan` 按当前选槽、实际WAV长度、视频边界与排布设置即时计算。
工作台音频、原文/译文/双语字幕、区域试片和正式配音成片共用此计划。
原声成片仍使用源时钟。源start/end和句子身份不变，另返回playback_start/end；
乐观切槽期间撤销旧时钟，保存后整体刷新，避免邻句使用过期排布。

`voice_timing.json` 是可检查的报告，不是正确播放的前置条件；单句/所选/全量
都写报告。局部失败不撤销其他可行窗。排布设置、选槽音频版本和策略版本进入
字幕/成片指纹，不进入模型音频身份；修改排布不导致音色音频全部过期。

## 验证

纯领域测试覆盖双向移动、3～5句联动、窗口边缘、安全间隔、固定障碍、视频
边界及随机不变量。消费者测试覆盖选槽即时变化、原译字幕同钟、坏文件与
局部失败不裁音频。集成测试使用隔离数据与假TTS检查先滑动后有限重试、
非单调长度、精调保护和成片阻断，浏览器检查播放与字幕使用相同时间。
