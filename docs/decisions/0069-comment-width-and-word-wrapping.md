# ADR 0069：评论宽度与按单词换行

日期：2026-09-29。状态：采用。

- 新增 `comments.width_percent`，为最大换行区域占画面宽度的百分比。`0` 表示自动，保留现有横屏、竖屏及居中布局；其他值在边距允许的范围内生效，短文字不强行撑满。
- 配置存储默认项为 `comments.overlay.width_percent`。统一配置负责全局 → 系列 → 项目继承；成片版本可独立覆盖。控件为滑条、数值和“自动”按钮；自动是有效的固定值，不等于恢复继承。
- 评论工作区修改宽度后沿用现有串行、去抖预览，不自动保存。预览和成片继续共享 ASS 生成器，不另写浏览器模拟布局。
- 排版按英文单词优先换行，中文允许逐字换行并尽量避免标点悬挂。超出整行的长词、网址允许折行，但不拆重音组合和常见组合表情。
- 双语两部分独立按各自字号换行，仍共享宽度和位置。文字过多时沿用现有缩字号及溢出保护。
- 评论渲染指纹加入算法版本，重新生成时不复用旧的逐字断词成品。仅影响叠加评论的成片，不重新下载、翻译或配音；已生成文件和已发布稿件不自动修改。

验证覆盖词边界、超长词、中英混排、重音与表情、横竖画幅及六种对齐、边距限制、配置继承和版本指纹、真实 FFmpeg 预览，以及三个配置入口的控件事件。
