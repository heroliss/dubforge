# 0057 独立成片版本与分P引用

日期：2026-09-28

## 问题

旧组合键只能表达原声/配音、字幕开关、评论开关。同样三个开关的两个成品无法分别使用中文、双语或不同样式。字幕导出、合成、全流程若各自保存一套参数，会出现预览与实际渲染不一致、顺序变更误触发重做等问题。

本决定对 ADR-0042 的“组合即成品身份”作扩展：新入口以稳定版本 ID 为身份；原组合接口仍按原规则替换，兼容已有工程。ADR-0039 的三维正交性继续保留。

## 决定

- 成片版本以稳定 `id` 定义身份，名称和分P位置不参与媒体输入指纹。`AssemblyCatalog` 保存定义，`AssemblyResult` 保存最后成功的文件绑定、输入指纹和生效设置快照。
- `assembly_versions` 作为领域入口，统一校验、解析、继承来源、冻结、依赖和有效性。界面只发稀疏覆盖，不回传派生的 `values` 或状态作为配置。
- 优先级：全局制作默认 → 项目默认 → 本版本覆盖。评论呈现的项目基线来自已确认的评论方案；全流程自动采集时来自已确认的流程评论设置。评论内容、排序与节奏仍共享，不在每个版本复制内容。
- 版本内显式值即覆盖，即使等于默认；`false`、`0`、透明背景都不是继承。删除覆盖键才恢复继承。声音、字幕、评论三个开关是版本自身的明确意图。既有项目默认表单的归一化行为暂不改动。
- 只开放呈现/混音/编码参数的版本覆盖，不让版本暗中更换识别、翻译、配音引擎。共享源视频、校对稿和逐句配音；每版字幕直接从校对稿派生至私有临时目录，不依赖公共 SRT 导出类型。
- 正式生成必须先对选中的版本预检并确认输入指纹；空选不生成。单帧与短片可以预览未保存的草稿，不能修改版本定义、正式产物或共享字幕。
- 同版本成功后原子替换自身并保留产物 ID；失败保留原文件。未变版本核验文件内容后复用。复制版本获得新 ID，即使三个开关相同也可独立存在。
- 分P只保存版本引用、发布名称和顺序，自动流程冻结完整生效设置。渲染与发布之间按版本身份查找，不再靠文件名前缀猜原声/配音。旧 API、旧组合文件和旧流程记录保留兼容。
- 新项目模板只复制定义，不复制产物；全局模板更新不静默替换已有项目清单。项目主动应用模板后需保存；已被本项目流程引用的版本不能直接移除定义。
- 项目 manifest 同步定义和成功绑定，重建索引按逻辑文件名重新关联 artifact ID。移除定义不删除成品；回收/仅删除记录沿用独立文件管理入口。

## 界面

成片页为版本清单、当前版本编辑与自动画面预览，常用字幕语言直接展示，样式/混音折叠。字段标明继承来源和恢复继承；项目默认混音与输出另列，旧“流程默认烧录”开关不再混入版本页。全流程编辑器引用同一版本清单，可就地编辑版本后再预检；发布页展示实际文件的版本名称与生成效果。

## 验证

pytest 覆盖显式等值覆盖、无效值、并发修订、模板只影响新项目、引用删除保护、实际 FFmpeg 单语/双语独立输出、仅重做变更版本、试片不落正式状态、编码失败保留旧文件、manifest 恢复与缺失文件。

下载到发布集成测试使用真实制作步骤和 FFmpeg；只模拟外部下载、模型与B站接口，验证配音中文字幕 P1、原声双语 P2、独立评论语言、分P顺序、AI声明判断及合集目标。Vue 组件测试覆盖空选、确认冻结、复制身份、稀疏保存与流程引用。
