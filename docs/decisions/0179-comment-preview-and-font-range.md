# ADR-0179：评论预览过渡与字号范围排版

日期：2026-10-16
状态：已采纳

## 决策

- 评论预览从等待刷新起显示转圈和状态，旧帧保留但淡化。参数防抖、串行渲染与过期响应隔离继续有效；最新帧完成、错误或参数失效后结束等待。
- 已选评论编辑区从最多 380px 扩大为 1280px，并允许纵向调整高度。
- `font_size`、`source_font_size` 兼容已有最大字号；新增 `min_font_size`、`source_min_font_size`。原文独立样式关闭时跟随通用范围，关闭前的独立值仍保留。
- `width_percent` 为最大宽度，按完整正文换行。新增 `height_percent` 作为目标最大高度。在字号范围内缩小以适应高度，达到最小字号后仍放不下则完整扩展高度，不再缩破下限或用省略号删去正文。
- 排布尊重位置锚点：顶部向下、底部向上扩展。预览反馈是否突破目标高度；超过视频可见范围时显示提示，用户可调整宽度、字号或文字。
- 自动候选的建议字数筛选与手动保留超长提示仍分离。所有被接受的评论使用同一排版器，预览和正式成片共用，使用 `full-text-range-v4` 标识实际渲染规则变化。
- 旧快照缺少范围字段时补程序缺省值，不擅自应用后来修改的全局值；新参数贯穿全局、模板、项目和成片版本覆盖。

本决策替代 ADR-0177 中手动超长时可无下限缩小字号的策略。
