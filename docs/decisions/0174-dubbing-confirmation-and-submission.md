# 0174：配音确认与提交反馈

日期：2026-10-16

## 问题

单句覆盖确认依次等待权限检查、完整工作台读取、任务提交和工作台及导航刷新，导致任务已经接收后弹窗仍不关闭。完整工作台包含全部句子的音频状态和时间排布，不能作为提交单句的必要往返。等待期间缺少明确反馈，也会诱发重复点击。

## 决策

- 工作台返回每句 `synthesis_revision` 与项目 `synthesis_slots`。确认窗口冻结所选句的凭据，POST 携带 `expected`，后端在已有启动锁与编辑门禁内核验后入队。凭据绑定实际文字、声音参数、选用声源、配音文件版本和满意记录；保留旧客户端省略凭据的兼容入口及原有依赖检查。
- 确认后立即显示提交状态，禁用重复点击、改槽和关闭。取得有效的任务编号后立即结束确认，不等待完整工作台或导航刷新。以任务编号保留已接收状态，旧的读取结果不能将它撤回为空闲。
- 已知拒绝在弹窗内说明；确认内容变化时只允许刷新并重新确认，不悄悄改成新计划提交。网络错误、服务端错误或无效回执均先核对状态，不自动重发。后台刷新失败与任务提交失败分开表达。
- 完整工作台每请求只扫描一次槽目录，并复用该请求内的文件版本、音频快照和逐句指纹；不通过延迟失效的缓存掩盖真实变化。
- 页面空闲时降低轮询频率；隐藏、挂起或正在读取时不积压完整工作台刷新，回到前台时及时核对。

## 验证

隔离测试覆盖确认期间输入变化的拒绝、入队锁、提交不构造完整工作台、目录和快照复用，以及按钮重入、有效回执、旧读取结果、失败重试与结果待核对。浏览器验收使用独立数据目录和模型替身，并人为延迟完整工作台，确认弹窗关闭不再依赖刷新完成；未重做真实项目音频。
