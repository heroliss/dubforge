# ADR-0117：归档模板收纳与可找回删除

状态：已采纳，2026-10-08。

## 背景

活动模板与归档模板混在配置侧栏中，影响日常选择。项目已有删除和目录找回能力，模板却仅存于数据库，缺少独立恢复文件；两者必须分别说明删除范围和恢复方式。

## 决策

- 配置侧栏只显示活动系列模板，归档模板放在默认收起的次级区域。通过项目链接打开正在查看的归档模板时展开该区域，保留选中位置。
- 仅已归档且无项目绑定的模板可删除；归档项目的绑定同样计入。删除不隐式解除绑定，不改变项目的继承设置。
- 模板删除先原子写完整备份到当前工作目录的 `trash/templates/*.json`，成功后再清除数据库模板行。该目录是程序的恢复区，不属于 Windows 回收站，不自动清空。
- 「找回已删除模板」按需读取备份并恢复原模板标识、覆盖设置和归档状态。恢复不覆盖现存同标识模板，也不自动重新绑定项目。损坏或无效备份明确报告失败。
- 项目删除复用安全回收组件：先刷新目录中的 `manifest.json`，再将整个目录移入系统回收站，成功后才清理数据库登记。无法回收则中止，不降级永久删除。外部引用的源视频和独立发布记录保留。
- 项目清单补充模板归档状态，使缺失模板的目录恢复保留管理状态；旧清单缺省仍兼容。

## 手动找回

项目：从 Windows 回收站还原完整项目文件夹到工作目录的 `projects/` 下，保留其中的 `manifest.json` 和全部产物；在项目列表点击「找回项目…」。已有登记不覆盖，已归档项目仍回到归档列表，之后可恢复为当前项目。

模板：保留工作目录中 `trash/templates/` 的 JSON 文件；从其他备份位置找回时，将原备份文件以原文件名放回该目录，再进入设置的「找回已删除模板」，刷新并恢复。模板仍保持归档，可随后点击「恢复」。普通模板截图或手工导出的任意 JSON 不属于此恢复格式。

项目目录恢复可重建设置、步骤与产物索引和成片版本；不重建原运行历史、进度或数据库自增编号。Windows 回收站已清空或文件不完整时，需另有完整目录备份。模板恢复依赖该独立备份，删除备份本身后需另有文件备份。

## 验证

新增隔离测试覆盖模板删除前置条件、备份失败、恢复冲突与格式校验，以及项目的假回收站往返、不可回收失败、清单失败和外部路径保护；界面验证覆盖折叠区域、绑定禁删、重复点击和失败后的保留状态。
