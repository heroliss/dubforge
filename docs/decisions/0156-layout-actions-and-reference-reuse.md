# ADR-0156：排布操作、失败收尾与固定参考复用

状态：已采用。日期：2026-10-15。

## 问题

用户难以区分滑动现有声音与缩时重新合成，容易以为修复时间必须生成新槽。
部分配音失败时，工作台已经按现存声音重排，但文件报告可能仍是上一轮结果。
固定参考虽有模型特征缓存，校验和首次特征提取仍存在明显重复工作。

## 决策

音频素材、自动播放排布与人工位置是独立层。仅排布不改变音频字节、音色、
槽选择和满意标记；改变声音才需要模型与声音历史。原文、译文、试听和
配音成片始终使用同一派生播放时间，源稿仍用于语义校对与原声参考。

工作台读取当前完整有效的音频就计算排布，新音频原子写完并选用后即生效，
不必等待整批结束。自动缩时则在本批自然合成结束后，按真实完整邻句容量
决定是否请求更小因子，每次返回再排布。缺音频时不凭预估长度过早压快邻句。

工作台提供「重新排布（不改声音）」直接刷新当前派生计划，无模型、无任务、
不把自动结果写成人工覆盖。同样输入得到相同结果是正常行为。精确指定某句
位置仍使用「文字与时间 → 播放排布」，保存后成为固定点，可恢复自动。
重新生成冲突句是独立的声音制作操作，仍使用统一目标槽确认弹窗。

选句限定音频合成范围，不限定时间排布的读取范围。全稿按局部窗口检查，
相邻自动句可移动，人工位置保留。默认每窗最多9句不是全片只允许影响9句：
补齐缺音频或新增人工固定点可能拆分/合并连续区域并改变窗口分组。
不引入另一套只在工作台生效的局部时间轴，也不因单句操作重配邻句声音。

失败、服务超时或取消后仅尽力更新一次当前排布报告；不继续调用模型，不让
报告/日志写入失败覆盖原错误。避免每合成一句就写全稿报告带来近二次方开销。

固定参考成功校验按规范路径、大小、mtime、ctime、inode及最低时长有界缓存。
文件变化即重新校验，失败不缓存。不把路径存在等同于音频有效，也不引入
跨服务的上传文件永久缓存。本机 IndexTTS 删除冷缓存时未使用的重复编码，
并复用已读取的重采样波形；保留重采样路径不同的音色/情感独立计算。

## 本次检查范围

按用户要求不运行测试、模型或浏览器验收，仅进行代码审查、语法检查及前端
构建。IndexTTS 修改前保存原字节备份，运行中的服务不重启；下次正常重启后
加载优化。性能收益不以未经测量的耗时百分比描述。
