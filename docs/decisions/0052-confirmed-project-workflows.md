# ADR-0052：项目全流程方案与后台协调

日期：2026-09-28。状态：采用。

## 背景与边界

现有生产步骤、评论工作区、发布回执各自具有缓存、编辑和安全边界，但总览的勾选链不能表达两个有序分P、评论准备及发布终点。用户要求通过默认配置与自动填充，一次完成配音/原声两个带字幕和评论的成品，并加入预设合集。

同时发现旧 `_chain` 续跑使用步骤开始时的项目对象，会覆盖运行期间的设置；重启只清运行步骤，没有清除两步间遗留队列。两者先修复并有独立回归，原勾选链不承担发布副作用。

## 决策

- 引入 `WorkflowRecipe`（全局默认/项目覆盖）和 `WorkflowRun`（确认快照、游标、发布记录关联）。存入现有 SQLite；不写制作配置，不使下游产物过期，不在流程记录中存服务密钥。账号凭据继续由发布模块保护。
- `workflow_plan` 负责验证、预检与指纹；`workflows` 只协调现有 Runner、评论与发布接口。页面不循环驱动制作或投稿；API 不复制领域规则。执行终点为 `produce` / `draft` / `publish`，默认 `draft`。
- 方案显式保存有序成品组合，每个组合的配音、字幕、评论三维独立。默认建议 P1 配音字幕评论、P2 原声字幕评论，仍须预检及确认后才能启动。原片直接引用，不复制、不合成。
- 账号、模板和项目覆盖复用发布模块的继承规则。预检冻结解析后的发布设置；后续改模板不影响已确认任务。平台资料和 AI 只填未手动指定的字段，不替用户决定账号、分区、权限、合集或声明。权利确认只绑定当次任务，不存为可继承的默认。
- 评论默认消费已确认方案；自动模式必须显式选用，固定采集上限、评分提示词、上屏数量、语言和样式。复用评分/翻译缓存，按实际片长限制上屏条数。零条、译文不合格或时间不适配均停止，不静默省略指定效果。
- 两阶段预检：启动前检查源、依赖计划、工具与服务、LLM、账号/选项和封面策略；完成后由现有发布计划检查实际文件指纹、时长、大小及平台要求。第一阶段明确说明内容/成片尚不存在，不能承诺所有运行期调用成功。
- 启动/恢复在制作、编辑及发布公共锁内登记项目占用；全流程执行期间拦截同项目的竞争制作和编辑。全局制作设置变化在下一阶段前停止并要求重新确认。旧 `_chain` 在交接/重启时清除，续跑回写最新项目而不是旧对象。
- 恢复同一计划必须保持原步骤表与游标对应；暂停期间前序文件丢失会回退游标，有新增缺失依赖则重新规划，仍复用已有效产物。关闭网页不中断，程序重启不自行恢复制作或投稿。
- 使用客户端请求 UUID 去重，重复标识仅允许同一项目/方案。每个流程的发布草稿使用固定 ID；生成与关联中断不创建第二份。已有草稿/回执的项目引导继续原记录，不由新流程重复创建稿件。
- 上传后投稿继续调用现有单次确认的发布动作；投稿结果不明绝不自动重试。有 BV 回执后单独轮询审核，连续失败退避并转为需处理；入合集首次执行及回读沿用发布模块，未确认的关联需要用户显式核对/重试，禁止通过重投视频补救。

## 验证

隔离测试覆盖全局/项目继承、权利不继承、空字段、前置依赖、配置变化、请求去重、停止/重启、缺失文件续跑、未知回执、合集失败和双分P顺序。三秒样片集成测试真实执行下载步骤入口、音轨处理、转录步骤、语义整理、翻译步骤、配音步骤、字幕导出、评论评分翻译和双版本 FFmpeg 烧录；仅网络、模型与 B站传输用固定响应，验证一个稿件、两个有序分P、一次关联及审核查询。

页面测试覆盖确认前无写请求、双击不重复、取消、草稿不投稿、方案暂存、分P调整、新建合集回填。浏览器只读核对项目总览/方案抽屉，没有保存真实方案、上传或投稿；未启停用户常驻服务。

本轮全量回归：后端 920 项、前端 195 项、B站组件 43 项通过；前端生产构建通过。后端另有两条现有第三方依赖弃用警告，不影响测试结果。

## 限制

需要后端进程保持运行；服务安装/启动仍显式操作。远端模型、网络、平台风控和审核无法用本地预检保证。流程方案/记录保存在数据库，迁移工作空间需一并备份数据库；字幕、评论、视频产物仍遵守原子文件写入规则。已进入发布阶段的中断在发布页恢复，避免重新制作改变待上传文件。
