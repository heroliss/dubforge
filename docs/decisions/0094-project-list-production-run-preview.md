# ADR 0094：项目列表制作运行的入口与检查面板

## 背景

项目卡片的「核对运行步骤…」实际按总览已保存的步骤勾选运行制作链，名称未说明执行用途。旧入口使用短文本弹窗，无法原地查看依赖问题、补齐依赖或确认部分就绪项目；检查一个项目会让列表全部运行按钮显示加载动画。批量入口还会因为当前列表存在失败项目而隐式改变目标范围。

## 决策

- 单项目入口命名「运行制作步骤…」，悬停说明已勾选的步骤及执行顺序；正在执行的项目改为「查看进度」。完整流程、制作链和历史恢复各自使用明确的入口名称。
- 单项目与批量共用一个制作运行抽屉。先显示项目范围，再逐项目读取最新记录与运行计划；打开和检查只读取状态，不启动任务。检查期间可取消，关闭或卸载后的迟到响应不能更新面板。
- 默认使用项目总览已勾选的制作步骤；可明确选择补齐缺失或需更新的依赖，重新检查并展示新增步骤。确认使用面板已展示的步骤快照，不重新读取列表勾选扩大范围。
- 依赖、读取异常、无步骤、全部最新及项目忙碌分别展示原因与项目链接。批量中的异常项目不阻断其他就绪项目，确认前可调整本次项目选择。
- 执行步骤使用紧凑的顺序布局；按步骤、依赖状态、原因及配置阻塞分别汇总问题。同一原因对应数百个逐句音频时，只展示数量和步骤链接，文件名样例供悬停查看；不同问题不能因属于同一步而被合并隐藏。
- 使用手动制作入口时展示保留计划的影响，并引导需要继续旧流程的用户检查恢复方案。制作入口只提交制作链，不启动发布流程。
- 批量入口明确针对所选项目或当前列表待制作项目，保留隐藏选择的范围说明；失败项目的出现不再隐式缩小批量目标。
- 确认期间阻止重复提交；响应后按项目展示启动或跳过结果，刷新列表不延迟确认回执。启动结果不确定时提示先查看状态，不自动重复请求。

## 验证

使用实际组件与隔离接口验证只读检查、确认快照、补齐依赖、部分异常、取消与迟到响应、重复点击和列表范围。前端构建后检查页面上的入口与抽屉，不运行真实制作任务。

新增16项回归通过，前端完整455项测试及生产构建通过。实际浏览器验证单项目打开、补齐依赖重检与关闭，239个音频依赖汇总为113项需更新及126项缺失；确认按钮从未点击。服务已提供最新构建，检查后运行项目数仍为0。
