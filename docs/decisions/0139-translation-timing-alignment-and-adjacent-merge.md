# ADR-0139：翻译时长预检与相邻语义片段归并

## 状态

已采用

## 背景

语义整理结果通过编号校验，并不能保证翻译模型把内容放在同一编号中。
当 ASR 产生连续的半句时，翻译模型可能把后一句内容提前或延后，造成译文
明显超过本句到下一句开始的可用时段；单独的 TTS 缩时重试无法修复这种编号错位。

## 决策

翻译完成后生成 `alignment_audit.json`，按目标语言朗读时长估算报告明显超时、
可用时段未利用以及相邻连续行一长一短的可疑窗口。审查只产生诊断，不自动移动
原时间轴或改写译文。

LLM 语义整理完成后，在进入翻译前保守归并相邻悬空片段：不跨真实停顿或句末标点，
合并后不超过步骤时长上限；英文需要小写续句、悬挂功能词、破折号或未完的 `-ing`
等证据，中文只归并明显亚秒残片。该规则保持源文字顺序和声学起止时间，减少跨编号
翻译的机会；不使用“固定每 N 行”或强制合并完整句子。

## 后果

未来项目会在翻译和配音前得到可定位的时长/错位提示，普通 TTS 仍以实际音频时长为准。
已有产物不会被隐式重写；要修复旧项目需从语义整理开始重新运行后续步骤。

## 2026-10-15：配音前估时只作诊断

配音前复用同一审查，但不再把字数估算偏长或连续句一长一短当作批量制作
失败。这些信号不能证明翻译跨编号错位，且本句到下一句起点的间隔没有
计入有界滑动和相邻句联动可用的空余，曾导致尚未合成就误报失败。

日志保留重点句号、估算超出秒数和可疑连续窗口，并明确其为文字长度估算。
翻译审查与任务准备共用同一估时函数，中日韩标点不计入文字长度，拉丁语
缩写词和点式首字母缩略词作为完整单词计数，避免同一句出现不同的预估值。
选句、全量、继续已有配音以及关闭自动缩时的运行都采用同一诊断语义。
模型请求前仍严格拒绝无效起止时间；取得实际 WAV 后继续按项目设置先排布、
再有限缩时。真实音频仍放不下时仍以 `DUB_TIMING_UNRESOLVED` 失败，
保留已生成声音，防止不完整或重叠配音进入正式成片。
