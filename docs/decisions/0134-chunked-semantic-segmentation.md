# 0134：长稿语义整理采用分块与局部重试

## 背景

词级时间轴会把一段长视频展开成数万行输入。把整段时间轴和提示一次发送给模型，会同时放大首字节等待、隐藏思考占用、编号漂移和时间戳越界的概率；一次失败还会丢掉整份候选。

## 决策

- 词数超过阈值时按核心词数分块，默认每块约 500 词；边界优先靠近已有停顿。
- 相邻块额外提供约 80 词前后文，仅用于理解；正式产物只接收各块自己的核心范围，避免重叠字幕和重复计时。
- 每块独立执行格式、时间范围、静音区和内容覆盖校验；失败只重试当前块，默认最多 3 次，配置上限为 5 次。
- 分块任务失败后，下一次从失败状态重做时可恢复已经通过校验的块响应；缓存绑定完整提示、原文、模型参数和规则指纹。已完成步骤主动重做仍跳过缓存。
- 时间越界使用明确的“时间超出输入范围”错误，不先截断为零时长，以便模型按错误范围修复。
- 小稿仍保留全文一次整理路径；分块是按输入规模自动选择的策略，不改变最终 `split.txt` 协议。

## 取舍

分块降低了单次请求的上下文完整度，但保留了边界上下文，并把失败范围缩小到一个块。当前核心输出不跨块改写上一块的正式字幕，优先保证可去重、可恢复和时间轴确定性；分块聚合后只对无长停顿且被语义质量规则标记的可疑接缝做一次局部复核，复核失败保留原块结果，不让所有块无条件输出重叠正文。
