# ADR 0068：配音完整性与预览回退分离

日期：2026-09-29。状态：采用。补充 ADR 0022 的默认声源语义。

## 问题

工作台为未配音的句子提供原声试听。正式合成误用同一回退结果，导致部分 TTS 失败后，自动流程只检查已生成的配音，跳过剩余句子继续合成。

## 决策

- `selection` / `render_lines` 保留工作台的试听回退；`production_lines` 表示正式制作意图。未明确编辑的句子必须使用配音第一版，不能因为文件不存在而转成原声。
- 明确选择的原声、静音、其他配音版本继续生效；选择绑定文字和时间轴。配音版齐全按实际文件、生成快照和上游就绪判断，不以某一次批量任务的成功或失败状态代替。
- 合成依赖、音轨铺设、成片指纹和批量补配采用相同制作意图。有效历史配音继续复用；不存在、失效或丢失的所选配音必须补齐。
- 全流程预检展示已就绪、待补和跳过原因；大量依赖提示默认展示前六项，可展开全部。新发现的配音依赖使旧流程续跑计划重新规划，不沿用错误游标跳过。
- 合成批次开始、实际铺轨以及自动准备发布资料前检查完整性。缺失时报 `DUBBING_INCOMPLETE`，停止后续操作；只制作原声版本不要求配音。
- 不改用户的选择、文件或已发布稿件，不自动启动重试。手动播放和试听不受正式制作门禁影响。

## 验证

隔离测试覆盖部分生成失败后只补缺句、未生成与显式原声/静音区别、已选版本丢失/改变、旧计划续跑修正、TTS 失败停止下游、混合版本编码前和发布准备前门禁，以及预检 UI 的数量和说明。所有模型与平台操作使用桩，不真实配音或投稿。
