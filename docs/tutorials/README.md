# 使用教学

先做出一条短片，再逐步学习精修、自动运行与设置。无需一次读完全部参数。

## 按这个顺序学习

| 章节 | 你会学到什么 | 读完能做什么 |
|---|---|---|
| **[1. 第一条视频](first-video.md)** | 连接服务、创建项目、确认目标、校对与试片 | 做出一段原声字幕短片，再按需增加配音 |
| **[2. 手动制作与逐步检查](manual-workflow.md)** | 九个阶段各自的输入、操作和结果 | 知道该检查哪里、该单独重跑哪一步 |
| **[3. 自动流程、模板与批量](automation-and-templates.md)** | 单项目自动推进、模板复用、分组顺序与恢复 | 将已经调好的制作方式用于多个项目 |
| **[4. 设置怎么选](settings.md)** | 服务连接、制作参数、作用范围和运行存储 | 按“想调整什么”找到对应设置 |

**已有经验？** 想直接批量制作，进入第 3 章；遇到某个设置问题，直接查第 4 章。安装尚未完成时，先看[安装指南](../installation.md)。

## 先建立一个整体概念

这四段体验是一条阅读路线；实际任务会根据目标计算依赖，可以跳过未使用的能力。

<img src="../images/workflow-overview.svg" alt="从导入与计划，到校对文字和声音、组合版本，再到本地导出或按需交付。" width="960">

- **项目**管理一条视频及其校对稿、声音、成片和执行记录。
- **成片版本**决定这次使用什么声音、字幕、评论与剪辑。
- **自动流程**把已经保存的目标和设置串起来；手动操作与它共用同一份项目结果。

## 如何看教程中的配图

真实截图采用隔离演示项目、自写双语稿和自绘视频，显示的是操作位置；不会把“待运行”伪装成模型、合成或投稿成功。圈线编号与图下说明对应，点击图片可以查看大图。流程和架构图是示意图，全部采用暗色风格。
