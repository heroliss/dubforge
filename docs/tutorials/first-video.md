# 第一条视频：先做一段短片

[教学目录](README.md) · 下一章：[手动制作与逐步检查](manual-workflow.md)

这一章先完成一段**保留原声的字幕短片**。走通后，再增加配音版本和投稿；这样每次只需要判断一个新环节。

> 前提：已按[安装指南](../installation.md)安装并打开工作台。配图是隔离演示，展示操作位置，不代表实际模型或投稿结果。

## 1. 先让需要的服务可用

在「设置 → 模型与服务」填写 LLM 的接口地址、密钥和模型名，测试后保存。它用于语义整理、翻译等文本处理。

| 本次想做什么 | 先准备什么 |
|---|---|
| 从视频声音识别字幕 | 本地识别组件与模型 |
| 整理、翻译校对稿 | 可用的 LLM 连接 |
| 保留原声，烧录字幕 | 暂时不需要配音服务 |
| 增加中文配音 | 再配置独立 IndexTTS 2.5 或 GPT-SoVITS 服务及音色 |

第一次先保持其余参数默认。服务表单如何填写见[模型与配音连接](settings.md#模型与配音服务)。

## 2. 创建一个容易核对的项目

在项目空间创建项目，输入一段短视频的链接或本地路径。选择自己听得懂、方便逐句判断的素材，更容易发现识别和翻译问题。

首次可以用默认设置，模板稍后再学。使用本地路径引用的视频，在项目使用期间保持原位置；文件复制与引用的区别见[故障排查](../troubleshooting.md)。

## 3. 明确要做成什么，再运行

到「合成成片」选择一个目标版本：先保留原声、开启需要的字幕；第一次可以关闭配音和上屏评论，保存版本与目标。在「发布到B站」的交付规则中，将本次终点设为**仅保留成片**，点击「保存修改」；本次不需要连接账号。

回到总览，检查目标，再打开运行计划。下图是另一种演示选择：两个目标版本、终点为「准备发布草稿」；它用来说明位置，并非本章要求。

<img src="../images/project-overview.webp" alt="项目总览：①交付终点和目标版本，②运行项目入口。" width="960">

**① 核对自己的终点与目标版本 → ② 打开运行计划，检查后确认执行**

计划会显示需要执行、可以复用和仍需处理的内容。确认后等待本次计划执行及产物核验完成，再检查文字和画面；自动流程会推进到选定终点，不会在校对稿就绪时自动暂停。并不是每条视频都必须运行全部九个阶段。

## 4. 对照原片，校对几句

进入「字幕与配音」，先看最容易判断的几句：文字是否准确，译文是否自然，出现时间是否合适。

<img src="../images/subtitles-dubbing.webp" alt="字幕与配音：①原片预览，②双语句子与声源，③文字和时间编辑。" width="960">

**① 对照视频 → ② 选择句子 → ③ 修改并保存文字和时间**

只做原声字幕版时，无需生成配音。想增加配音时，先连接服务并选择音色，试配代表句，确认后再补齐所需声音。列表勾选控制这次操作哪些句子，句子的原声／配音选择控制成片用什么声音。

保存校对后，在合成页检查结果是否需要更新；如果前一轮已经完成成片，重新制作受影响的目标版本即可。

## 5. 先看短试片，再生成正式版本

进入「合成成片」，核对声音、字幕、评论与剪辑清单。图中①是自动运行使用的目标版本，②是本次手动生成范围，③是当前版本的删除片段。

<img src="../images/assembly-versions.webp" alt="成片页面：①项目目标版本，②手动生成范围，③删除片段清单。" width="960">

先选一个代表时段生成短试片，检查字幕位置、阅读节奏与音量；再制作正式版本。试片完成不等于整片已经生成，正式结果仍需等待核验。

### 做到这些，就完成了第一轮

- 字幕内容和时间已经保存，能与原片对照。
- 短试片中字幕可读，声音符合预期。
- 正式目标版本已有核验通过的输出，可以从成片结果查看或下载。

接下来可在同一项目增加配音版，或继续学习如何单独调整某个步骤。
