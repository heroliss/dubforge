# 自动运行、模板与批量制作

[回到 README](../../README.md) · [第一条视频](first-video.md) · [逐步手动制作](manual-workflow.md) · [设置如何生效](settings.md)

先让一个项目按预期完成，再把相同方案复用到多个项目。本篇按这个顺序练习：

**检查一个项目 → 保存制作目标 → 复用模板 → 批量运行 → 处理后继续。**

还没有可用项目时，先完成[第一条视频](first-video.md)；想在每个阶段停下来校对，可以配合[逐步手动制作](manual-workflow.md)。

## 1. 从一个项目的「运行项目」开始

打开项目总览，先找下图的两处：**准备做出什么、准备运行到哪里**，以及**运行入口**。

<img src="../images/project-overview.webp" alt="项目总览：标记①圈出交付终点和目标成片，标记②指向运行项目按钮。" width="960">

1. **① 核对目标。** “目标成片”列出要制作的版本，“项目交付终点”说明制作完成后是否继续准备草稿、上传或提交。
2. **② 点击「运行项目…」。** 没有中断任务时，会直接检查当前保存的目标；有中断任务时，先选择继续原任务还是开始新执行。
3. 在「检查执行方案」里阅读实际步骤、需补齐或更新的内容，以及将复用的结果。需要修改时先取消，到对应步骤保存，再重新检查。
4. 方案符合预期后，点击底部确认按钮。按钮会说明本次是制作、准备草稿、上传还是投稿。

> **查看方案不会启动任务。** 保存设置、检查计划、确认执行是三个不同动作；只有最后确认才开始。

无需为了运行项目把每一步都重新勾一遍。程序按目标检查依赖，复用有效结果；列表中的历史版本也不会自动全部重做。

## 2. 把目标保存在对应步骤

如果检查结果和预期不同，回到下面的位置调整。总览与批量运行读取这些已保存设置，不需要再维护另一份制作范围。

| 我想改变什么 | 去哪里设置 |
| --- | --- |
| 要做原声版还是配音版，是否烧录字幕、加入评论 | **合成成片**：配置版本并保存 |
| 项目自动运行时要生成哪些版本 | **合成成片**：选择项目目标成片，再保存版本与目标 |
| 制作后是否继续上传，使用哪个账号和合集，分 P 怎样排列 | **发布到B站**：保存交付方式、稿件目标和发布资料 |
| 翻译、配音或某个制作阶段的参数 | 该项目的对应步骤页，修改后保存 |

### 第一次先选择合适的终点

在「发布到B站 → 项目交付目标」中，“交付方式”有四种选择：

<img src="../images/publishing-target.webp" alt="项目交付目标：①决定制作后继续到哪里，②决定创建新稿或更新原稿。" width="960">

**① 交付方式决定终点，② 稿件目标决定发到哪里。** 图中选择的是准备本地发布草稿，尚未上传；完整操作仍需保存设置，并检查确认运行方案。

| 交付方式 | 确认运行后做到哪里 |
| --- | --- |
| **仅保留成片** | 做好目标版本后结束，文件留在本机 |
| **准备发布草稿** | 制作后准备本地稿件或更新方案，后续由你处理 |
| **上传后等待确认** | 上传选定视频，等待你另行确认提交 |
| **上传并提交** | 按确认的账号、稿件目标与范围上传并提交 |

先用“仅保留成片”检查画面和声音；准备投稿时，再选择需要的交付方式。保存交付设置本身不会上传或提交。

首次发布且没有发布或上传记录的项目，默认准备创建新稿。已有记录时，明确选择**创建新稿**或**更新已选原稿**；更新原稿会保留原 BV，需要核对具体稿件及更新范围。回执不明时，先查询原操作结果，再继续。

“上传并提交”表示提交到平台，**不表示平台一定审核通过或已经公开可见**。审核状态和退回原因在发布记录中另行查看。

## 3. 做对一次，再保存成模板

当几条视频需要相同音色、字幕、成片组合和交付规则时，到「设置 → 制作与发布」整理一套可复用方案。

下图先看左侧的**作用范围**，再看上方的**制作阶段**，最后查看该阶段的具体内容。

<img src="../images/production-settings.webp" alt="制作与发布设置：①选择全局默认或系列模板，②切换制作阶段，③编辑可复用的成片版本方案。" width="880">

1. **① 选择范围。** 全局默认保存通用起点；为某类视频新建系列模板，只改这类视频需要的差异。
2. **② 按阶段设置。** 例如在“字幕与配音”设置声音，在“合成成片”设置版本，在“发布到B站”设置交付规则。
3. **③ 保存方案。** 可以准备“中文配音版 + 原声双语版”等组合，供后续项目选用；具体参数作用见[设置如何生效](settings.md)。

### 记住三层关系

| 层级 | 适合放什么 | 如何影响项目 |
| --- | --- | --- |
| **全局默认** | 大多数视频共用的起点 | 为新项目、未另设的模板项提供基础 |
| **系列模板** | 某个系列或类别的共同差异 | 创建或应用时，解析为该项目的基础值 |
| **项目设置** | 只适合这条视频的调整 | 项目单独设置优先于基础值 |

**已有项目保留创建或上次应用时的基础值，不会实时跟着模板变化。** 例如修改模板里的字幕样式，旧项目仍保留原样；这样可以避免已经校对好的视频突然改变。

要让已有项目使用新版方案：

1. 在项目总览或项目卡片点击「应用最新设置…」，或选择另一个模板。
2. 先比较旧值、新值与影响步骤，再点击「确认应用设置」。
3. 项目单独设置继续保留。若某项仍未采用模板值，到该参数处恢复项目基础值并保存。
4. 重新检查运行方案。应用设置只更新参数，不会立刻重做旧成品。

## 4. 从项目列表批量推进

先给各项目指定合适模板，再勾选要执行的项目。**同一批可以混用不同模板，也可以混合本地制作和投稿目标。**

下图按 **① 模板 → ② 选择范围 → ③ 批量运行** 的顺序操作。

<img src="../images/project-space.webp" alt="项目空间：①在项目卡片选择模板，②勾选需要的项目，③点击批量运行，检查各项目计划后确认。" width="960">

1. **① 指定模板。** 在项目卡片选择模板，检查并确认应用的变化；需要刷新当前模板的值时，点击旁边的「应用最新设置…」。
2. **② 勾选项目。** 确认本次选择范围，尤其注意已选但被筛选隐藏的项目。
3. **③ 点击「批量运行…」。** 查看每个项目的终点、账号、稿件目标、分 P 和实际制作步骤。有问题时进入对应项目修改，保存后重新检查。
4. 核对合集组内顺序；包含自动投稿时，再确认素材可用于发布及本次投稿范围。
5. 点击底部「确认运行 N 个项目…」。各项目沿用自己的设置，不会因进入同一批而统一改成投稿。

视频数量较多时，可先用[批量创建项目](../batch-project-import.md)导入清单，再选中已创建项目运行。

### 同一合集保序，其他分组独立推进

例如有 **3 条视频要自动投稿到同一合集，另有 2 条零散视频**，可以一次选中全部 5 条：

| 项目 | 批量运行中的安排 |
| --- | --- |
| 均设为“上传并提交”，且账号、合集与小节相同的 3 条视频 | 组成保序组，按你确认的顺序逐项推进 |
| 其余 2 条零散视频 | 各自独立推进，不等待这个合集组 |

仅制作、准备草稿或上传后等待确认的项目保持各自终点，独立执行；不会为了合集顺序自动升级为投稿。

首次检查会尝试补齐原视频发布日期并据此安排顺序。合集组里可以「上移」「下移」；若同一合集有多条视频且日期仍无法获取，按提示人工核对。已确认批次沿用确认时的顺序。

**项目之间的顺序**与**一条稿件内的分 P 顺序**分别管理：前者在批量检查中确认，后者在各项目的发布设置中保存。自动投稿的合集组会等待前项审核及入合集结果，再推进后项；平台处理时间也会影响这一过程。

## 5. 有一组失败时，处理后继续原任务

批量任务按组显示当前进度和需要处理的问题。一组失败或结果不明时，该组暂停；其他组可以继续，不需要把全部项目从头再跑。

1. 找到需要处理的组，先看简短原因；需要更多信息时展开「查看上次中断详情」。
2. 按原因修复服务连接、模型额度、内容或项目设置。涉及投稿、原稿更新或章节时，先核对原稿及平台回执。
3. 在原批次点击「检查并继续本组…」；想一起处理多个待继续的组时，点击「检查待继续的组…」。
4. 检查剩余步骤、可复用结果及原交付范围，再确认继续。已完成的远端操作先核对，不通过重建批次重复投稿。

单项目中断后，从「运行项目…」选择：

| 当前目的 | 选择 |
| --- | --- |
| 接着完成原来确认的工作 | **继续上次任务**，重新核对断点与可复用结果 |
| 已主动改变目标，要按新设置执行 | **按当前设置开始新执行**，重新检查新目标；先处理已有稿件及未知回执 |

检查或提交中显示“核对中”“正在提交”等状态时，等待原请求回执；结果不明就重新读取原批次，不连续创建新的运行。

### 运行期间哪些操作仍然可用？

- 可以关闭网页，后台任务仍会继续；要继续制作，主程序需保持运行。
- 正在执行的步骤使用已确认输入，相关字段暂时冻结。其他未受影响的设置仍可按界面提示编辑；允许保存的连接或时限调整在后续执行时生效，不会改变当前步骤。
- 任务结束后若显示“产物核验中”，先等待核验结果，再决定下一步。不要为刷新状态而强制重启后端。

遇到持续失败时，按[排障指南](../troubleshooting.md)核对具体错误；想深入理解参数层级，继续阅读[设置如何生效](settings.md)。
