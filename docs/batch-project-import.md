# 批量创建项目

入口：**项目空间 → 批量导入**。支持粘贴文本、选择文件或拖入一个 `.txt` / `.json` 文件。每批最多100个视频、清单最大1MB，文件使用 UTF-8 编码。

导入只创建项目、绑定系列模板并保存参数，不下载视频、不调用 LLM，也不上传或投稿。完成后可以在项目空间勾选这些项目，使用现有的「批量运行」检查并启动。

## 最简单：每行一个来源

```text
https://www.youtube.com/watch?v=BaW_jenozKc
https://www.youtube.com/watch?v=aqz-KE-bpKQ
D:\Videos\本地视频.mp4
```

上面的网络地址仅用于展示格式，请换成自己的视频。空行和以 `#` 开头的整行备注会忽略。可混合视频链接和本机绝对路径；本地视频必须存在，只引用，不复制、不移动。暂不展开频道、播放列表或共享路径。

1. 在「未指定时使用」选择同一个系列模板，也可选择只用全局默认。
2. 点「解析并预览」。可以逐行另选模板，或取消勾选不想创建的项目。
3. 检查名称、来源、配置来源和项目覆盖，点「确认创建 N 个项目」。

不提供名称时，本地视频以文件名命名，链接以站点/视频标识命名；导入不联网抓标题。后续可在项目里改名，下载步骤仍照常获取平台资料。

## JSON：同批默认 + 逐项目差异

可直接下载 [基础样板](examples/batch-projects.json)。更推荐从界面下载样板：它会带上当前实际模板标识。

```json
{
  "schema": "dubforge.batch.v1",
  "defaults": {
    "template": "越南旅行",
    "settings": { "comments.mode": "auto", "comments.count": 10 }
  },
  "projects": [
    {
      "source": "https://www.youtube.com/watch?v=BaW_jenozKc",
      "title": "旅行视频 01"
    },
    {
      "source": "https://www.youtube.com/watch?v=aqz-KE-bpKQ",
      "title": "旅行视频 02",
      "template": "美食系列",
      "settings": { "comments.count": 5 }
    },
    {
      "source": "D:/Videos/本地视频.mp4",
      "title": "本地视频",
      "template": null
    }
  ]
}
```

示例中的模板需要已存在，请替换成自己的名称或 `series:…` 标识。名称必须唯一，稳定标识可避免模板重命名引起歧义。已归档模板不可用于新项目。

模板选择优先级：**预览中的逐行手选 → 项目 template → defaults.template → 界面默认模板 → 全局默认**。`template: null` 明确表示不绑定系列模板，并不是“忽略此字段”。

参数继续采用现有的一条继承链：**全局默认 → 系列模板 → 项目覆盖**。

- `defaults.settings` 是本批每个项目要保存的显式覆盖，不会修改全局默认或模板。项目的 `settings` 同名参数优先。
- 只写例外；不写的参数会继续实时继承模板。`false`、`0`、空字符串和允许的 `null` 都是明确的值，不代表继承。
- 数组整体替换，尤其是 `assembly.versions`；不逐个合并版本。
- `title` 是项目管理名称；`publish.title` 才是投稿标题。明确设置的发布文案优先于自动补全。
- `settings` 使用界面下载说明中的点分键名；不支持密钥、Cookie、代理和服务地址等环境设置。
- JSON 中的 Windows 路径建议写成 `D:/Videos/a.mp4`；使用反斜杠时要写成 `D:\\Videos\\a.mp4`。纯文本路径不需要转义。

## 同一视频做 P1 配音版 + P2 原声双语版

通常最合适的做法是先在系列模板设置好两种成片版本、发布分P顺序和目标合集，导入时只指定模板即可，后续修改模板也能继续生效。

如果这批视频有独立要求，可参考 [双分P样板](examples/batch-projects-two-parts.json)。主要参数为：

- `assembly.versions`：每个版本独立决定 `dubbing`、`burn_subtitles`、`include_comments`。版本 `overrides` 可单独指定字幕/评论语言和外观。
- `publish.version_ids`：按顺序引用版本 id，例如 `["dub", "src"]` 就是 P1 配音、P2 原声。
- `publish.part_titles`：版本 id 对应的分P名称。
- `publish.season_id`：实际 B站合集 ID；建议在系列模板里选择已有合集，不让 LLM 猜 ID。`section_id` 是合集章节，不是视频时间轴章节。

模板里已有合适版本时，不要重复把这些参数全写进 JSON，否则它们会成为独立的项目覆盖。

## 交给其他 LLM 生成

展开导入界面的「JSON 样板与 LLM 生成说明」，下载「LLM 说明与可用参数」。文件包含实际可用模板、字段类型/选项/范围、版本可覆盖字段、基础样板和双分P样板；不包含账号凭据或当前配置的完整值。

可以连同视频地址列表一起交给其他 LLM，并附上：

> 根据附件里的 DubForge 批量导入格式生成一个 UTF-8 JSON 文件。只使用我给出的视频地址，优先继承我指定的系列模板，仅把个别视频的差异写进 settings，不猜测模板、合集或账号 ID。每个项目填写易辨认的中文 title。只输出 JSON，不附加解释。我的模板是：……；视频及差异要求是：……。

生成的文件拖入 DubForge 或粘贴内容，先看预览再确认。错误项目会单独标出，可先创建其他有效项目。

## 重复、失败与恢复

- 同批重复来源或项目空间已有来源默认不勾选，可明确勾选再次创建。YouTube 的短链接、普通链接、Shorts 和时间戳参数会归到同一视频标识。
- 每个项目的登记、步骤、模板绑定、参数和批次回执放在同一个数据库事务内。部分失败不回滚其他已成功项目。
- 浏览器连接中断或刷新后，在原浏览器标签页重新打开导入窗口可以查询结果、用同一批次安全重试。成功项目不会再创建；后来删除的项目也不会被重试复活。
- 结果仍不明确时，不开启另一批；先查询或安全重试。全部条目都有结果后，可把失败项单独转成清单调整再导入。
- 模板在预览之后改变，会要求重新预览；不会悄悄改用新参数创建。

批次回执保存在本地数据库。浏览器的恢复入口使用本标签页的会话存储；关闭标签页或清除会话存储可能失去入口，此时请先核对项目列表再导入，重复检测仍有效。
