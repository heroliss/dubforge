## 真实 Windows 隔离启动

在 Windows PowerShell 5.1 下实际执行：

```powershell
.\scripts\smoke.ps1 -SkipTests -SkipFrontendBuild -KeepTemporaryData
```

本次命令退出码为 0，用时 11.18 秒。它创建全新临时配置、数据库、模型缓存和临时目录，只复制示例配置，并固定监听 `127.0.0.1:8611`。实际确认健康响应的应用名为 DubForge、版本为 `1.0.0`，项目列表严格为空。

本次 Windows 虚拟环境解释器通过重定向启动器启动真实监听子进程。执行器核对本轮启动进程、父子关系、出生时间、解释器、命令及工作目录；健康响应和项目列表返回后仍核对为同一监听身份。正常退出时，两项自有进程均结束，8611 恢复空闲。没有按端口接管或终止未知进程，也未操作用户常驻的 8600。

这条命令显式跳过后端测试和前端构建；其通过范围仅为上述真实隔离启动与退出。测试、类型检查和构建由前表的独立执行结果支持，不能把跳过项算作这次冒烟的执行内容。
